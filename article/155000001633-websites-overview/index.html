Websites Overview

MxP Websites let you build, organize, optimize, and publish multi-page sites from your sub-account. You can start from a blank site or template, manage pages from the Pages area, customize layouts in the Website Builder, review mobile behavior, connect a domain, and publish when the site is ready. This overview focuses on the core website workflow and links to dedicated guides for advanced features.

What Are Websites in MxP?

Websites are multi-page web experiences you can build and publish from the Sites area of a MxP sub-account. They are designed for use cases such as business homepages, service pages, contact pages, content pages, and other visitor-facing experiences.

Websites use the same core page-building experience as Funnels, including sections, rows, columns, elements, responsive editing, preview, save, and publish controls.

Key Benefits of MxP Websites

MxP Websites combine page creation, site organization, publishing, and performance tools in one place so you can manage the full website lifecycle from the same sub-account.

  • Centralized Page Management: Create, preview, edit, organize, and reorder website pages from the Pages area.
  • Flexible Page Building: Build layouts with sections, rows, columns, and elements, then adjust styling from the builder settings.
  • Responsive Design: Review and customize the visitor experience for desktop and mobile layouts.
  • Controlled Publishing: Save changes without immediately updating the live site, preview your work, then publish when it is ready.
  • Custom Domains: Connect and assign a branded root domain or subdomain to the website.
  • Built-In Performance Data: Review page views, opt-ins, sales, and other website performance data from MxP.

Websites vs. Funnels

Websites and Funnels use similar building tools, but they are organized for different visitor journeys. Choosing the right structure at the beginning helps keep pages and reporting easier to manage.

Manage Website Pages

The Pages area keeps your website pages in one place so you can edit, preview, and organize them without searching through the builder.

  • Open a page for editing in the Website Builder.
  • Preview a page before publishing.
  • Manage page-level settings and products where applicable.
  • Reorder page cards directly from the Pages grid.

Reorder Website Pages

Reordering pages helps you organize the Pages grid without opening the Page Builder. The new order saves automatically when you drop a page into position.

  1. From the Sub-Account view, select Sites in the left hand menu.
  2. Select Websites.
  3. Open the website you want to manage.
  4. Select the Pages tab.
  5. Click and hold the page card you want to move.
  6. Drag the page card to the desired position. A grabbing cursor and drop placeholder show where the page will be placed.
  7. Release the page card. The new order saves automatically.

If reordering fails: MxP restores the previously saved page order and displays an error.

How To Set Up a Website in MxP

A simple create → customize → review → connect → publish workflow keeps website setup easier to manage and helps prevent unfinished changes from reaching visitors.

Step 1: Create the Website

Starting with a blank site or template gives you the website workspace and page structure you will customize before launch.

  1. From the Sub-Account view, go to Sites → Websites.
  2. Click + New Website.
  3. Choose From Blank or From Templates.
  4. Enter the website name.
  5. Click Create and open the website.

Step 2: Add and Organize Pages

Create the pages the site needs, set clear page names and paths, and use the Pages grid to keep the site organized. You can also create and switch between pages from inside the Page Builder.

Step 3: Build and Customize Each Page

Building each page around its purpose keeps content, navigation, and calls to action easier for visitors to understand and use.

  • Add and arrange the sections, rows, columns, and elements needed for the page.
  • Update text, images, buttons, forms, navigation, and other content.
  • Review typography, spacing, backgrounds, and any global sections used across pages.
  • Use Preview to test links and page behavior before publishing.

Step 4: Review Mobile and SEO Settings

Reviewing responsive layouts and page metadata before publishing helps make the site easier to use across devices and prepares each page for sharing and search visibility.

  • Switch between desktop and mobile views to review responsive behavior.
  • Adjust supported mobile-specific settings or element visibility when needed.
  • Add the page title, meta description, and other applicable SEO settings before publishing.

Step 5: Connect the Domain and Publish

Connecting the correct domain and testing the saved version before publishing helps prevent broken navigation, incomplete pages, and domain-routing issues.

  1. Connect the root domain or subdomain you want to use for the website.
  2. Confirm the website is assigned to the correct domain and default page.
  3. Save your latest builder changes.
  4. Preview the website and test navigation, forms, buttons, and mobile layouts.
  5. Click Publish when the saved version is ready to go live.

Frequently Asked Questions

Q: Can I create and organize pages without leaving the Page Builder?
Yes. The Page Builder includes page-management tools that let you create, switch between, search, and organize pages from inside the editor.
Q: Can I use AI to help create or edit website pages?
Yes. Funnel & Website AI can provide AI-assisted page creation and editing.
Q: Where can I review website sales and transactions?
For current website selling experiences, review the applicable order and transaction records from the Payments area.
Q: What should I use if I need to restore an earlier page version?
Use Versions in the Website Builder to review previously saved versions and restore an earlier version when available. Undo/Redo is session-based and is better suited to recent edits made during the current editing session.
