Instagram Feed Widget in Funnels & Websites

Add a live Instagram feed directly to a Funnel, Website, or Store page with the Instagram Feed widget. Select an Instagram Business or Creator account already connected in Social Planner, choose a starting layout, and customize how posts appear across devices.

This guide explains how to add, style, preview, and publish the Instagram Feed without third-party embed tools or custom code.

What Is the Instagram Feed Widget?

The Instagram Feed widget is a native Page Builder element that displays posts from a connected Instagram account on Funnels, Websites, and Store pages.

Add the widget from Social Widgets, choose a template, select an Instagram account connected in Social Planner, and customize the feed for your page.

Key Benefits of the Instagram Feed Widget

The Instagram Feed widget provides a built-in way to display current Instagram content while controlling how the feed looks and behaves.

  • Five starting templates: Start with a preconfigured layout and customize it afterward.

  • Grid or Slider layouts: Switch between supported layouts at any time.

  • Responsive controls: Configure columns, rows, and spacing by device.

  • Flexible post display: Control post type, tile style, crop, and displayed details.

  • Built-in lightbox: Let visitors view supported posts, carousels, and videos without leaving the page.

  • Custom styling: Use light or dark schemes and customize supported colors.

Prerequisites and Limitations

Connect a supported Instagram account before adding the widget so it can retrieve content through Social Planner.

  • Use an Instagram Business or Creator account connected in Social Planner.

  • Personal Instagram accounts are not supported.

  • Feed history varies based on the content Instagram makes available through its API.

  • Posts load progressively, with up to 50 posts per request.

  • Additional posts can load through supported Load More or Slider navigation.

How to Set Up the Instagram Feed Widget

Add the Instagram Feed from the Page Builder, choose a starting template, and select the Instagram account you want to display.

Step 1: Open the Page Builder

From the Sub-Account View, open the page you want to edit:

  • Funnel: Go to Sites → Funnels, open the Funnel, then open the applicable step.

  • Website: Go to Sites → Websites, open the Website, then open the applicable page.

  • Store: Go to Sites → Stores, open the Store, then open the applicable page.



Step 2: Add the Instagram Feed

  1. Open the element panel.

  2. Select Social Widgets.

  3. Select Instagram Feed.

  4. Drag the widget onto the page.

  5. Choose a starting template.


Available templates include:

  • Profile widget: Profile header with a post grid.

  • Grid: Post grid only.

  • Small widget: Compact 2×2 layout.

  • Post slider: Horizontal carousel.

  • Dark profile widget: Profile layout with a dark color scheme.

You can customize any template after adding it.

Step 3: Select an Instagram Account

  1. Select the Instagram Feed widget.

  2. Choose an Instagram account already connected in Social Planner.

  3. Confirm that available posts appear.

  4. Use the General, Styles, and Post tabs to customize the widget.

  5. Save and preview the page.

  6. Publish when the page is ready.


Customize the Feed Layout

Layout controls determine how posts appear across desktop, tablet, and mobile.

You can:

  • Switch between Grid and Slider.

  • Use automatic columns or set 1–10 columns.

  • Set 1–5 rows.

  • Set post spacing from 0–50 px.

  • Configure columns, rows, and spacing separately by device.

  • Use up to 3 columns on mobile.

  • Add a feed title up to 200 characters.


Tablet initially follows the mobile settings. After you change a tablet-specific setting, tablet and mobile can be configured independently.

Customize Profile and Post Display

Choose which profile information and post details visitors see.

Profile Header

Show or hide the complete profile header or individual supported elements:

  • Profile picture

  • Display name

  • @handle

  • Post count

  • Follower count

  • Following count

  • Follow button


Posts

Choose which posts appear:

  • All supported posts

  • Photos only

  • Videos only


Choose a tile style:

  • Classic: Image with a hover overlay.

  • Card: Image with a caption block.


Choose a crop:

  • Square (1:1)

  • Portrait (4:5)


Depending on the selected tile style, you can show supported details such as the author, date, Instagram link, likes, comments, and caption.



Slider Controls

For Slider layouts, configure:

  • Navigation arrows

  • Drag/swipe

  • Animation speed from 0.1–2.0 seconds

  • Autoplay off or every 3–30 seconds


Configure Post Click Behavior

Choose what happens when a visitor selects a post:

  • Open the built-in lightbox.

  • Open the post on Instagram.

  • Take no action.

The built-in lightbox supports carousel posts, video playback, and keyboard navigation. Visitors can use the arrow keys to navigate and Escape to close it.

You can also control supported lightbox details, including:

  • Author

  • Follow button

  • Instagram link

  • Likes

  • Caption

  • Comments

  • Date


Customize Colors and Visibility

Use styling controls to match the Instagram Feed to your page and control where it appears.

Start with a Light or Dark color scheme, then customize supported colors for:

  • Header

  • Posts

  • Slider arrows

  • Popup

  • Load More

You can also:

  • Add a custom CSS class to the widget.

  • Control visibility by device.

  • Review the widget across desktop, tablet, and mobile views.


Reconnect an Instagram Account

The Instagram Feed requires an active Social Planner connection to retrieve current content.

If the Instagram connection expires, the widget displays a Disconnected badge and a Reconnect account button.

If Instagram or Social Planner is temporarily unavailable, the published widget can display cached content. If no cached content is available, the widget hides instead of displaying an error on the page.


Frequently Asked Questions

Q: Which Instagram accounts can I use?

Use an Instagram Business or Creator account connected in Social Planner. Personal Instagram accounts are not supported.

Q: Do I need a third-party Instagram feed service?

No. The Instagram Feed widget is built into the Page Builder and does not require a separate embed service or custom code.

Q: Can I use the widget on Store pages?

Yes. The widget is supported on Funnels, Websites, and Store pages.

Q: Can I configure the feed differently on mobile?

Yes. The widget supports device-specific layout settings. Mobile supports up to three columns.

Q: What happens if my Instagram connection expires?

The widget displays a Disconnected badge and a Reconnect account button.

Q: What happens if Instagram is temporarily unavailable?

Available cached content can remain visible. If no cached content exists, the widget hides instead of displaying an error.

Q: How many Instagram posts can the widget load?

Posts load progressively, with up to 50 posts per request. Total feed history depends on the content Instagram makes available for the connected account.
