Course Pricing: Sell Courses Without an Offer

Course Pricing lets eligible MxP users price and sell an individual course directly without first creating a separate Offer. Choose Free, One-time, or Recurring pricing, save the configuration to generate a checkout link, and configure supported access and promotional settings. This guide explains how direct Course Pricing works, how to set it up, and what to review before sharing the course.

What You'll Learn

Learn how to configure direct Course Pricing, generate and test the course checkout link, manage Advanced access settings and coupons, share the course, and understand the Not set up pricing status.

What Is Course Pricing?

Course Pricing lets you configure how learners access and pay for an individual course directly from the course.

When direct Course Pricing is available in your sub-account, you can choose Free, One-time, or Recurring pricing. Saving the pricing generates a checkout link that can be used to enroll or sell the course.

Direct Course Pricing provides an additional sales path without requiring a separate Offer for that checkout. Existing Offer-based course sales remain available for businesses that use the Offers experience.

2

Key Benefits of Course Pricing

Direct Course Pricing shortens the path between finishing a course and making it available to learners while keeping pricing, checkout, and access controls connected to the course.

  • Price Courses Directly: Configure pricing from the course without creating a separate Offer for the direct checkout flow.
  • Flexible Pricing: Offer the course for free, charge once, or use recurring billing.
  • Automatic Checkout Link: Generate a shareable course checkout link after saving pricing.
  • Checkout Preview: Review and test the learner checkout experience before sharing it.
  • Access Controls: Configure supported access timing and duration settings.
  • Course Promotions: Enable supported coupons for course-specific promotions.
  • Clear Pricing Status: Identify courses that still require pricing through the Not set up status.
3

Prerequisites and Limitations

Confirm that direct Course Pricing is available and review your payment setup before building the course checkout experience.

  • Course Pricing is rolling out gradually. During the initial rollout, it is enabled for 20% of newly created sub-accounts and is not currently available in existing sub-accounts.
  • A supported connected payment provider is required for paid Course Pricing.
  • A connected payment provider is not required for Free pricing.
  • Courses without configured direct pricing display Not set up.
  • Checkout and Advanced Course Pricing controls become available after the applicable pricing configuration is saved.
  • Cloned or kajabi-imported courses without configured direct pricing can require Course Pricing to be set up before using the direct checkout flow.
  • Offer-based course sales remain available for businesses using Membership Offers.

Don't see direct Course Pricing? The feature is currently in a limited rollout. If the Pricing tab is not available in your sub-account, continue using the existing Membership Offer flow.

4

How To Set Up Course Pricing

Configure and save the course pricing before sharing the course so MxP can generate the direct checkout experience and make the related pricing controls available.

  1. From the Sub-Account view, select Memberships.
  2. Select Courses.
  3. Open Products.
  4. Select the course you want to price.
  5. Open the Pricing tab.
  6. Select Free, One-time, or Recurring.
  7. For paid pricing, enter the applicable price and billing details.
  8. Review the configuration.
  9. Save the course pricing.

After pricing is saved, MxP generates the course checkout link.

  1. Preview the learner checkout.
  2. Test the checkout flow before sharing the link with learners.

Paid courses: Confirm that a supported payment provider is connected before testing a live payment. Courses are supported in MxP's payment-provider channel configuration.

5

How To Configure Advanced Course Pricing Settings

Advanced settings let you refine how course access works and whether supported promotions can be applied after the main Course Pricing configuration is saved.

  1. Go to Memberships → Courses → Products.
  2. Open the applicable course.
  3. Select Pricing.
  4. Confirm that the main Course Pricing has been configured and saved.
  5. Open Advanced.
  6. Configure the available access-start setting when learner access should begin at a defined time.
  7. Set the applicable access duration when course access should expire after a defined number of days.
  8. Enable coupons when supported course promotions should be available.
  9. Save the updated settings.

6

How To Share a Priced Course

Once pricing is configured, use Share Course to access the generated checkout link and distribute the course through the channel learners should use to enroll or purchase.

  1. Go to Memberships → Courses → Products.
  2. Open the applicable course or locate it on the Products page.
  3. Select Share Course.
  4. Review the available checkout-link controls.
  5. Copy the generated checkout link.
  6. Share the link through the channel you want learners to use.
7

Course Pricing Status

Pricing status helps identify whether a course is ready to use the direct checkout experience or still requires a Course Pricing configuration.

Courses without configured direct pricing display Not set up. This can include newly created, cloned, or kajabi-imported courses that do not yet have direct Course Pricing configured.

Configure and save the applicable pricing before using the direct checkout and related Advanced Course Pricing controls.


8

Frequently Asked Questions

Q: Do I need to create an Offer to use direct Course Pricing?
No. When direct Course Pricing is available, you can configure pricing on the course and use its generated checkout link. Membership Offers remain available as a separate course-selling method.
Q: Why don't I see the Course Pricing controls described here?
Course interfaces can vary by account rollout. If direct Course Pricing is not available, continue using the existing Membership Offer flow.
Q: Do I need a payment provider for a free course?
No. A supported payment provider is required when collecting payment for a paid course, but not for Free pricing.
Q: What does Not set up mean?
It means direct Course Pricing has not yet been configured for that course. Configure and save a pricing type before using the related direct checkout controls.
Q: Can I limit how long a learner has access to a course?
Yes. When the applicable Advanced Course Pricing control is available, you can configure a defined access duration for the course.
Q: Can I use coupons with Course Pricing?
Yes. When supported by the Course Pricing configuration, coupons can be enabled from the Advanced settings for eligible course promotions.
