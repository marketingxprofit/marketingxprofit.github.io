What is Managed Agents?

Managed Agents (formerly Super Agents) is an AI-first builder in MxP that creates powerful CRM agents from a simple conversation instead of a complex flowchart. By describing your use case in natural language, you receive a fully configured agent that can answer questions, use your Knowledge Base, and perform CRM actions, all powered by the same Agent Studio engine you use for visual AI workflows.

Managed Agents removes the need to design every node on a canvas. Under the hood, it uses Agent Studio's event-driven model and tools, so the agents it generates follow the same lifecycle (draft, test, publish).

Build Agents Using Natural Language

Describing your automation goals in everyday language gives Managed Agents enough context to design a working agent for you. This conversational approach helps you move quickly from vague ideas to a concrete, testable automation.

When you start a Managed Agent, you'll see a prompt area where you can explain:

  • The role of the agent (e.g., "social media assistant," "email campaign manager," "community moderator").
  • The channels it should work on (e.g., website chat, SMS, email).
  • The knowledge it can use (e.g., which Knowledge Base(s) or key documents).
  • The CRM actions it's allowed to take (e.g., tagging, updating fields, triggering workflows, sending emails).
Example Prompt

"Create a Social Media Assistant that writes and schedules on-brand posts for Facebook, Instagram, and LinkedIn. It should pull product details from our 'Marketing KB', follow our voice and tone guidelines, and save content ideas to a custom field on the contact record when they come from inbound chat conversations."

After you submit your description, Managed Agents will:

  • Generate a draft agent with a clear goal and behavior.
  • Propose triggers and channels based on what you described.
  • Configure conversation logic and CRM actions using Agent Studio under the hood.

Managed Agents can also configure Facebook lead form and survey triggers from a natural-language description. Describe that the agent should run after a Facebook lead or survey response, then select from the Facebook Pages, Lead Forms, or surveys available in the sub-account.

You do not need to look up Page, form, or survey IDs manually.

You can then refine the agent by continuing the conversation (for example, "Make the tone more formal" or "Limit posts to 3 per week per platform").

Intelligent CRM Agents

Managed Agents are built to do real work inside your MxP account, not just chat. They combine AI reasoning with your CRM data and Knowledge Base so they can both "talk" and "take action."

Capability 1
Answer questions using your Knowledge Base
  • Use MxP Knowledge Bases to ground responses in your real pricing, policies, procedures, and product information.
  • Include documents, rich-text content, tables/CSVs, and crawled web content so agents can handle a wide range of queries.
Capability 2
Run CRM actions and automations
  • Update contact fields and tags.
  • Trigger workflows for follow-ups, nurture sequences, or hand-offs to humans.
  • Create tasks, notes, or appointments depending on how you instruct the agent and which nodes are available in Agent Studio.
Capability 3
Generate images, audio, and video

For image generation, specify the desired shape in the prompt and choose the image quality under Capabilities → Image generation.

  • Generate images, spoken audio, and video as part of an agent interaction.
  • Control generated audio using voice selection and free-text tone instructions.
  • Generate spoken audio in the same language used in the prompt.
  • Save generated images, audio files, and videos to Media Storage as reusable assets.
  • Generate media during triggered agent runs without requiring an active chat session.

Note: Managed Agents use an updated image-generation experience that generates images faster and improves the rendering of small text and fine details. Image generation is consistent across all supported aspect ratios. Your existing image-generation settings and prompts continue to work without changes.

Event-Driven Automation

Event-driven automation ensures your Managed Agents spring into action exactly when they're needed, without manual intervention from your team.

When media generation is enabled, a triggered Managed Agent can generate images, audio, or video without requiring someone to start the request in chat.

Some of Managed Agents' trigger types include:

Trigger 1
Tag Changed

Fire an agent when a contact gains or loses a specific tag—perfect for onboarding flows, upsell offers, or VIP outreach based on segmentation.

Example: When a contact is tagged "New Customer," a Managed Agent sends a personalized welcome series and logs orientation tasks in the CRM.

Trigger 2
Form Submitted

Launch the agent after a specific form is submitted, such as a demo request, support escalation, or feedback form.

Example: After a "Website Demo Request" form is submitted, a Managed Agent qualifies the lead, books an appointment if they're a fit, and passes notes to your sales funnel.

Trigger 3
Chat Interface

Trigger agents directly from supported chat channels, similar to how Conversation AI bots are deployed.

Example: A Managed Agent deployed to your chat widget answers pre-sales questions, checks Knowledge Base entries, and tags contacts for a sales follow-up.

Trigger 4
Facebook Lead Form

Start a Managed Agent when a contact submits a lead form from a connected Facebook Page. You can select a Page to trigger the agent from every Lead Form on that Page, or select specific Lead Forms to narrow when the agent runs.

The agent receives the lead's submitted answers along with the contact, allowing it to qualify, respond to, or route the lead using the submission as context.

Trigger 5
Survey Submitted

Start a Managed Agent when a response is submitted to one or more selected surveys. The agent runs when a response is received for any selected survey.

The agent receives the survey name and submitted answers as context, allowing it to follow up on feedback, route contacts, or take other configured actions.

How to Set Up Managed Agents

Setting up Managed Agents involves creating an agent from a conversation, testing it thoroughly, and then wiring it to real CRM events. Following these steps ensures your first deployment is safe, predictable, and aligned with your business rules.

Step 1
Access Managed Agents under Agent Studio
  1. Log in to your sub-account.
  2. Navigate to AI Agents → Agent Studio.
  3. Click the Managed Agents tab.

Step 2
Create a Managed Agent from a conversation
  1. Click + Create Agent.
  2. In the prompt area, describe:
    • The agent's primary goal.
    • The channels it should support.
    • Which Knowledge Base(s) it should use.
    • The CRM actions it can take.
  3. You can also choose from prebuilt use cases.
  4. Submit the description and wait for Managed Agents to generate the draft agent.

Step 3
Review and refine the generated agent
  1. Review the generated summary:
    • What the agent does.
    • When it runs (triggers).
    • Which systems it touches (Knowledge Base, workflows, email, etc.).
  2. Use the chat-based editing sidebar to request adjustments to tone, rules, or actions.
  3. Define one or more triggers:
    • Tag Changed – e.g., when a "New Lead" tag is applied.
    • Form Submitted – e.g., demo request or onboarding form.
    • Chat Interface – e.g., website chat widget or another supported channel.
    • Facebook lead form – Run the Managed Agent when a contact submits a lead form from a selected Facebook Page.
    • Survey submitted – Run the Managed Agent when a response is received for one or more selected surveys.
  4. Confirm that any connected workflows, calendars, or Knowledge Bases are configured and tested.


Configure a Facebook Lead Form Trigger

Use this trigger when you want a Managed Agent to run as soon as a contact submits a Facebook lead form.

  1. From the Sub-account view, select AI Agents.
  2. Select Agent Studio.
  3. Select Managed Agents.
  4. Open the Managed Agent you want to configure.
  5. Open the Triggers section.
  6. Select + Add Trigger.
  7. Under Communications, select Facebook lead form.
  8. Select the Facebook Page.
  9. To trigger the agent for all Lead Forms on the Page, select the Page without limiting the trigger to individual forms.
  10. To narrow the trigger, select the specific Lead Forms that should start the agent.
  11. Use search to find a Page or Lead Form when needed. Lead Form search is limited to the selected Page.
  12. Publish the Managed Agent when the configuration is complete.

When the Managed Agent is published, MxP checks that the selected Page and Lead Forms still exist and that the selected Page and form combination can trigger the agent. If a selection is no longer valid, MxP identifies the issue before publishing.

The agent receives the lead's submitted answers with the contact when the trigger runs.

Configure a Survey Submitted Trigger

Use this trigger when you want a Managed Agent to run automatically after someone submits one of your selected surveys.

  1. From the Sub-account view, select AI Agents.
  2. Select Agent Studio.
  3. Select Managed Agents.
  4. Open the Managed Agent you want to configure.
  5. Open the Triggers section.
  6. Select + Add Trigger.
  7. Under Forms & Surveys, select Survey submitted.
  8. Select one or more surveys.
  9. Use search to find surveys when needed.
  10. Publish the Managed Agent when the configuration is complete.

[Screenshot: Trigger Picker showing Forms & Surveys and Survey submitted.]

The Managed Agent runs when a response is submitted to any selected survey. The survey name and every submitted answer are included in the agent's context.

When you publish the Managed Agent, MxP checks that the selected surveys still exist and identifies invalid selections before publishing.

Step 4
Configure media generation capabilities

1. Open the Capabilities section for the Managed Agent.

2. Turn on Image generation, Audio generation, or Video generation based on the media the agent needs to create.

3. For image generation:

  • Select a quality level: Low, Medium, or High. Medium is the default.
  • Include the desired image shape in your prompt.
  • Supported shapes include 1:1, 4:5, 2:3, 3:2, 9:16, 3:4, 4:3, 5:4, 16:9, and 21:9.
  • You can also describe the shape with terms such as vertical, widescreen, square, or banner.
  • If you do not specify a shape, the agent generates a square image.

Example: Generate a 9:16 vertical image of a coffee shop for an Instagram story.

4. Each new image-generation request creates a new image unless you explicitly ask the Managed Agent to edit an existing image.

5. For audio generation:

  • Select a supported voice.
  • Use the Tone field to describe how the audio should sound.
  • Write the source text in the language you want the agent to speak.

6. For video generation, Managed Agents generate an 8-second video in a 16:9 aspect ratio.

7. Audio and video are generated separately.

8. Generated media is saved to Media Storage for reuse.

Note: Managed Agents use an updated image-generation experience that generates images faster and improves the rendering of small text and fine details. Image generation is consistent across all supported aspect ratios. Your existing image-generation settings and prompts continue to work without changes.

Step 5
Test the Managed Agent in the built-in panel
  1. Open the testing panel for the agent.
  2. Run a test to check if the flow is functioning as expected.
  3. Confirm that Knowledge Base answers are accurate and that the agent respects your constraints.
  4. If the Managed Agent uses web search, review the Sources displayed beneath the response and open any citation to verify the information.
  5. If media generation is enabled, ask the Managed Agent to create a sample asset.
  6. Iterate using chat-based editing until responses and actions look correct.

Step 6
Publish the Agent
  1. Change the agent status from Draft to Published so it can respond to live events.

Step 7
Monitor and optimize
  1. After going live, monitor agent performance from Agent Studio and related reporting.
  2. Periodically return to the Managed Agent's chat builder to refine rules, tone, and behaviors based on real-world outcomes.
  3. Keep your Knowledge Base clean and updated; tools like the Knowledge Base Retrieval Tester help identify missing or low-quality content that could affect answers.
Success

Once published, your Managed Agent runs automatically based on the triggers you configured. It will handle conversations, answer questions from your Knowledge Base, and execute CRM actions exactly as you described—all without manual intervention.

Frequently Asked Questions

Q: How is a Managed Agent different from a Flow Based Agent?
A Managed Agent is created conversationally from your natural-language description, whereas a Flow Based Agent is built manually on the node-based canvas. New agent creation should be done using Managed Agents. Existing Flow Agents continue to run normally and can still be opened, edited, and managed from the Flow Agents page.
Q: What happens if my Knowledge Base content changes after I publish a Managed Agent?
The agent will automatically pull updated information from your Knowledge Base the next time it runs, as long as the content has been indexed. To ensure accuracy, use the Knowledge Base Retrieval Tester to validate that new or modified content is discoverable before your agent references it in live conversations.
Q: Can I use multiple triggers for a single Managed Agent?
Yes. You can configure multiple supported triggers for one Managed Agent so it can respond to different events. Supported triggers can include tag changes, form submissions, chat interactions, schedules, appointments, contact events, opportunity events, Facebook lead form submissions, and survey submissions.
Q: How do I prevent a Managed Agent from making unwanted CRM changes?
Use the chat-based editing experience to set explicit guardrails. For example, you can instruct the agent to "only suggest CRM changes for human approval" or "never apply discounts over 10%." Always test thoroughly in the built-in testing panel before publishing to confirm the agent respects your constraints.
Q: Do I need coding or technical skills to build a Managed Agent?
No. Managed Agents is designed for users without technical backgrounds. You describe your automation goals in plain language, and the system generates the agent configuration automatically. No coding, flowchart design, or complex setup is required.
Q: What channels can Managed Agents work on?
Managed Agents can run from supported chat channels and CRM events, including tag changes, form submissions, Facebook lead form submissions, survey submissions, appointments, schedules, contact events, and opportunity events. Available channels and events depend on the triggers and integrations configured in the MxP account.
Q: Are Managed Agents included in AI Employee plans?
Yes. The AI Employee Growth plan includes 100 runs/month. The AI Employee Unlimited plan includes 1000 runs/month. Pay-per-use pricing is also available. For more information on pricing, see AI Product Pricing.
