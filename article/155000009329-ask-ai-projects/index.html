What Are Ask AI Projects?


Ask AI Projects in MxP let you organize related conversations, files, instructions, and memories in dedicated workspaces. Each project gives Ask AI the context it needs to provide relevant, consistent responses without requiring you to repeat the same information across conversations. You can also manage scheduled tasks, track project activity, and keep different workflows organized in one place.

Project Instructions and Context


Project instructions define how Ask AI should approach work within a particular project. By setting expectations for tone, formatting, brand voice, and other requirements, you can maintain a consistent approach across multiple conversations without repeating instructions in every prompt.


Each project can include:


  • Project Name: Identifies the workspace and helps distinguish it from other projects.

  • Description: Explains the purpose of the project and provides background about the work.

  • Custom Instructions: Defines the rules, guidelines, formatting preferences, or brand voice Ask AI should follow.

  • Related Conversations: Keeps chats associated with the same project together.

  • Reference Content: Provides additional information through uploaded files, Media Library items, and text documents.

  • Project Memory: Retains useful information associated with the project.


For example, you could create a project named "Monthly Marketing Campaigns" and add instructions such as:

"Write marketing content in a professional, approachable tone. Use concise paragraphs, emphasize customer benefits, and include a clear call to action when appropriate."


These instructions apply to conversations within that project, helping maintain consistent communication.

Project Files and Supported Formats


Adding reference materials gives Ask AI access to relevant project information, such as campaign details, content guidelines, or business documentation. Keeping this material within a project helps provide consistent context for conversations related to the same work.


Adding Project Context


You can add reference material to a project using three methods:


  • Upload Files: Add documents directly from your device.

  • Select From Media Library: Choose existing files stored in your MxP Media Library.

  • Add Text Documents: Create or add text-based reference content for the project.


Supported File Formats


Ask AI Projects support the following document formats:


File TypeFormat
PDF documents.pdf
Microsoft Word documents.docx
Plain text documents.txt
Markdown documents.md
Comma-separated values.csv


File Limit: Each project supports up to 50 files.


For example, a marketing project could include a brand guidelines PDF, a campaign plan in Word format, and a CSV containing approved product information.



Project Memory


Project-specific memory helps Ask AI retain useful information related to ongoing work. Instead of treating each project conversation as an isolated request, memory provides additional context that can make future responses more relevant.


Project memory supports the following actions:


  • Review Memories: View information saved for the project.

  • Delete Memories: Remove information that is outdated or no longer needed.

  • Import Memories: Bring existing memories from another AI assistant into the project.


For example, a project dedicated to creating educational articles could retain relevant preferences about the audience, content style, and terminology.


Project memories are intended to support the work associated with that project. This makes it easier to maintain different working contexts for different objectives.


To learn more about general memory functionality, see What is Ask AI Memory?.

Scheduled Tasks in Projects


Scheduled tasks allow Ask AI to execute recurring prompts using the instructions and context associated with a project. This is useful for work that needs to happen regularly and should follow the same project-specific guidelines.


Project-based scheduled tasks can support recurring activities such as:


  • Preparing periodic marketing summaries.

  • Generating recurring content ideas using project brand guidelines.

  • Reviewing relevant business information.

  • Producing recurring updates based on the project's available context.


For example, a marketing project could include a weekly task asking Ask AI to generate campaign ideas using the project's brand voice and reference documents.


Using project instructions with scheduled tasks helps maintain a consistent approach across recurring executions.



For general scheduling instructions, see How to Use Scheduled Tasks in Ask AI to Automate Prompts.

Project Activity and Management


As your projects grow, management and activity-tracking tools help keep workspaces organized and make important changes easier to review. These capabilities are useful when managing multiple projects with different instructions, reference files, and scheduled tasks.


Project Activity Tracking


Project activity provides visibility into changes involving:


  • Project instructions.

  • Project files.

  • Scheduled tasks.

  • Project status.


Reviewing activity helps you understand how a project's configuration has changed over time.



Organizing and Managing Projects


Ask AI includes the following project management capabilities:


  • Search: Find projects by their identifying information.

  • Sort: Organize the project list using available sorting controls.

  • Pin: Keep important projects easily accessible.

  • Archive: Move projects that are no longer part of your active work out of the main project list.

  • Restore: Return archived projects to your active workspace.

For example, you could pin frequently used projects and archive completed campaigns to reduce clutter while keeping those projects available for future reference.

Frequently Asked Questions


Q: Can other MxP users access my Ask AI Projects?

No. Projects and their associated chats are private to the individual user. The availability of Projects at the agency and sub-account levels does not mean projects are shared with other users.



Q: Are projects shared between agency and sub-account views?

No. Each agency and sub-account maintains its own projects, keeping project work organized within the relevant account context.



Q: How many files can I add to a project?

Each project supports up to 50 files. Supported document formats include PDF, Word (.docx), plain text, Markdown, and CSV.



Q: Can I import memories from another AI assistant?

Yes. Ask AI Projects include an option for importing memories from another AI assistant. This can help you bring existing context into a project instead of rebuilding that information manually.



Q: Do I need to create a separate project for every conversation?

No. Projects are designed to group related conversations together. You can use a single project for multiple conversations that share the same objectives, reference materials, or instructions.



Q: What is the difference between project instructions and Ask AI Skills?

Project instructions provide guidelines and context for conversations within a particular project. Ask AI Skills are reusable instruction sets that Ask AI can apply when a request matches a particular workflow or when a user invokes a Skill.



Q: Can I restore an archived project?

Yes. Ask AI Projects support archiving and restoring projects, allowing you to organize inactive work without permanently removing the project from your available workspaces.



Q: Can scheduled tasks use my project's context?

Yes. Scheduled tasks associated with a project run using its instructions and context. This helps recurring tasks follow the guidelines and reference information relevant to the project.
