Lead Source Report: See Leads, Status, and Value by Source

The Lead Source Report in MxP helps you track where leads come from, monitor opportunity statuses, and compare lead values by source. It provides a clear overview of your sales pipeline so you can identify which channels generate the most opportunities.

What Is the Lead Source Report?


The Lead Source Report is a dashboard widget that groups opportunities by their recorded source. It displays lead counts, opportunity statuses, and monetary values to help you evaluate lead generation performance.

Key Benefits of the Lead Source Report


The report makes it easier to understand lead performance and identify opportunities requiring attention.

  • Lead Source Tracking: See which channels generate opportunities.

  • Status Monitoring: Track Open, Won, Lost, and Abandoned opportunities.

  • Value Insights: Compare opportunity values across sources.

  • Flexible Filtering: Filter by pipeline, users, sources, and attribution.

  • Opportunity Details: Click counts to review individual opportunities.

Understanding the Lead Source Report


Each source appears in a separate row, with opportunities grouped by status.

ColumnDescription
SourceRecorded opportunity source.
Total LeadsTotal opportunities from that source.
OpenOpportunities still in progress.
WonOpportunities marked as won.
LostOpportunities marked as lost.
AbandonedOpportunities marked as abandoned.


Note: The report counts opportunities, not unique contacts. Monetary values require the appropriate permissions.

Filtering and Date Settings


Filters help you narrow results to specific opportunities, while date settings control which reporting period is used.


Available filters include:

  • Pipeline and Assigned User

  • Source and Attribution

  • Tags and Followers

  • Lead Value and Custom Fields


Source filters: Use Is, Is not, Is empty, or Is not empty to include or exclude sources.


Date properties:

  • Created Date: When the opportunity was created.

  • Status Change Date: When its recorded status last changed.

How to Set Up the Lead Source Report


Proper configuration ensures the report displays the relevant opportunities and reporting period.

  1. Navigate to Dashboard in your MxP sub-account.

  2. Click Edit dashboard, then Add widget.



  3. Search for Lead Source Report in the Widget Gallery.



  4. Select the widget and choose your pipeline.

  5. Configure filters under Conditions.

  6. Adjust date settings as needed.

  7. Click Save.

Viewing Opportunities and Missing Sources


The report allows you to inspect individual opportunities and identify records without source information.

  • View opportunities: Click an opportunity count to open the corresponding records.

  • Find missing sources: Locate the N/A row or apply Source → Is empty.

  • Exclude missing sources: Apply Source → Is not empty.

Frequently Asked Questions


Q: Why are some opportunities missing?

Check the selected pipeline, date range, and filters. Opportunities without a source may appear under N/A.


Q: Why can't I see opportunity values?

Your account may not have the required permission to view lead values.


Q: Can one contact appear multiple times?

Yes. Each opportunity is counted separately, even when several belong to the same contact.


Q: Does the report use UTM parameters as the Source?

No. The report groups opportunities by Opportunity Source. UTM parameters can be used as additional attribution filters.


Q: Can I filter the report by salesperson?

Yes. Use the Assigned User condition to display opportunities associated with specific users.
