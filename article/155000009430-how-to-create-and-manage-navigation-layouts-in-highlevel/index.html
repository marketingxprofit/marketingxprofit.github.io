How to Create and Manage Navigation Layouts in MxP

Navigation Layouts help MxP agencies create a consistent, organized navigation experience across their sub-accounts. Instead of configuring menus individually, agencies can create and save reusable layouts that organize products, rename groups, change icons, reorder items, and hide unnecessary options. This guide covers creating, applying, and managing Navigation Layouts, including shared updates, individual customizations, plan availability, and important limitations.

Key Benefits of Navigation Layouts

Navigation Layouts help agencies simplify navigation management while maintaining an organized experience for different clients and sub-accounts.

  • Consistent Navigation: Apply the same saved configuration across multiple sub-accounts to maintain a familiar navigation experience.

  • Reusable Configurations: Save layouts for future use instead of rebuilding the same navigation structure for each sub-account.

  • Flexible Organization: Rearrange products, rename groups, change icons, and hide unnecessary menu options.

  • Centralized Management: Update a shared layout and automatically reflect changes across the sub-accounts using it.

  • Individual Flexibility: Save a separate layout when one sub-account needs a different navigation configuration.

  • Simplified Navigation: Reduce visible menu clutter without changing product availability or user permissions.


Prerequisites and Limitations


Plan Availability

Agency PlanNavigation Layout Capabilities
$97 PlanDefault navigation only. Navigation customization is unavailable.
$297 PlanCustomize navigation for one sub-account. Reusable layout management is unavailable.
$497 PlanCreate, save, edit, rename, and duplicate Navigation Layouts. Apply layouts to multiple sub-accounts and manage shared updates.

Important Limitations

  • Plan Eligibility: Reusable Navigation Layout management is available on the $497 agency plan.

  • $297 Customization: Agencies on the $297 plan can customize navigation for one sub-account but cannot manage reusable layouts.

  • Snapshots: Navigation Layouts are not included in snapshots.

  • New Sub-Accounts: Saved layouts are not automatically applied to newly created sub-accounts. Agencies must apply them manually.

  • Permissions: Hiding a navigation item does not disable the feature or restrict access to it.

  • Shared Changes: Editing a shared layout can automatically update all sub-accounts using that layout.


What Happens When an Agency Downgrades?

When an agency downgrades from the $497 plan to the $297 plan, its existing Navigation Layouts remain in place.

However, the agency can edit navigation for only one sub-account going forward. Reusable layout management is no longer available under the $297 plan.

How To Setup Navigation Layouts

.

Create and Save a Navigation Layout

Create a Navigation Layout when you want to reuse the same navigation configuration or establish a consistent menu structure for multiple sub-accounts.

Steps:

  1. Start from the MxP Agency View.

  2. Configure the navigation using the available customization options:

    • Organize products and navigation items.

    • Rename navigation groups.

    • Change icons.

    • Reorder menu items.

    • Hide menu options that should not appear in the layout.

Apply a Layout to One Sub-Account


Steps:

  1. Use a saved layout when you want to apply an existing navigation configuration to a specific sub-account.

    1. From your Agency View, access your saved Navigation Layouts.

    2. Find the layout you want to use.

    3. Choose the option to apply the layout.

    4. Select the sub-account that should use it.

    5. Apply the layout to the selected sub-account.

    6. Review the sub-account's navigation menu to see the applied configuration.


Apply a Layout to Multiple Sub-Accounts

Steps:

  1. You can apply the same saved layout to multiple sub-accounts without customizing each one individually.

    1. From your Agency View, access your saved Navigation Layouts.

    2. Select the layout you want to apply.

    3. Choose the option to apply the layout to sub-accounts.

    4. Select the sub-accounts that should use the layout.

    5. Apply the layout to your selected accounts.

    6. Review the navigation menu in the assigned sub-accounts.


Important: Once multiple sub-accounts use a shared layout, changes to that shared layout can affect all assigned sub-accounts.


Manage Existing Navigation Layouts

Saved Navigation Layouts can be updated, renamed, or duplicated as an agency's navigation requirements change. Agencies on the $497 plan can manage reusable layouts.

Edit an Existing Layout

Edit an existing layout when you want to change its navigation structure, such as menu order, group names, icons, or hidden items.

Steps:

  1. Edit a saved layout whenever you need to change its navigation menu.

    1. From Agency View, access your saved Navigation Layouts.

    2. Select the layout you want to update.

    3. Edit the navigation configuration.

    4. Make your changes, such as reordering items, renaming groups, changing icons, or hiding options.

    5. Save your changes.


Important: Updating a shared layout can automatically update all sub-accounts assigned to it. To customize only one sub-account, save a separate layout instead.


Rename a Layout

Rename a saved layout when its existing name no longer clearly identifies its intended use.

Steps:

  1. Give your layouts clear names so they are easier to identify and manage.

    1. From Agency View, access your saved Navigation Layouts.

    2. Find the layout you want to rename.

    3. Select the rename option.

    4. Enter the new layout name.

    5. Save your changes.


Duplicate a Layout

Duplicate an existing layout when you want to use its configuration as the starting point for a separate navigation experience.

Steps:

  1. Give your layouts clear names so they are easier to identify and manage.

    1. From Agency View, access your saved Navigation Layouts.

    2. Find the layout you want to rename.

    3. Select the rename option.

    4. Enter the new layout name.

    5. Save your changes.


Manage Shared and Individual Layout Changes

Update a Shared Layout

When multiple sub-accounts use the same saved layout, changes to the shared layout can automatically update the navigation experience for all assigned accounts.

For example, if an agency modifies menu ordering or hides an unnecessary item in a shared layout, that update can be reflected across the sub-accounts using the layout.

Steps:

    1. From Agency View, access your saved Navigation Layouts.

    2. Select the shared layout you want to update.

    3. Make the required navigation changes.

    4. Save the updated layout.

    5. Review the navigation menus in the assigned sub-accounts.

Important: Shared changes should be used when the same navigation update is intended for all sub-accounts assigned to the layout.


Customize One Sub-Account Independently

Save a separate Navigation Layout when one sub-account needs a unique menu configuration without affecting other sub-accounts using the original shared layout.

For example, an agency may want one client's navigation to display a different menu order or hide certain items while leaving the shared navigation unchanged for other clients.

Steps:

  1. From Agency View, access your saved Navigation Layouts.

  2. Duplicate the existing shared layout.

  3. Rename the copied layout so you can easily identify it.

  4. Customize the new layout for the specific sub-account.

  5. Save the new layout.

  6. Apply it only to the sub-account that needs the changes.

Important: To avoid affecting other sub-accounts, do not modify the original shared layout when changes are intended for only one account.

Frequently Asked Questions


Q: Does hiding a navigation item remove the user's access to that feature?

No. Hiding an item changes its visibility in the navigation interface. It does not disable the feature or change the user's permissions.

Q: Are Navigation Layouts included in snapshots?

No. Navigation Layouts are not included in snapshots. They must be managed separately from snapshot content.


Q: Will a saved Navigation Layout automatically apply to new sub-accounts?

No. Newly created sub-accounts do not automatically receive saved Navigation Layouts. The agency must apply the intended layout manually.


Q: What happens when an agency downgrades from the $497 plan to the $297 plan?

Existing layouts remain in place. However, the agency can edit navigation for only one sub-account going forward and cannot manage reusable layouts under the $297 plan.


Q: Can agencies on the $297 plan create reusable layouts for multiple sub-accounts?

No. The $297 plan supports navigation customization for one sub-account. Reusable layout management and multi-sub-account layout application are available on the $497 plan.


Q: Can one sub-account use a different layout without changing the others?

Yes. Agencies with reusable layout management can save a separate Navigation Layout and apply it to the intended sub-account without modifying the original shared layout.
