Configure and Filter General Widgets on your Sub-account Dashboard

General Widgets on the sub-account dashboard are fully editable, giving you more control over the data and presentation of your default dashboard. You can add permanent Conditions, set widget-specific date ranges, compare reporting periods, rename widgets, apply themes, and duplicate or delete widgets. These options help teams create focused reporting views without rebuilding pre-built widgets as custom widgets. This guide explains how to configure General Widgets and use the new editing options.

What are Editable General Widgets?


General Widgets are pre-built dashboard widgets provided in sub-accounts to help users monitor common business metrics without creating widgets from scratch. These widgets can now be edited so each dashboard can show data that better matches a team's reporting needs.


You can change a General Widget's title, reporting dates, comparison period, saved Conditions, and visual theme. General Widgets can also be duplicated to create reporting variations or deleted when they are no longer needed.

The widget face also displays its active date property and date range, helping viewers understand the reporting basis behind the displayed values.

Key Benefits of Editable General Widgets


Editable General Widgets make the default dashboard more flexible while preserving the convenience of pre-built reporting components.


  • Permanent data filtering: Add Conditions based on supported fields such as assigned user, tags, source, lead value, custom fields, and attribution.


  • Widget-specific reporting periods: Override the dashboard-level date range for an individual widget.


  • Period comparisons: Compare the current reporting period with Last year or Last period.


  • Clear date context: View the active date property and date range directly on the widget.


  • Custom titles: Rename widgets using team-specific or client-friendly language.


  • Visual customization: Apply themes to General Widgets without rebuilding them.


  • Faster reporting variations: Duplicate configured widgets and apply different Conditions or date settings.


  • Cleaner dashboards: Delete General Widgets that are no longer required.

How To Edit and Configure General Widgets


Editing a General Widget opens its configuration panel, where you can change reporting settings, apply Conditions, and select a theme.


  1. From the Sub-Account view, select Dashboard in the left navigation.

  2. Click Edit dashboard in the top-right corner.

  3. Locate the General Widget you want to customize.

  4. Hover over the widget and click the three-dot menu (⋮).

  5. Select Edit.

  6. The Edit widget panel opens with Configure, Conditions, and Themes tabs.

  7. Make the required changes.

  8. Click Save.

Configure the Widget Title and Reporting Period


The Configure tab controls the widget's title and date settings. These options help viewers identify what the widget measures and which reporting period is used to calculate its values.


Edit the Widget Title


  1. Open the Edit tab.

  2. Locate the Title field.

  3. Enter the title you want to display on the widget.


You can rename a General Widget using terminology that is clearer for your team or client.



Configure Advanced Settings


  1. From the Configure tab, expand Advanced settings.

  2. Use Date property to select the date field used when calculating widget data.

  3. Use Date range override to assign a reporting period specifically to the widget.

  4. Use Comparison date range to compare the selected period with a supported comparison period.

  5. Click Save.




Supported comparison examples include Last year and Last period.


A widget-level date range override works independently from the dashboard-level date range. This allows two similar widgets to report on different time periods.


The widget face displays the active date property and date range, helping viewers understand which reporting basis produced the displayed values.

The following General Widgets don't currently have a Conditions tab:

  • Tasks: You can edit the title and dashboard date range (date property applies to the due date).
  • Manual Actions: You can edit the title and dashboard date range (date property applies to the created date).
  • Google Business Profile: You can edit the title only.
  • Email Health Report: You can edit the title and dashboard date range override.

Add a Condition


  1. From the Edit widget panel, select Conditions.

  2. Select the field you want to filter.

  3. Select the appropriate operator.

  4. Select or enter the value.

  5. Click + AND when another condition in the same filter group must also match.

  6. Click + Add filter to create another filter group.

  7. Add any additional Conditions needed for the widget.

  8. Click Save.


Conditions within the same group use AND logic. Separate filter groups use OR logic.


For example, you can filter by a custom field using a configuration such as:


Custom fields → Property Type → Is one of → selected property types

You can also combine supported criteria such as Source and Tags to create more focused reporting views.


Apply a Theme to a General Widget


Themes change the visual appearance of a General Widget without requiring you to recreate it as a custom widget. This can help distinguish reporting groups or create a dashboard that better matches client-facing presentation needs.


  1. From the Edit widget panel, select Themes.

  2. Select the visual theme you want to apply.

  3. Review the updated widget appearance.

  4. Click Save.




Duplicate or Delete a General Widget


Duplicating a configured widget makes it easier to create reporting variations from the same starting point. Widgets that are no longer useful can also be removed while the dashboard is in edit mode.


Duplicate a General Widget


  1. From the Sub-Account view, select Dashboard.

  2. Click the three-dot menu (⋮).

  3. Select Duplicate.

  4. Edit the duplicated widget as needed.


Duplicating is useful when you want to compare different users, sources, tags, custom-field values, or reporting periods using the same base widget.




Delete a General Widget


  1. From the Sub-Account view, select Dashboard.

  2. Click the three-dot menu (⋮).

  3. Select Delete.


Frequently Asked Questions


Q: Are Conditions saved permanently on a General Widget?
Yes. Conditions remain applied to the widget after you leave edit mode and return to the dashboard.


Q: Can a General Widget use a different date range from the dashboard?
Yes. Use Date range override under Configure → Advanced settings to assign a reporting period specifically to that widget.


Q: Can I compare one reporting period with another?
Yes. Use Comparison date range to compare the current period with a supported comparison such as Last year or Last period.


Q: Can I combine multiple Conditions?
Yes. Use + AND when conditions within the same filter group must all match. Separate filter groups use OR logic.


Q: Can I create multiple versions of the same General Widget?
Yes. Use Duplicate, then change the duplicated widget's title, Conditions, date settings, or theme.


Q: Can I remove a General Widget I no longer need?
Yes. Enter Edit dashboard, open the widget's three-dot menu, and select Delete.


Q: Do General Widgets respond to dashboard-level Quick Filters?
No. Dashboard Quick Filter support for General Widgets is not included in the current release.


Q: Can I configure what appears inside Funnel and Manual Actions widgets?
Not as part of the current General Widget editing release.
