AI & Search Visibility - Read Your SEO Audit Report & Action Items

The SEO Audit Report in AI & Search Visibility provides a detailed breakdown of your website's technical SEO health, including crawled pages, links, resources, and detected issues. It also organizes findings into action items with severity levels and recommended fixes, helping you understand which areas need attention.

Reading Your SEO Audit Report and Action Items


The SEO Audit Report is organized into five views: Overview, Pages, Links, Resources, and Actions. Each provides a different level of detail, from your website's overall health to individual issues and recommendations.


Understanding the SEO Audit Overview


The Overview provides a summary of your website's audit results and highlights areas that need attention. It combines key metrics, priority issues, crawl information, and technical performance findings in one place.


Report AreaWhat It Shows
Audit SummaryHealth Score, Pages Needing Attention, Errors, and Broken Links.
Priority ItemsDetected issues, affected SEO areas, priority levels, and the number of pages affected.
Crawl and IndexabilityPage signals, their meaning, affected page counts, and status. These indicate how pages respond to crawlers and whether they are eligible for indexing.
LinksTotal links discovered, including internal and external links.
Core Web VitalsWebsite performance indicators related to loading, responsiveness, and visual stability.
Crawled ResourcesResources discovered during the scan, including images, JavaScript, and other website files.


The Priority Items area helps identify issues that may require attention first. Each item displays its priority and affected page count. Select View Actions to review the associated action items.


The Overview also provides shortcuts to detailed reports:


  • Review Pages: Opens the Pages view from Crawl and Indexability.

  • Review Links: Opens the Links view.

  • View Resources: Opens the Resources view.



Understanding the Pages Report


The Pages report provides a detailed view of the URLs discovered during the website crawl. It helps you identify pages with SEO issues and understand their indexing eligibility and HTTP response status.


The report summarizes crawled pages, pages with issues, indexable pages, and non-indexable pages.


FieldWhat It Means
URLThe address of the crawled webpage.
Issues FoundThe number of SEO issues detected on the page, including errors, warnings, and notices.
TrafficThe traffic figure displayed for the page.
HTTP Status CodeThe response returned by the server, such as 200 (successful) or 404 (not found).
IndexableIndicates whether the page is eligible for indexing. This does not guarantee that a search engine has indexed it.
TitleThe page's title.
Canonical URLThe URL identified as the preferred version of the page.


In addition to these, users can choose from other customizable fields to display the data most relevant to their needs.




Review pages with errors or a non-indexable status to understand whether important website content may be affected.


Select View Actions to open the related SEO action items.




Understanding the Links Report


The Links report shows how pages on your website connect to other pages and external websites. It helps identify broken links and linking issues that may affect navigation or content discovery.


The summary displays Total Links, Internal Links, External Links, and Nofollow Links.


The detailed table includes:


FieldWhat It Means
Destination URLThe page or resource the link points to.
Source URLThe page where the link was found.
Status CodeThe HTTP response of the linked destination.
Link TypeThe type of link identified during the crawl.
Link ScopeWhether the link is internal or external.
Anchor TextThe clickable text used for the link.
Anchor TypeThe type of anchor associated with the link.
Follow/NofollowIndicates whether the link carries a nofollow instruction.


Additional fields, including source-page indexing signals, may be available through the table's column settings.


How to interpret the results: Review links returning error status codes to identify destinations that may be broken or unavailable. Check the source and destination URLs to understand where the issue occurs.


You can add or remove table columns to focus on the information you need. Select View Actions to review related recommendations.




Understanding the Resources Report


The Resources report identifies files discovered while crawling your website, including images, CSS stylesheets, and JavaScript files. Reviewing these resources helps you identify files that may be unavailable or require further performance investigation.


The summary includes:


  • Total Resources: All resources discovered during the crawl.

  • Images: Image resources found on the website.

  • CSS: Stylesheet resources used by website pages.

  • JavaScript: JavaScript files used by website pages.


The detailed table provides information such as:


FieldWhat It Means
URLThe address of the resource.
Source URLThe webpage associated with the resource.
TypeThe resource type, such as an image, CSS, or JavaScript file.
Status CodeThe HTTP response returned when the resource was requested.
ActionsAvailable actions associated with the resource.


Review resource status codes to identify files that failed to load. Resource findings can also help you investigate performance-related issues, although a resource's presence alone does not mean it is slowing the website.


You can customize the table by adding or removing columns.


Understanding SEO Audit Action Items


The Actions view brings together SEO issues identified during the audit and the recommendations associated with them. Issues are organized by category, with details that help you understand their severity, available fix options, and resolution status.


Understanding Action Item Categories


Each category groups issues affecting a particular area of website SEO.


CategoryIssues Covered
Crawlability and IndexingSearch engine access and indexing issues.
RedirectsURL redirect issues.
Meta Tags & DescriptionsPage titles, descriptions, and metadata.
Content and StructurePage content, headings, and structure.
Speed and PerformanceLoading and performance issues.
External LinkingLinks to external websites.
Images and MediaImage and media-related issues.
CSS ResourcesWebsite stylesheet issues.
Internal LinkingLinks between pages on your website.




Understanding Action Item Details


Each action item includes information about the detected issue and its current state.


FieldWhat It Means
SEO IssueThe problem identified during the audit.
SeverityThe issue's priority, such as Error, Warning, or Notice.
Fix TypeThe type of correction or assistance available.
StatusWhether the issue remains open, has been resolved, or has been dismissed, as applicable.
Detected OnWhen the issue was identified.
Resolved OnWhen the issue was marked resolved, if applicable.


Select View Details on an action item to examine the individual issue and its recommendation.


Understanding Fix Types and Statuses


The Fix Type indicates how an issue can be addressed:


  • Auto Fix: The system automatically generates a recommended fix for the identified issue and allows users to apply it directly to the affected asset, such as a website or funnel.

  • Assisted Fix: The system requires user input to determine the appropriate fix. Once the user provides the necessary information or value, the system helps apply the change directly to the website or funnel.

  • Manual Fix: The system generates a recommended fix but does not currently support applying it automatically. Users can copy the recommendation and manually implement it on their website or funnel.

  • Advisory: The system cannot determine the exact value needed to resolve the issue or apply the fix automatically. Instead, it provides general guidance to help users identify the appropriate solution and implement it themselves using their website or funnel builder.


After completing a manual correction, the Actions view allows you to mark the item as Resolved or Dismissed, as appropriate. Resolution status helps distinguish items that have been addressed from those still requiring attention.


When deciding what to address first, consider the Severity, the affected pages, and the recommendation details. 

Higher-severity issues affecting important website pages generally deserve attention before lower-severity optimization notices.
