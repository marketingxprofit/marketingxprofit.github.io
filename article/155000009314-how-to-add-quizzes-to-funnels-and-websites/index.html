How to Add Quizzes to Funnels and Websites

MxP lets you add Quizzes directly to Funnels and Websites using the native Quiz Element. You can create a new Quiz, select an existing one, or edit it without leaving the page builder. No embed codes are required. This article explains how to add, configure, and publish a Quiz on your page.

What is the Quiz Element in Funnels and Websites?


The Quiz Element lets you place an interactive Quiz directly on a Funnel step or Website page.

For example, you can add a lead qualification Quiz to collect visitor information and learn more about potential customers.


Unlike the previous embed-code process, the native Quiz Element lets you add and manage Quizzes directly within the page builder.

How to Add a Quiz to a Funnel or Website


The native Quiz Element lets you place a Quiz directly on your page without copying an embed code. Follow these steps to add a Quiz and review it before publishing.


Step 1: Open the Page Builder

  1. Go to Sites → Funnels or Sites → Websites.

  2. Open the Funnel or Website you want to edit.

  3. Select the page or Funnel step and open its builder.


Step 2: Add the Quiz Element

  1. Open Quick Add.

  2. Search for Quiz.

  3. Drag the Quiz element onto your page.


Step 3: Create or Select a Quiz


Choose one option:

Create a New Quiz

  1. Select Create New Quiz.

  2. Build your Quiz in the Quiz Builder.

  3. Save your Quiz.


Use an Existing Quiz

  1. Select Add Existing Quiz.

  2. Choose the Quiz you want to display.


Step 4: Configure the Quiz Element

  1. Select the Quiz Element on your page.

  2. Under General → Element Options, confirm the correct Quiz is selected.

  3. Review the available Styles and Button Actions settings.



Step 5: Edit the Quiz if Needed

  1. Click Edit Quiz.

  2. Update the Quiz content in the popup.

  3. Click Save.

  4. Close the popup to return to the page builder.


Step 6: Preview and Publish

  1. Preview the page to confirm the Quiz displays correctly.

  2. Test the Quiz questions and completion experience.

  3. Check its appearance on desktop and mobile layouts.

  4. Save any pending page changes.

  5. Click Publish when your page is ready.

Tip: Test the Quiz's submission message or redirect before sharing the page.

Understanding the Quiz Element


The Quiz Element is available in the Funnel and Website Builders.

You can find it by searching for Quiz in Quick Add or by opening Forms, Surveys And Quizzes in the element menu.

Once you add the element, the selected Quiz appears on your page.



Creating or Selecting a Quiz


You can create a new Quiz or reuse one you have already built.


Under Forms, Surveys And Quizzes, select:

  • Create New Quiz: Open the Quiz Builder to create a Quiz.

  • Add Existing Quiz: Choose a Quiz from your existing collection.


Both options are available without leaving the Funnel or Website Builder.


Editing a Quiz in the Page Builder


You can edit Quiz content directly from the Funnel or Website Builder.

Select the Quiz Element and click Edit Quiz in the settings panel. The Quiz Builder opens in a large popup where you can update questions, settings, and other Quiz content.

Save your changes to return to the page builder.



Note: If the same Quiz appears on multiple pages, confirm how edits affect its other placements before making changes.


Configuring Quiz Element Settings


The Quiz Element settings control which Quiz appears on your page and provide options for its appearance and behavior.


SettingPurpose
GeneralManage the element name and selected Quiz
StylesAdjust available appearance settings
Element OptionsSelect the Quiz to display
Edit QuizOpen the Quiz Builder
Button ActionsConfigure the available redirect behavior


The Button Actions dropdown includes Use action from Quiz Builder.



Important: Verify how element-level Button Actions interact with the Quiz Builder's submission settings before relying on a particular redirect behavior.


Managing Quiz Submissions and Results


The Quiz Builder manages the questions, scoring, results, submissions, and notifications associated with your Quiz.

You can review responses under Submissions and configure supported Quiz results to work with CRM custom fields or Workflows.


For detailed configuration, see the Quiz Builder Guide.

Frequently Asked Questions


Q: Do I need an embed code to add a Quiz?

A: No. Use the native Quiz Element to add a Quiz directly to a supported Funnel or Website page.


Q: Can I use an existing Quiz?

A: Yes. Select Add Existing Quiz or choose it from the Quiz Element settings.


Q: Can I create a Quiz without leaving the page builder?

A: Yes. Select Create New Quiz to open the Quiz Builder within the page-building experience.


Q: Can I edit a Quiz after adding it?

A: Yes. Select the Quiz Element and click Edit Quiz.


Q: Can I use the same Quiz on multiple pages?

A: You can select an existing Quiz for another page. Confirm how changes affect other placements before editing a shared Quiz.


Q: Where can I change Quiz scoring and results?

A: Use the Quiz Builder. See How to Set Up Quiz Scoring, Categories, and Result Pages.


Q: Where can I view Quiz submissions?

A: Open the Quiz Builder and select Submissions.


Q: Can I still use an embed code?

A: Yes. Traditional embed codes remain useful for other supported website integrations.


Q: Can I configure what happens after someone submits a Quiz?

A: Yes. Review the Quiz Builder's submission settings and the element's Button Actions, then test the completion behavior.
