Timezone Adaptation in Countdown Timers
Timezone Adaptation adjusts countdown timer deadlines based on the contact or visitor’s timezone. Emails use contact timezone data when available, while funnels and websites use the visitor’s IP-detected timezone. If timezone data is unavailable, the timer uses its configured timezone as the fallback.
What You'll Learn

Learn how timezone adaptation determines the timezone used for email, funnel, and website timers, how the fallback timezone works, how to enable the setting, and when to use localized deadlines.

What Is Timezone Adaptation in Countdown Timers?

Use Timezone Adaptation when a countdown timer should follow the viewer’s local timezone instead of always using the timezone selected during timer setup. The configured timer timezone remains the fallback when MxP cannot determine the contact or visitor timezone.

2

How Timezone Is Determined

The timezone source depends on where the countdown timer is displayed.

PlacementTimezone SourceFallback
EmailContact timezoneTimer’s configured timezone
Funnel / WebsiteIP-detected visitor timezoneTimer’s configured timezone

Fallback behavior: If contact timezone or IP-detected timezone data is unavailable, MxP uses the timezone selected during timer setup.

3

How To Enable Timezone Adaptation

For more information on creating a countdown timer, see Getting Started with Countdown Timer.

  1. Go to Marketing → Countdown Timersand open the countdown timer you want to update, or create a new one.
  2. In the timer settings, select the Time zonethat should be used as the fallback timezone.
  3. Check the Adapt to Contact Time Zonebox.
  4. Save the timer. When the timer is used in a supported email, funnel, or website placement, the applicable timezone logic is used.

    For placement instructions, see Using Countdown Timers in Emails and How to Use Countdown Timers in Funnels.

4

When to Use Timezone Adaptation

Enable Timezone Adaptation when the deadline should occur at the same local clock time for each viewer. If everyone must reach the deadline at the same absolute moment, review the timer configuration before enabling timezone adaptation.

5

Frequently Asked Questions

Q: Does the selected timezone still matter after enabling Adapt to Contact Time Zone?
Yes. The selected timezone remains important because it is used as the fallback when contact or visitor timezone data is unavailable.
