How to Set Up a Custom Domain for Prospecting Marketing Audit Reports

MxP allows agencies to share Prospecting Marketing Audit Reports using their own custom API domain instead of the default domain. This helps maintain consistent agency branding when prospects open shared reports. You can select an existing API domain from Prospecting Report settings without additional DNS configuration.

How to Set Up a Custom Domain for Prospecting Reports


Custom report domains use the API domain already configured in your agency's White Label settings. Once selected, newly shared Marketing Audit Reports automatically use your branded domain without changing the existing sharing process.


  1. Go to Agency View → Labs and enable the custom report domain feature.

  2. Navigate to Settings → Company → White Label → API Domain and make sure an API domain is configured. If you haven't configured one, follow the API Domain setup guide.

  3. Go to Agency → Prospecting → Settings → Report settings.

  4. Under Report domain, select Custom domain and choose your configured API domain from the dropdown. Your selection saves automatically.

  5. Open a Prospecting Marketing Audit Report and share it using the existing sharing options. Newly shared report links will now open using your selected domain.

Important Information About Custom Report Domains


The Report domain setting applies across your agency and determines which domain is used for newly shared Marketing Audit Reports. Understanding how domain changes affect existing links helps ensure a consistent sharing experience.


  • Default Domain: You can continue using the default domain by selecting Default domain in Report settings.

  • Existing Report Links: Links shared before switching domains will continue working on their original domain. Only newly shared links use the selected custom domain.

  • Agency-Wide Setting: The selected report domain applies across your agency.

  • Availability: Custom report domains are available for both free and paid Prospecting.

  • Existing API Domains: You do not need additional DNS configuration if your API domain is already configured in White Label settings.
