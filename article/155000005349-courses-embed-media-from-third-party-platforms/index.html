Courses - Embed Media from Third-Party Platforms

Third-party media embedding lets you add externally hosted video or audio directly to a MxP course lesson using an iframe embed code. This article shows you how to embed supported video and audio platforms in course lessons, including the required steps and best practices.

What is Third-Party Media Embedding in Courses?


Third-party media embedding lets you add externally hosted video or audio directly to a MxP course lesson using an iframe embed code. This allows learners to view supported media within the lesson without requiring you to upload the media file to MxP.


You can embed videos, podcasts, demos, and audio from supported third-party platforms directly into your course lessons.

Supported Platforms


We currently support media embedding from:


For Video:


  • YouTube
  • Vimeo
  • Loom


For Audio:


  • SoundCloud
  • Wistia
  • Spotify
  • Mixcloud


You can use iframe embed code from these platforms.

How to Embed Media from a Third-Party Platform


Adding the embed code to the lesson media area allows MxP to display the externally hosted media directly within the course lesson.


  1. Go to Memberships > Courses > Products.



  2. Open the course you want to edit.

  3. Open the lesson/module where you want to add the media.

  4. In Lesson Media or Description, select Embed Media.



  5. Copy the iframe embed code from the supported third-party platform.

    YouTube example:

    • Open the YouTube video.
    • Click Share.
    • Select Embed.
    • Copy the iframe code.



  6. Return to the course and paste the iframe code into the Embed Media field.

  7. Click Embed.

  8. Confirm that the media appears correctly in the lesson.

  9. Save and publish your lesson as needed.

Copyright & Usage Compliance


Reminder: You are responsible for ensuring you have the right to embed third-party content.


Before embedding, confirm:


  • The content is public or has permission for sharing.
  • You have the legal right to display the content.
  • You are complying with the source platform’s terms of service and usage guidelines.
  • Do not embed content that’s private, licensed without permission, or marked as non-shareable.

Best Practices


  • Always test your post using the preview feature to ensure embeds load correctly.

  • Avoid shortened or redirected links; use official embed codes.

  • Educate your team on content licensing to avoid violations.

Frequently Asked Questions


Q: Can I embed media from any third-party platform?
No. Use iframe embed code from one of the supported video or audio platforms listed above.


Q: Do I need to upload the video or audio file to MxP first?
No. The media remains hosted on the third-party platform and is displayed in the lesson through its iframe embed code.


Q: Where do I get the iframe embed code?
The process varies by platform. Look for the platform's sharing or embedding options. For example, YouTube provides the code under Share > Embed.


Q: What should I do if the embedded media does not display correctly?
Confirm that you copied the official iframe embed code from a supported platform and that the source media can be shared publicly.
