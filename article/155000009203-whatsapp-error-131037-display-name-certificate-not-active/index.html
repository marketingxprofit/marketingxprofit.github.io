WhatsApp Error #131037 — Display Name Certificate Not Active

WhatsApp Error #131037 — Display Name Certificate Not Active

How to resolve the display name certificate error when sending WhatsApp messages.

Error #131037: The display name certificate for this phone number is not currently active. Messages cannot be sent until the certificate is applied to the number.

Table of Contents

What Causes This Error How to Resolve It If the Error Persists Frequently Asked Questions

What Causes This Error

Error #131037 occurs when the display name certificate for your phone number is not currently active on the number being used for sending.

Even when a display name shows as Approved in your account, the certificate still needs to be applied to the phone number before messages can be sent. For Cloud API numbers, this is done through re-registration — a standard step that activates the certificate on the number.

✘Display name shows as Approved but the certificate has not been applied to the number.
✘Re-registration was not completed after the display name was approved.

How to Resolve It

Re-register your phone number using the WhatsApp Cloud API. This activates the display name certificate on the number and is a standard step required for the certificate to take effect.

1

Use the Correct PIN

►If two-step verification is enabled: use your existing 6-digit two-step verification PIN.
►If two-step verification is not enabled: you may set a new 6-digit PIN for this registration.
2

Retry Sending

Once re-registration completes successfully, retry sending your template message. The error should no longer appear.

If the Error Persists

If you still receive error #131037 after re-registration, gather the following details and contact our support team so we can investigate further:

►The display name currently submitted for this number, and the date it was approved.
►Whether two-step verification is enabled on the number.
►Whether the error occurs for all templates or only specific ones.
When contacting support, include your Location ID, phone number ID, the exact error message, and a screenshot or recording of the issue to help us investigate quickly.

Frequently Asked Questions

Q: My display name shows as Approved. Why am I still getting this error?

An approved display name and an active certificate are two separate things. The certificate must be applied to the phone number through re-registration before messages can be sent. Re-registration is a required step even when the display name shows as approved in your account.

Q: Will re-registration affect my existing templates or contacts?

No. Re-registration only activates the display name certificate on the phone number. It does not affect your approved templates, contact data, or any other account settings.

Q: What PIN should I use for re-registration?

If two-step verification is enabled on the number, use your existing 6-digit two-step verification PIN. If two-step verification is not enabled, you may set a new 6-digit PIN during re-registration.

Q: Does this error affect all templates or just specific ones?

Error #131037 is related to the phone number's certificate, not individual templates. It typically affects all outgoing messages from that number. If the error only appears for specific templates after re-registration, contact support with the details listed above.

Q: Where can I find my Phone Number ID?

Your Phone Number ID can be found in Meta WhatsApp Manager under Account tools → Phone numbers. It is also visible in the CRM under Settings → WhatsApp in your sub-account.
