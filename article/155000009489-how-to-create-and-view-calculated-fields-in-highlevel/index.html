How to Create and View Calculated Fields in MxP

Calculated Fields automatically calculate values using information already stored in your CRM. You can use them to track lead scores, measure time between dates, or count down to upcoming renewals without manually updating results.

You create Calculated Fields on the web and can view their read-only values in Contacts and Opportunities on mobile.

How to Create a Calculated Field

  1. In your MxP sub-account, go to Settings > Custom Fields.

  2. Select Contact or Opportunity, then open the Fields tab.

  3. Click Create field and select Calculated.

  4. Enter a field name and select a folder.

  5. Choose a calculation type:

    • Custom formula: Calculate values using numbers, text, dates, or conditions.

    • Time between: Measure the time between two dates.

    • Time since: Calculate time elapsed since a date.

    • Time until: Calculate time remaining until a future date.

  6. Select an output type: Number, Boolean, Text, Date, or Date-time.

  7. Select your source fields or enter a formula. Configure the number format if needed.

  8. Preview the result using sample values, then save the field.

How to View Calculated Fields on Mobile

Update your MxP mobile app to version 4.25.0 (863) or higher.


View in Contacts

  1. Open the mobile app and go to Contacts.

  2. Select a contact and tap Details.

  3. Find the Calculated Field in its assigned folder.

View in Opportunities

  1. Go to Opportunities > Pipelines.

  2. Select an opportunity and open Details.

  3. Find the Calculated Field.

To display a Calculated Field on opportunity cards:

  1. Go to Opportunities > Settings > Customize Cards.

  2. Select the Calculated Field you want to display.

  3. Tap Save.

[Screenshot: Calculated Field displayed in mobile Opportunity Details.]

Refresh or Copy a Calculated Value

  • Refresh: Tap the refresh icon beside the field to retrieve its latest value.

  • Copy: Long-press the calculated value to copy it.

Calculated Fields display a lock icon because their values cannot be edited manually.

Important Notes

  • Calculated Fields are created and configured on the web.

  • Values automatically recalculate when their source fields change.

  • Calculated values cannot be manually edited or overwritten through imports or workflows.

  • Date and time calculations use your sub-account's time zone.

  • Formula changes are managed on the web and do not require a new mobile app release.
