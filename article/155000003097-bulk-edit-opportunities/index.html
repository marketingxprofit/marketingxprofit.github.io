Bulk Edit Opportunities

Bulk Edit Opportunities lets you update multiple opportunity records at the same time instead of editing each one individually. You can select opportunities from Grid/Card View or List View, choose the fields you want to change, and apply those updates in a single action. This article explains how bulk editing works, how to select opportunities, and how to update multiple opportunity fields efficiently.

What is Bulk Editing Opportunities?


Bulk Edit Opportunities helps you update shared details across multiple opportunity records at once. This is useful when several opportunities need the same pipeline, stage, status, owner, value, source, or other opportunity information updated without opening each record individually.


You can bulk edit selected opportunities from either Grid/Card View or List View. List View also provides additional flexibility when you need to review or work with opportunities across All Pipelines.

Key Benefits of Bulk Editing Opportunities


  • Save time: Update multiple opportunities at once instead of editing each record individually.

  • Maintain consistency: Apply the same changes across selected opportunity records.

  • Flexible selection: Choose specific opportunities from Grid/Card View or List View.

  • Update multiple fields: Change several opportunity details within the same bulk edit.

  • Manage broader record sets: Use List View when you need to work with opportunities across All Pipelines.

How to Bulk Edit Opportunities


Selecting the right opportunities before making changes helps ensure that updates are applied only to the intended records. MxP supports bulk editing from both Grid/Card View and List View, allowing you to choose the view that best fits the number and type of opportunities you are managing.


Step 1: Navigating to Opportunities


  1. Log in to your account.

  2. From the left navigation menu, click Opportunities.

  3. Select the pipeline containing the opportunities you want to update.

    If you need to work with opportunities across All Pipelines, switch to List View.

  4. Choose how you want to select the opportunities.



Step 2: Selecting Opportunities in Grid/Card View


Grid/Card View is useful when you want to select opportunities visually within specific pipeline stages.

  1. Remain in Grid/Card View.

  2. Select the opportunities you want to update from the applicable pipeline stages.

  3. After selecting the opportunities, click Edit.



Step 3: Selecting Opportunities in List View


List View makes it easy to select individual records or larger groups of opportunities from a table.


  1. Switch to List View.

  2. To select specific opportunities, click the checkbox beside each opportunity you want to edit.

  3. To select all displayed opportunities, click the checkbox beside Opportunities at the top of the list.

  4. Click the checkbox again if you need to deselect the selected opportunities.

  5. After making your selection, click Edit.



Step 4: Editing the Selected Opportunities


The Bulk Edit window lets you choose which opportunity fields should be updated across the selected records. You can add one or multiple fields depending on the changes you need to make.


  1. In the Bulk Edit window, open Opportunity Details.

  2. Select the fields you want to update.

    Available fields can include:

    • Pipeline

    • Stage

    • Status

    • Value

    • Owner

    • Follower

    • Source

    • Expected Close Date

    • Lost Reason

    • Other available opportunity fields

  3. Enter or select the new value for each field you are updating.

  4. Add additional fields if you want to update more than one opportunity detail at the same time.


    For example, you could move the selected opportunities to a different pipeline, choose the appropriate stage, and update their status within the same bulk edit.

  5. Review your changes to confirm that the correct opportunities and field values have been selected.

  6. Click Save.

Frequently Asked Questions


Q: Can I bulk edit opportunities from both Grid/Card View and List View?

Yes. You can select and bulk edit multiple opportunities from either view. Grid/Card View is useful for selecting opportunities visually within pipeline stages, while List View provides a table-based selection experience.


Q: Can I bulk edit opportunities across all pipelines?

Yes. Switch to List View and select All Pipelines when you need to review and work with opportunities across multiple pipelines.


Q: Can I select only certain opportunities for a bulk edit?

Yes. You do not need to select every opportunity. Use the individual selection controls in Grid/Card View or the checkboxes in List View to choose only the records you want to update.


Q: Can I move multiple opportunities to another pipeline or stage?

Yes. Add the Pipeline or Stage field in the Bulk Edit window and select the destination you want to apply to the selected opportunities.


Q: Can I change more than one field during the same bulk edit?

Yes. You can add multiple fields in the Bulk Edit window and configure each field before clicking Save.
