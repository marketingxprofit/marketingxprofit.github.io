How to Use the WhatsApp Template Library

How to Use the WhatsApp Template Library

Create WhatsApp message templates from prebuilt content instead of writing every message from scratch.

The WhatsApp Template Library lets you browse templates, filter by category, industry, and language, preview messages, and customize the content before submitting to Meta.

Important: Prebuilt templates are not pre-approved for your account. Selecting one creates a new template in your sub-account, which must receive its own Meta approval before you can send it.

What Is the WhatsApp Template Library?

The WhatsApp Template Library provides ready-made content sourced from templates that have previously been approved by Meta. You can use this content as a starting point, make changes for your business, and submit your version through the standard WhatsApp template creation process.

When creating a template, you can choose from three options:

Creation Option
How It Works
Blank Template
Start with an empty form and write your own message.
AI Template
Use AI assistance to generate template content, then review and edit it.
Use Prebuilt Template
Select existing content from the Template Library and customize it before submission.

The library helps you spend less time drafting common messages while keeping control over the final content. It does not bypass Meta's review or guarantee approval.

Before You Begin

✓Your sub-account has an active WhatsApp subscription and has completed WhatsApp onboarding.

✓You have any business details, media, links, and sample values ready for your message.
✓You have permission to create and edit WhatsApp templates. An administrator can review the Create/edit WhatsApp templates permission in your user's Roles & Permissions settings.
The steps below apply when Use Prebuilt Template is available in your sub-account.

How to Create a WhatsApp Template from the Library

1

Open WhatsApp Templates

From the relevant sub-account, navigate to Settings → WhatsApp → Templates and click Create Template.

Choose Use Prebuilt Template to open the Template Library in a modal without leaving the WhatsApp creation flow.

2

Browse and Filter Templates

Use the library's search and sorting options to find suitable content. The left-hand filter panel helps narrow your results:

Filter
Purpose
Category
Find templates in the available categories.
Industry
Find content relevant to your business or industry.
Language
Find templates available in the language you need.

You can also favorite templates for easier access later. When your search returns no suitable results, broaden the search or remove some filters.


3

Preview the Message

Select a template to view its WhatsApp message preview. Review how the message is presented, including its header, body, footer, and buttons, where included. Check that the content, language, and intended customer action fit your needs before continuing.

Note: The preview helps you evaluate the message. It is not confirmation that the template is approved for your sub-account.


4

Customize the Template

Selecting a library template pre-fills the creation form. The form remains editable so you can adapt the content before submission. Review the following:

Template Detail
What to Check
Name
Use a name that helps your team identify the template.
Category
Confirm that the category matches the purpose of the message.
Language
Confirm that the selected language matches the message content.
Header
Review the header type and content — this may be text, an image, a video, a document, or a location.
Body
Replace business-specific details and review any personalization placeholders.
Footer
Update or remove wording that does not apply to your business, where supported.
Buttons
Check button labels and associated destinations or actions.

Complete any required fields and provide realistic sample values for variables. Correct any validation errors shown by the builder before submitting.

Important: You are editing your own new template — not changing the original library entry or templates created by other businesses.

5

Submit to Meta

Review the completed template and submit it through the standard template creation flow. Meta reviews the submitted version for content, category, formatting, and policy compliance. Previous approval of the library's source content does not guarantee approval of your submission.

Return to Settings → WhatsApp → Templates to monitor the status. A template marked In Review is still being assessed. If it is rejected, review Meta's reason before making corrections and resubmitting.

6

Use Your Approved Template

Once approved and active, a template created from the library behaves like any other WhatsApp template in your sub-account.

►Workflows — for automated messaging
►Bulk Actions — for sending to a selected audience
►Conversations — for one-to-one communication
Creating or submitting a template does not automatically send it to customers.

How to Save a WhatsApp Template to the Template Library

Agency admins can use the Save Template action to enter the existing Template Library save flow from WhatsApp.

1

Open Settings → WhatsApp → Templates.

2

Locate the template you have created.

3

Open its three-dot menu and select Save Template.

4

Complete the required details in the Template Library save flow.

Important: Saving to the library and obtaining Meta approval are separate actions. Saving content for reuse does not transfer its approval to another sub-account or remove the need for approval when a new WhatsApp template is created from it.

Access and Permissions

The WhatsApp library creation flow uses the existing WhatsApp template management permission. There is no separate WhatsApp library permission to enable.

✓Agency owners, agency admins, and sub-account admins can use the flow within their permitted account access.
✓Agency users and sub-account users need the relevant WhatsApp template management permission.
✘Users without access to the template editor cannot use the library through that creation flow.
Being able to view existing WhatsApp templates does not necessarily mean a user can create or edit them. Review the user's Create/edit WhatsApp templates permission when a creation action is unavailable.

The centrally maintained library content is read-only. Authorized users can customize their own template during creation, but they cannot directly modify the original library entry.

Frequently Asked Questions

Q: Are library templates already approved for my account?

No. Their source content has previously passed Meta review, but selecting a library template creates a new template in your sub-account. Your version requires its own approval — even when you do not change the wording.

Q: Does using the library guarantee faster Meta approval?

No. The library reduces the work involved in preparing the message. It does not provide a separate approval process or a guaranteed review timeframe.

Q: Can I change the content before submitting?

Yes. The selected template prefills an editable form. Review and customize the content, business details, variables, and buttons before submission.

Q: Will my changes affect the original library template?

No. Changes made during creation apply to your new template. They do not modify the centrally maintained library entry.

Q: What happens when I cannot find a suitable template?

Use Blank Template to write your own message or AI Template for assistance drafting it. The library is an additional creation option, not a replacement for either existing method.

Q: Is an approved template required for every WhatsApp reply?

No. Free-form messages can be sent within the active 24-hour customer service window following a customer's message. Approved templates are required for messaging outside that window. The library changes how you prepare templates — it does not change these messaging rules.
