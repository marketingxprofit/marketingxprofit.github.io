What is Ask AI Memory?

Ask AI Memory helps MxP provide more personalized and relevant AI responses by remembering useful details about you, your business, and your preferences across conversations. Memory Settings gives you visibility and control over saved memories, including tools to search, delete, clear, and import information from another AI assistant. In the MxP mobile app, you can manage these details directly from Ask AI instead of repeatedly providing the same context in new conversations.

What is Ask AI Memory?


Ask AI Memory stores useful context learned or saved from your interactions with Ask AI so that relevant information can be reused in future conversations. Unlike Chat History, which preserves previous conversations for reference, saved memories provide reusable context that Ask AI can apply when responding to new requests.


For example, saved memories might include details about your business, your role, preferences, or recurring instructions. Keeping these memories accurate helps Ask AI provide responses that better reflect the context in which you work.

Key Benefits of Ask AI Memory


Managing saved memories gives you greater control over the context Ask AI can use in future conversations. Accurate memories can reduce repetitive prompting while helping keep important business and preference information available when you need it.

  • Less repetitive prompting: Ask AI can reuse relevant saved context instead of requiring you to explain the same business details or preferences in every conversation.

  • Greater control over saved context: Review what Ask AI remembers and remove individual details that are incorrect, outdated, or no longer useful.

  • Faster AI migration: Import memories from another AI assistant to bring existing context into Ask AI instead of rebuilding it gradually through new conversations.

  • Easier memory management: Search saved memories to quickly locate specific information and clear memories that you no longer want to retain.

  • Context separation: Memory context is kept appropriately scoped so information associated with one working context does not unintentionally become context for another.

Viewing and Searching Saved Memories


The Saved Memories screen provides a centralized view of the information Ask AI has retained. Reviewing this list periodically can help you keep stored context relevant and identify information that should be updated or removed.


The header displays the number of saved memories currently available. Each memory is displayed in full, allowing longer entries to wrap across multiple lines rather than being cut off.


To find a specific memory:

  1. Open the Saved Memories screen.

  2. Tap the Search field.

  3. Enter a word or phrase related to the memory you want to find.

  4. Review the results as the list filters while you type.

  5. Clear the search field to return to the complete list.


You can also use the available sort control to change the order in which memories appear.

Deleting Saved Memories


Removing outdated or incorrect memories helps keep the context available to Ask AI accurate. You can remove one memory without clearing the rest of your saved information, or clear all saved memories when you want to start over.


Delete an Individual Memory


Deleting an individual memory is useful when a particular detail is incorrect, outdated, or no longer relevant while the rest of your saved context remains useful.

  1. Find the memory you want to remove.

  2. Tap the trash icon on that memory's row.

  3. The memory is removed, and a confirmation message appears.


You can continue deleting additional memories without waiting for each confirmation message to disappear.

Clear All Memories


Clearing all memories removes the saved context associated with the current memory scope. Use this option when you want to remove the entire saved-memory set rather than deleting entries individually.

  1. Open Saved Memories.

  2. Tap the trash icon in the header.

  3. Review the confirmation dialog.

  4. Confirm that you want to clear the saved memories.

  5. MxP removes the memories and confirms how many entries were deleted.

Deleting saved memories manages Ask AI's reusable memory context. Chat History is a separate feature used to access previous Ask AI conversations.

Importing Memories From Another AI Assistant


Importing memories lets you bring useful context from another AI assistant into Ask AI. This can be especially helpful when another assistant already has substantial information about your business, role, preferences, clients, or working style.


The importer uses a two-step workflow: first, MxP provides a prompt for collecting the information from the other AI assistant; then you paste the resulting response back into Ask AI.


Ask AI Memory supports importing up to 100 memories at once.


Step 1: Export Context From Your Other AI Assistant

  1. Open Saved Memories.


  2. Tap Import memories.


  3. Review the provided export prompt.

  4. Tap Copy to copy the prompt. You can also select Show more to read the full prompt.


  5. Open the AI assistant that already has the information you want to transfer, such as ChatGPT or Claude.

  6. Paste and run the copied prompt.

  7. Copy the assistant's complete response.


Step 2: Import the Response Into Ask AI

  1. Return to the Import memories workflow in the MxP mobile app.

  2. Paste the complete response from the other AI assistant into the provided field.

  3. Tap Add to memory.


Ask AI processes the pasted response and converts the relevant entries into saved memories. The importer removes common export formatting, such as dates, bullets, and headers, before saving individual memory entries.

Memory Scope and Sub-Accounts


Understanding memory scope helps prevent context from different working environments from being mixed together. When working across sub-accounts, MxP loads the memories applicable to the current context rather than treating every sub-account as one shared memory environment.


When you switch sub-accounts, the Saved Memories screen reloads the memories for the applicable scope. This helps keep client and business context separated when you work across multiple sub-accounts.


Review the current sub-account before deleting, clearing, or importing memories so that you manage the intended memory set.

Ask AI Memory vs. Chat History


Memory and Chat History serve different purposes in Ask AI. Understanding the difference makes it easier to decide whether you need to manage reusable context or simply return to an earlier conversation.

  • Saved Memories contain reusable information that can provide context for future Ask AI conversations.

  • Chat History lets you return to previous Ask AI conversations and review earlier messages.


Removing a saved memory is therefore different from managing an existing conversation in Chat History.


Ask AI Memory vs. Skills


Memories and Skills can both make Ask AI more useful, but they serve different purposes. Memories provide reusable context about you and your work, while Skills provide reusable instructions or workflows for completing particular types of tasks.


Use Memory for information Ask AI may need to know across conversations, such as business context, preferences, or recurring details.


Use Skills when you want Ask AI to follow defined instructions or a repeatable workflow for a particular task.

For more information, see Ask AI Skills and Connectors.

How To Set Up and Manage Ask AI Memory on Mobile


Properly reviewing and managing saved memories keeps the context available to Ask AI relevant to your current work. The MxP mobile app provides direct access to Memory Settings from Ask AI, where you can review existing information before deciding whether to search, delete, clear, or import memories.

  1. Open the MxP mobile app.

  2. Tap Ask AI.

  3. Open Chat History.

  4. Tap the memory icon in the header. The icon appears before New chat.


  5. Review the memories currently saved.

  6. Use Search or the sort control to locate information when needed.

  7. To remove one memory, tap its trash icon.

  8. To remove all memories in the applicable scope, tap the trash icon in the header and confirm the action.

  9. To transfer context from another AI assistant, tap Import memories.


  10. Copy the provided prompt and run it in the other AI assistant.

  11. Copy the assistant's response and return to MxP.

  12. Paste the complete response into the importer.

  13. Tap Add to memory.

Frequently Asked Questions


Q: Does deleting a saved memory delete my Ask AI conversation?
No. Saved Memory and Chat History serve different purposes. Removing a saved memory removes that reusable memory entry rather than functioning as a Chat History deletion control.


Q: Can I import information from ChatGPT or Claude?
Yes. The import workflow provides a prompt that you can run in another AI assistant. Copy that assistant's response and paste it back into MxP to convert the relevant information into Ask AI memories.


Q: How many memories can I import at once?
Ask AI Memory supports importing up to 100 memories at once.


Q: Do I need to manually remove bullets and dates from an imported response?
The mobile importer is designed to parse the export and remove common formatting such as dates, bullets, and headers before saving individual memory entries.


Q: What happens to my memories when I switch sub-accounts?
The Saved Memories screen reloads the memories applicable to the selected sub-account context, helping keep separate working contexts from being mixed together.


Q: Should I use a Memory or a Skill for reusable instructions?
Use Memory when Ask AI needs reusable context about you or your work. Use Skills when you want Ask AI to follow defined instructions or workflows for particular tasks.


Q: Does Ask AI use every saved memory for every response?
No. The existing Memory V1 implementation uses the 20 most recent memories in AI requests. Saved information therefore should remain relevant and useful rather than being treated as an unlimited prompt containing every memory.
