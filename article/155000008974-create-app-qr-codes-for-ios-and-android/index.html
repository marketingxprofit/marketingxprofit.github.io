Create App QR Codes for iOS and Android

App QR Codes let you use one QR code to direct people to the appropriate app destination based on their device. iOS users can open the Apple App Store, Android users can open the Google Play Store, and other or unidentified devices can use an optional fallback URL. This guide explains how App QR Codes work and how to create one in MxP.

What You'll Learn

Learn how App QR Codes route visitors based on device type, configure App Store and Play Store destinations, add an optional fallback URL, customize the QR code, and test it before publishing.

What Is an App QR Code?

An App QR Code is a QR Code type that automatically routes someone to the appropriate destination based on the device used to scan it.

You can configure an App Store URL for iOS users and a Play Store URL for Android users. You can also provide an optional Other Devices URL for unsupported or unidentified devices.

When someone scans the QR code, MxP detects the device and redirects the visitor to the applicable configured destination.

2

Key Benefits of App QR Codes

App QR Codes simplify app promotion by giving multiple device types one scannable entry point while automatically directing visitors toward the destination intended for their device.

  • One QR Code Across Platforms: Promote one code instead of maintaining separate QR codes for iOS and Android.
  • Automatic iOS Routing: Send iOS devices to the configured Apple App Store destination.
  • Automatic Android Routing: Send Android devices to the configured Google Play Store destination.
  • Fallback Support: Add an optional destination for unsupported or unidentified devices.
  • Fewer Download Steps: Direct visitors toward the appropriate destination without requiring a separate page containing multiple app-store choices.
  • Reusable Promotion: Use the same App QR Code across print materials, websites, campaigns, and other promotional channels.
  • Existing Design Controls: Continue using the standard QR Code Builder customization experience.
3

Prerequisites and Limitations

Configure and verify the app destinations before distributing the QR code so each supported device type can reach the intended location when scanned.

  • Have the Apple App Store destination URL available for iOS users.
  • Have the Google Play Store destination URL available for Android users.
  • The Other Devices URL is optional.
  • When configured, the Other Devices URL acts as the fallback for unsupported or unidentified devices.
  • MxP automatically determines the device type after the QR code is scanned.
  • App QR Codes support separate routing for iOS, Android, and other or unidentified devices.
  • The standard QR Code design and customization experience remains available for App QR Codes.
4

How To Set Up an App QR Code

Create the App QR Code from the standard QR Code Builder, assign the destination for each device type, then test the code before distributing it.

  1. From the Sub-Account view, select Sites.
  2. Select QR Codes from the upper navigation.
  3. Click Create QR Code.
  4. Enter a recognizable name for the QR code.
  5. Select App as the QR Code type.
  1. Enter the App Store URL that iOS users should open.
  2. Enter the Play Store URL that Android users should open.
  3. If needed, enter an Other Devices URL for unsupported or unidentified devices.
  1. Click Next to continue to the QR Code design and customization experience.
  2. Customize the QR code using the available design options.
  3. Scan and test the QR code before finalizing it to confirm that the configured destinations open correctly.
  4. Save the QR code when the configuration and design are complete.

Tip: Test the code with both an iOS and Android device when possible. If you configured an Other Devices URL, verify that fallback destination separately as well.

How App QR Code Device Routing Works

MxP determines which configured destination to use after someone scans the App QR Code, removing the need for the visitor to choose between separate iOS and Android links.

Frequently Asked Questions

Q: Do I need separate QR codes for iOS and Android?
No. One App QR Code can contain separate destinations for iOS and Android users.
Q: How does MxP decide which destination to open?
MxP detects the device used to scan the code. iOS devices use the App Store URL, Android devices use the Play Store URL, and other or unidentified devices can use the configured fallback URL.
Q: Is the Other Devices URL required?
No. The Other Devices URL is optional.
Q: What should I use as the Other Devices URL?
Use the URL you want unsupported or unidentified devices to open. The Other Devices URL is optional.
Q: Does the App QR Code use different design options from other QR codes?
No. App QR Codes continue to use the standard QR Code design and customization experience.
Q: Can I use the same App QR Code on printed and digital materials?
Yes. The same App QR Code can be reused across print materials, websites, campaigns, and other promotional channels.
