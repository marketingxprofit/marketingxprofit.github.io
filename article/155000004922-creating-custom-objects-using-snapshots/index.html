Creating Custom Objects using Snapshots

This support doc provides step-by-step instructions on using the Custom Object Support in Snapshots feature. Customers can copy custom object data, including all custom fields and associations, between sub-accounts. 


This article highlights feature benefits, usage instructions, and important limitations, enabling users to easily replicate custom object data across multiple sub-accounts.

What Custom Object Snapshots Include


A Snapshot can include:


  • Custom Objects

  • Custom fields associated with those objects

  • Supported associations between CRM objects


Associations are included automatically when both objects in the relationship are selected for the Snapshot. Contact-to-Contact associations are not supported in Snapshots.


Important: Snapshots copy reusable configuration assets. They do not function as a method for moving live customer records or account history between sub-accounts. 

Before You Begin


Make sure:


  • The source sub-account contains the Custom Objects you want to copy.

  • Your user role has access to Snapshots.

  • The destination sub-account has enough available Custom Object capacity.


All current MxP plans support up to 10 Custom Objects per location. Snapshot imports remain subject to the Custom Object limit in the destination account.


If Load Snapshot is unavailable, verify that Snapshot access is enabled under User → Roles and Permissions from the Agency Dashboard. 


Custom Object Support in Snapshots


You can now include custom objects and all their associated custom fields (not limited to primary fields) within snapshots. This enables you to effortlessly copy custom object data across multiple sub-accounts.


Custom Objects can only be copied between sub-accounts. Direct export of custom objects is not supported

Custom Object Associations


Custom objects are automatically associated with other custom objects or contacts within the snapshot process. Associations are included by default and cannot be modified or deselected during snapshot creation.


Associations between custom objects and other objects (including contacts) will be automatically created or updated. You cannot manually edit these associations during the snapshot process.

How to Copy Custom Objects Between Sub-Accounts


Snapshots let you reuse Custom Object configurations across sub-accounts without rebuilding them manually.

When you include Custom Objects in a Snapshot, MxP can copy the selected objects, their custom fields, and supported associations into another sub-account. 


Custom Object records are not documented as Snapshot assets, so this article does not treat record data as transferable.


1. Navigate to Agency > Account Snapshots > Create Snapshot.


2. Select the custom object you want to include in the snapshot.





3. The selected custom object’s fields and associations (to other custom objects or contacts) will automatically be included.


4. Choose the source and target sub-accounts to complete the snapshot transfer.

Important Limitations


Custom Object Limit per Snapshot:


A snapshot can contain a maximum of 10 custom objects per sub-account. If importing the snapshot would exceed this limit, no custom objects will be created in the target sub-account.

Frequently Asked Questions


Q. Can I copy Custom Objects between sub-accounts?

Yes. Include the Custom Objects in a Snapshot, then load that Snapshot into the destination sub-account. Custom fields and supported associations can be included with the objects.



Q. Do I need the Pro plan to use Custom Objects?

No. Starter, Unlimited, and Pro plans currently support up to 10 Custom Objects per location.



Q. Do Custom Object records transfer with a Snapshot?

Current Snapshot documentation describes Snapshots as tools for copying configuration assets rather than live account records. Do not treat Custom Object record data as part of the Snapshot transfer.



Q. Are associations included automatically?

Supported CRM associations are included automatically when both objects in the relationship are selected. Contact-to-Contact associations are not supported.



Q. Can I load more than one Snapshot into the same sub-account?

Yes. MxP supports loading multiple Snapshots into the same sub-account. Review conflicts carefully when assets overlap.
