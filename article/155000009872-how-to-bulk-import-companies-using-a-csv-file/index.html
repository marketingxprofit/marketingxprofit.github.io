How to Bulk Import Companies Using a CSV File

Company Bulk Import in MxP allows you to create or update multiple Company records using a CSV file. Instead of adding Companies individually, you can upload business information, map fields, handle duplicates, and track import results through a guided process.

What Is Company Bulk Import?


Company Bulk Import allows you to create or update multiple Company records in MxP by uploading a CSV file.

A Company record stores business information such as Company Name, Phone, Email, Website, and Address.


Instead of entering this information manually for each Company, you can upload multiple records at once using a guided four-step process:

Start → Upload → Map → Verify


This feature is useful when moving Company information from another CRM, adding several businesses, or updating existing Company details.

Prerequisites and Labs Enablement


Before importing Companies, ensure the feature is enabled in your MxP account.


How to Enable Company Bulk Import

  1. Open your MxP sub-account.

  2. Navigate to Labs.

  3. Locate Company and Custom Object Import.

  4. Enable the feature.

  5. Navigate to Contacts → Companies and confirm the Import button is available.

Note: According to the feature release, Company Bulk Import is available through Labs. If you cannot find the option, contact your account administrator.


How to Prepare Your CSV File


A CSV file stores information in rows and columns. Each row represents a Company, while each column contains information such as its name, email, phone number, or address.


Before importing, ensure that:

  • Your file is saved in .csv format.

  • The first row contains column headers.

  • Required Company fields are included.

  • Company information is correctly formatted.

  • The appropriate Company ID is included when updating existing records.

  • Any custom Company fields you want to import already exist in MxP.


For example, your CSV file may contain the following columns:

Company NamePhoneEmailWebsite
Acme Technologies1415555198contact@acmetech.comwww.acmetech.com
BluePeak Marketing44207946958hello@bluepeak.comwww.bluepeak.com


Tip: Review your CSV file carefully before importing. Test with a small number of records first, and keep a backup of existing Company information before making bulk updates.


How to Bulk Import Companies


MxP provides a four-step import process to help you upload, map, and verify Company data.

Step 1: Start — Select Companies

  1. Navigate to Contacts → Companies.

  2. Click Import in the upper-right corner.

  3. Select Companies from the available import options.

  4. Click Next.

This opens the Company Bulk Import process.


Step 2: Upload — Add Your CSV File

Upload your CSV file and choose how MxP should handle the imported records.

  1. Upload your prepared CSV file.

  2. Select the preferred import option:

    • Create companies: Create new Company records.

    • Update companies: Update matching existing Company records.

    • Create and update companies: Update matching records and create new Companies when no match is found.

  3. Select the duplicate detection criteria, such as Company ID.

  4. Click Next.

Note: Company ID is used to identify existing Company records during updates. Make sure the correct identifier is included when matching existing Companies.



Step 3: Map — Match CSV Columns to Company Fields

Field mapping determines where information from your CSV file will be saved in MxP.

For example, the Phone column in your CSV should be mapped to the Phone field in Companies.

  1. Review the uploaded CSV columns.

  2. Check the automatically suggested field mappings.

  3. Use the dropdown menus to correct any mappings.

  4. Ensure all required fields are mapped.

  5. Review the Don't update to an empty value option.

  6. Click Next.


Don't update to an empty value

Enable this option to prevent blank cells in your CSV file from replacing information already stored in existing Company records.


For example, if an existing Company has a phone number but the corresponding CSV cell is empty, enabling this option helps preserve the existing phone number.


Step 4: Verify — Review and Start the Import

The Verify step allows you to review your import information before processing begins.

  1. Review the uploaded CSV file.

  2. Confirm that the field mappings are correct.

  3. Check the import and duplicate handling settings.

  4. Click Start Bulk Import.

MxP will begin processing your Company records.

Important: Review your import settings carefully before submission because completed imports cannot be automatically undone.


How to Track Import Progress and Results


After starting the import, you can monitor its progress and review the results through Bulk Actions.


Step 1: Open Bulk Actions – Companies

  1. Navigate to Bulk Actions – Companies.

  2. Find your import using the file name, date, or status.

  3. Review its current status and completion details.


The page displays information such as:

  • Import file name.

  • Operation.

  • Status.

  • User.

  • Created and completed dates.

  • Statistics.


Step 2: Review Bulk Import Statistics

Click the Statistics icon for your import.

The Bulk Import Stats window displays:

  • All: Total records processed.

  • Success: Successfully processed records.

  • Error: Records that could not be imported.

  • Warning: Records that require attention.

You can also review individual record results and click Download to save the import report.

If any records fail, review the errors, correct the affected CSV rows, and import those records again.


Step 3: Verify Your Imported Companies

Once the import is complete:

  1. Return to Contacts → Companies.

  2. Search for the imported Companies.

  3. Open the records to verify their details.

  4. Confirm that new Companies were created or existing Companies were updated correctly.

For example, if your account had three Companies and two additional Companies were successfully imported, the Companies list would now show five records.


Your Company Bulk Import Is Complete!

You can now manage the imported Company records directly from your MxP CRM.

Frequently Asked Questions


Q: Why can't I see the Import button in Companies?

Verify that Company and Custom Object Import is enabled in Labs and that you have permission to import Company records.


Q: Can I create and update Companies in the same import?

Yes. Select Create and update companies during the Upload step.


Q: How does duplicate detection work?

MxP uses the selected matching criteria, such as Company ID, to identify existing Company records during the import.


Q: Can I prevent empty CSV values from replacing existing data?

Yes. Enable Don't update to an empty value during field mapping to preserve existing information when the corresponding CSV cells are blank.


Q: Can I import custom Company fields?

Yes. Ensure the custom fields already exist in MxP and map the corresponding CSV columns to those fields.


Q: Where can I check my import results?

Open Bulk Actions – Companies and click the Statistics icon for your import.


Q: What should I do if some records fail?

Download the import report, review the errors, correct the affected CSV rows, and import those records again.


Q: Can I undo a completed Company import?

No. Completed imports cannot be automatically reversed. Review your file and field mappings carefully before starting an import.
