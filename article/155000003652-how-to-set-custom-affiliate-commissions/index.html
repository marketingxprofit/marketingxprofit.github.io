How to Set Custom Affiliate Commissions

Custom affiliate commissions let you override campaign-level commission settings for an individual affiliate. You can configure a general commission, create product-specific rates, and adjust supported tier commission rates without changing the campaign defaults for other affiliates.


The campaign continues to control the overall tier structure. This guide explains how to open an affiliate’s campaign settings, configure available commission overrides, save the changes, and understand the supported precedence rules.

What are Custom Commissions for an Affiliate?


Custom commissions let you configure commission settings for one affiliate within a specific affiliate campaign.

Affiliate-level settings can override the campaign-level commission settings for that affiliate. Other affiliates can continue using the campaign’s configured commission rates.


In multi-tier campaigns, affiliate-level settings can adjust supported commission rates for existing tiers. The campaign continues to control the number of tiers.

Key Benefits of Custom Affiliate Commissions


Affiliate-level commission settings let you customize one affiliate’s rates without changing the broader campaign structure.


  • Individual Overrides: Set a custom commission for one affiliate without changing the campaign default for other affiliates.


  • Product-Specific Rates: Configure different commission rates for selected products where supported.


  • Tier-Level Customization: Adjust supported commission rates for an affiliate in a multi-tier campaign.


  • Campaign Structure Preserved: Change affiliate-specific rates without changing the campaign’s tier count.

How To Set a Custom Commission for an Affiliate


Open the affiliate profile, choose the relevant campaign, then use the campaign-specific Commissions tab to configure the available override.


Open Affiliate Manager


Start from the Sub-Account where the affiliate campaign is configured.


  1. From the MxP Sub-Account view, select Marketing.
  2. Select Affiliate Manager.
  3. Open Affiliate.



Select the Affiliate


Open the profile for the affiliate whose campaign commission you want to customize.

  1. Locate the affiliate.
  2. Open the affiliate profile.


The profile displays affiliate statistics, campaign-specific referral links, commission information, and other affiliate-management options.




Choose the Campaign


Commission overrides are configured separately for each applicable campaign.


  1. Scroll to Active referral links.
  2. Locate the campaign you want to customize.
  3. Click Customize beside that campaign.


The campaign-specific Advanced settings modal opens.



Open the Commissions Tab


The Advanced settings modal includes separate campaign-specific controls, so open the commission settings before changing a rate.


  1. Confirm that the correct campaign is selected.
  2. Select Commissions.



Set the Default Commission


The default commission acts as the affiliate’s general commission setting where no more specific product commission applies.

  1. Locate Default commission for all products.
  2. Select the available commission type.
  3. Enter the affiliate-specific commission value.

The supplied current UI confirms percentage-based commission entry.




Customize Commission by Product


Use product-specific commission settings when selected products need a different affiliate commission from the general default.


  1. Select Customize commission by products.
  2. Select the products available for customization.
  3. Configure the supported commission rate for each selected product.
  4. Review the product-specific overrides before saving.


Product-based commission settings are more specific than broader default commission settings and take priority where they apply.


Configure Multi-Tier Commission Rates


In a multi-tier campaign, affiliate-level settings can customize supported commission rates for the campaign’s existing tiers.


  1. Open Advance commission settings.
  2. Review the tiers already configured for the campaign.
  3. Adjust the supported affiliate-level commission rates where needed.
  4. Leave the campaign’s tier structure unchanged.


Note: Affiliate-level settings can adjust supported rates for existing tiers, but the number of tiers must be changed from the campaign configuration.



The current campaign-level commission system supports up to seven tiers.



Save the Custom Commission


Save the settings after reviewing the affiliate’s default, product-specific, and tier-level commission values.

  1. Review the commission settings.
  2. Click Save.

How Commission Overrides Work


Commission calculations can involve affiliate-level settings, product-specific settings, and campaign defaults. The supported precedence rules should be applied only where current MxP documentation defines them.


Affiliate-Level vs. Campaign-Level Commissions


Affiliate-level custom commission settings can override campaign-level commission settings for that affiliate.

For example, if a campaign has a 40% default commission and one affiliate has a 50% affiliate-level override, the custom affiliate rate applies where that override is eligible.

Other affiliates can continue using the campaign-level commission.


Product-Specific vs. Default Commissions


Product-based commission settings take priority over broader default commission settings for the applicable product.

Use Default commission for all products for the affiliate’s general rate. Use Customize commission by products when a selected product needs a different rate.


Multi-Tier Commission Structure


The campaign controls the number of commission tiers.

Affiliate-level settings can adjust supported commission rates for the campaign’s existing tiers, but they cannot add, remove, or restructure those tiers.


Complete Commission Priority


MxP documentation supports the individual precedence rules above, but it does not currently publish one complete hierarchy covering every affiliate-level and campaign-level commission type.

Restore Default


The current Advanced settings modal includes a Restore Default action.

Frequently Asked Questions


Q: Can I set a different commission for one affiliate?
Yes. Affiliate-level commission settings can override campaign-level commission rates for that affiliate.


Q: Will changing one affiliate’s commission affect other affiliates?
No. Affiliate-level commission settings apply to the selected affiliate and campaign. Other affiliates can continue using the campaign-level settings.


Q: Can I set a different commission for a specific product?
Yes. Use Customize commission by products to configure supported product-specific commission overrides.


Q: Can I change the number of tiers from the affiliate profile?
No. The campaign controls the tier structure. Affiliate-level settings can adjust supported rates for existing tiers.


Q: How many tiers can an affiliate campaign have?
Current MxP documentation supports up to seven tiers at the campaign level.


Q: What takes priority, a product-specific commission or a default commission?
Product-based commission settings take priority over broader default commission settings for the applicable product.
