How to Use the Enhanced Dashboard Builder

MxP's Dashboard Editor makes it easier to customize dashboards, track changes, and collaborate with your team. With auto-save, undo/redo, version history, and sticky notes, you can make updates confidently. You can also refresh dashboard data and turn a dashboard into a custom report in just a few clicks.

How To Edit a Dashboard


1. Open the Dashboard Editor

  1. From your Sub-Account, select Dashboard.

  2. Select the dashboard you want to edit.

  3. Click Edit dashboard.

  4. Use the widget panel on the left to add or arrange widgets.


2. Undo Changes or Restore a Previous Version

Use undo/redo for recent changes or version history to restore an earlier dashboard.

  1. In the editor, click Undo or Redo to reverse or reapply a change.

  2. To view older versions, click the clock icon (Version history).

  3. Select a version to preview it.

  4. Click Restore to use that version.

The current version is labeled Live.

3. Add Sticky Notes

Sticky notes help your team share reminders and context directly on a dashboard.

  1. In the editor, click the sticky note icon.

  2. Enter your note and choose a color.

  3. Drag the note to the desired position.

  4. Use the hide-notes control to hide all notes when needed.

4. Configure Quick Filters

Quick Filters help you control which data appears in supported dashboard widgets.

  1. Open the dashboard and click Edit dashboard.

  2. Open the Quick Filters configuration.

  3. Add or update your filters.

  4. Return to dashboard view mode using the back arrow.

5. Refresh Dashboard Data

Refresh your dashboard whenever you need updated widget data.

  1. Return to dashboard view mode.

  2. Hover over the refresh icon to view the last refresh time.

  3. Click the refresh icon to reload all widgets


    6. Create a Report from a Dashboard

  1. Create a custom report using the widgets already on your dashboard.
  2. Open your dashboard in view mode.
  3. Click the paper-plane icon (Send as report).
  4. Select Create and send.
  5. Your dashboard widgets are copied into a new report under Reporting → Custom Reports.
  6. Customize, export, send, or schedule the report as needed.

Note: The report is a separate copy. Changes to the original dashboard will not automatically update it.

Frequently Asked Questions


Q: Do I need to save dashboard changes manually?

No. Dashboard changes save automatically. Look for the Saved badge to confirm.

Q: Can I recover an older dashboard version?

Yes. Open Version history to preview and restore a previous version.

Q: Can my team see sticky notes?

Yes. Anyone with access to view the dashboard can see its visible sticky notes.

Q: Will a custom report update when I change my dashboard?

No. The report is an independent copy of your dashboard widgets.
