Conversations - Snippets

Conversations • Snippets • Reusable Messaging
Create and Use Snippets in Conversations
MxP Snippets let teams save reusable text and email content for frequently used messages. Snippets can include supported personalization, helping teams respond faster while keeping communication consistent. From Conversations, users can create, organize, search, and insert Snippets without repeatedly writing the same message.
What You'll Learn

Learn how to create Text and Email Snippets, manage user permissions, organize reusable content, and insert Snippets directly into Conversations.

Important

The current HiRise Snippets experience is automatically enabled and the classic Snippets layout has been retired. Users accessing Snippets through Conversations need Conversations → View & manage conversation permission.

What Are Snippets in Conversations?

Snippets are reusable text or email messages that can be quickly inserted into customer conversations. MxP supports separate Text Snippets and Email Snippets, allowing teams to prepare content for the channel where it will be used.

Snippets can also include supported personalization such as Custom Values and Trigger Links.

Common uses include:

  • Appointment reminders and follow-ups
  • Frequently asked questions
  • Lead follow-ups
  • Support responses
  • Business hours and instructions
  • Frequently reused email content
2

Key Benefits of Using Snippets

Snippets reduce repetitive typing while giving teams a centralized library of reusable messaging that can be updated and reused as communication needs change.

  • Save Time: Reuse common responses instead of rewriting them.
  • Improve Consistency: Give team members access to standardized messaging.
  • Personalize Responses: Add supported Custom Values to reusable content.
  • Stay Organized: Use folders, search, and filters to manage Snippets.
  • Edit Before Sending: Review and adjust inserted content before sending it to a contact.
3

Prerequisites and Permissions

Snippets inside Conversations depend on the user's Conversations permission. Checking this permission first can quickly resolve cases where the Snippets tab or composer option is missing.

  • Snippets are managed within the relevant Sub-Account.
  • The HiRise Snippets interface is automatically enabled.
  • Users need Conversations → View & manage conversation permission.

Give a User Access to Snippets

The user's Conversations permissions control whether they can access the Conversations workspace and its Snippets tools.

  1. From the Sub-Account View, click Settings.
  2. Select Users.
  3. Select the team member you want to update.
  4. Open Roles & Permissions.
  5. Select Conversations.
  6. Enable View & manage conversation.
  7. Click Save.
4

How To Create a Snippet

Creating a Snippet gives your team reusable content that can be searched, organized, and inserted whenever the same type of communication is needed.

  1. From the Sub-Account View, click Conversations.
  2. Select Snippets at the top of the page.
  3. Click + New Snippet.
  4. Select Add Text Snippet or Add Email Snippet.
  5. Enter a descriptive name.
  6. Add the message content.
  7. Add supported Custom Values or a Trigger Link when needed.
  8. Review the available preview or test option.
  9. Click Save.

Alternate Access: Snippets can also be accessed from Marketing → Snippets.

5

How To Organize and Manage Snippets

Keeping your Snippet library organized helps team members find approved content quickly and reduces the chance of outdated or duplicate messages being reused.

From Conversations → Snippets, you can:

  • Use Search to find a Snippet by name or keyword.
  • Filter the list by supported Snippet type.
  • Click New Folder to group related Snippets.
  • Use the three-dot menu (⋮) to move, edit, duplicate, or delete a Snippet.

Folders can be organized around areas such as Sales, Support, Appointments, Billing, or FAQs.

6

How To Use a Snippet in Conversations

Inserting a Snippet quickly populates prepared content while still allowing the user to review, personalize, or edit the message before it is sent.

  1. Go to Conversations.
  2. Open the contact conversation.
  3. Select the appropriate messaging channel.
  4. Click the Snippets icon in the message composer.
  5. Browse folders or search for the Snippet.
  6. Select the Snippet.
  7. Review the populated content and supported dynamic information.
  8. Make any necessary changes.
  9. Send the message.

Frequently Asked Questions

Q: What is the difference between a Text Snippet and an Email Snippet?
They are separate reusable content types. Use a Text Snippet for text-based messaging and an Email Snippet for reusable email content.
Q: Where can I access Snippets?
Go to Sub-Account View → Conversations → Snippets. Snippets can also be accessed from Marketing → Snippets.
Q: Do I need to enable HiRise Snippets in Labs?
No. The HiRise Snippets page is automatically enabled, and the classic Snippets layout has been retired.
Q: Can I personalize a Snippet?
Yes. Snippets support Custom Values and other supported placeholders for dynamic information.
Q: Can I edit a Snippet after inserting it into a conversation?
Yes. Review and edit the populated message in the composer before sending it.
Q: Is there a limit to how many Snippets I can create?
MxP currently documents no fixed Snippet limit. Use folders, search, and filters to manage larger libraries.
Q: What permission is required to use Snippets in Conversations?
The user needs Conversations → View & manage conversation permission. Manage this from Settings → Users → Roles & Permissions.
