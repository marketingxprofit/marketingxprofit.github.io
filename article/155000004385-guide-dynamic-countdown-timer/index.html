Marketing • Countdown Timers • Email & Funnels
Guide: Dynamic Countdown Timer
Dynamic Countdown Timers create personalized countdowns based on when an email is sent to a contact or when the contact opens it. Each contact can receive their own countdown window, and you can choose whether the timer expires after a set duration or aligns with a specific end time.
What You'll Learn

Learn how Dynamic Countdown Timers use email triggers, how Duration and Ends at Time work together, how timezone adaptation changes the countdown, and how to configure, place, and test a timer.

Important

A Dynamic Timer triggered by Email Opened is triggered once per contact. Reopening the same email does not restart the countdown; subsequent opens show the remaining time from the original trigger.

What Is a Dynamic Countdown Timer?

A Dynamic Countdown Timer creates a contact-specific deadline based on the selected email trigger. Use a Dynamic Timer when each contact should receive a personalized countdown instead of sharing one fixed expiration date.

Dynamic Timers are especially useful for evergreen promotions, follow-up campaigns, and other experiences where the available time should begin from an individual contact's email activity.

Dynamic Timer Triggers

The trigger determines when MxP begins calculating a contact's personalized countdown.

Email Sent
Starts the countdown when the email is sent to the contact.
Email Opened
Starts the countdown when the contact first opens the email.
3

Duration and Ends at Time

Duration controls how long the countdown runs. The Set End Time control enables the Ends at Time behavior, which aligns expiration with a selected time of day.

Duration Only

Disable Set End Time when you want the timer to expire strictly after the configured duration.

Example: With a 2-hour duration and an Email Opened trigger:

  • A contact opening the email at 2:00 PM expires at 4:00 PM.
  • A contact opening it at 5:00 PM expires at 7:00 PM.

Duration With Ends at Time

Enable Set End Time when the countdown should align with a selected clock time rather than ending solely according to the exact trigger timestamp.

Example configuration:

  • Trigger: Email Opened
  • Duration: 2 hours
  • Ends at Time: 11:00 PM

If the configured duration cannot be completed before the selected end time, the timer rolls to the next applicable occurrence of that end time.

4

Timezone Adaptation for Dynamic Timers

Enable Adapt to Contact Time Zone when the timer should adjust to the viewer's local timezone.

  • Emails: Use the contact's timezone when available.
  • Funnels and websites: Use the visitor's IP-detected timezone.
  • Fallback: If timezone data is unavailable, MxP uses the timezone selected during timer setup.

For complete timezone behavior, see Timezone Adaptation in Countdown Timers.

How To Set Up a Dynamic Countdown Timer

Configure the trigger, duration, expiration, timezone, and destination links before adding the timer to a campaign.

Create the Timer

  1. Navigate to Marketing → Countdown Timers.
  2. Click + New.
  3. Choose the countdown timer design you want to use and continue to the timer settings.
  4. Select Dynamic as the Timer Type.

Configure Timing and Timezone

  1. Select the appropriate trigger:
    • Email Sent: Begin the countdown when the email is sent.
    • Email Opened: Begin the countdown when the contact first opens the email.
  2. Set the Duration for the countdown.
  3. Configure the end-time behavior:
    • Disable Set End Time if the timer should expire after the configured duration.
    • Enable Set End Time if the countdown should align with a selected clock time.
  4. Select the appropriate Time Zone.
  5. Enable Adapt to Contact Time Zone if you want the timer to adjust based on the viewer's timezone.

Configure Links and Design

  1. Configure the Active Link for contacts while the timer is active and the Expired Link for contacts after the timer expires.
  2. Customize the timer's appearance using the available design settings.

Save, Place, and Test

  1. Give the timer a descriptive name and save it.
  2. Add the saved timer to the appropriate email, funnel, or website where supported. See the Related Articles for placement and synchronization instructions.
  3. Test the timer before publishing or sending the campaign. Confirm the trigger, duration, end-time behavior, timezone, and destination links work as expected.
6

Important Dynamic Timer Behavior

Review these behaviors before reusing or synchronizing a Dynamic Timer.

  • One-time trigger per contact: Once an Email Opened timer is triggered for a contact, reopening the same email does not restart it. Subsequent opens display the remaining time from the original trigger.
  • Same campaign: When the timer is used across an email and its destination funnel or website, use the corresponding saved timer to keep the countdown experience aligned.
  • Different campaign: If the same contact needs a new Dynamic Timer for another campaign, MxP recommends cloning the timer before reuse.

Frequently Asked Questions

Q: What happens if a contact never opens an email when Email Opened is the trigger?
The countdown does not begin until the contact opens the email.
Q: When should I use a Dynamic Timer instead of a Fixed Timer?
Use a Dynamic Timer when each contact should receive a personalized deadline based on their own interaction. Use a Fixed Timer when everyone should count down toward the same specific date and time.
Q: Can I make the timer expire exactly after the configured duration?
Yes. Disable Set End Time. The Dynamic Timer then expires after the configured Duration from the selected Email Sent or Email Opened trigger.
Q: What timezone is used if MxP cannot determine the contact or visitor timezone?
MxP uses the Time Zone selected during timer setup as the fallback.
