Hosted Numbers: Enable SMS on Existing Numbers | MxP

Hosted Numbers in MxP allows businesses to enable SMS on eligible existing US local and toll-free numbers without changing their current voice carrier. Available through Labs, this feature offers a guided process for verifying ownership, submitting authorization, and tracking hosting requests. Businesses can retain their familiar phone numbers while managing SMS through MxP.

What Are Hosted Numbers in MxP?


Hosted Numbers allows businesses to use an existing phone number for SMS through MxP while voice calls continue through the current carrier. Unlike number porting, which transfers a number to another provider, hosting enables SMS without transferring voice service.


Agency Owners and Admins can initiate hosting requests through a guided workflow that includes eligibility checks, ownership verification, service address selection, and authorization.

Key Benefits of Hosted Numbers


Hosted Numbers simplifies adding SMS to an existing business phone number while providing visibility into the setup process.

  • Keep Your Existing Number: Use the phone number customers already recognize.

  • Preserve Voice Services: Continue receiving calls through your existing carrier.

  • Guided Setup: Complete eligibility, verification, address, and authorization requirements in one workflow.

  • Track Request Progress: Monitor statuses and outstanding actions from the Hosted Numbers tab.

  • Flexible Request Management: Save, resume, or recover eligible hosting requests.

  • Clear SMS Readiness: See whether hosting is complete and whether the number can send SMS.

How to Set Up Hosted Numbers in MxP


Agency Owners and Admins can complete the hosting process directly within MxP. Accurate verification, service address information, and authorization help the request progress through hosting.


Step 1: Enable Hosted Numbers

  1. Log in as an Agency Owner or Admin.

  2. Navigate to Settings → Labs.

  3. Enable Hosted Numbers, where available.


Step 2: Start a Hosting Request

  1. Go to Settings → Phone System → Manage Numbers.

  2. Select Add Number → Host a Number.

  3. Enter the existing US phone number.

  4. Select Next to check eligibility.

  5. Continue if the number is eligible.


Step 3: Verify Ownership

  1. Review the verification code displayed by MxP.

  2. Answer the verification call on the existing number.

  3. Enter the code using the phone keypad.

  4. Select Verify in MxP.


Step 4: Provide the Service Address


Select an existing saved US service address or add a new physical address.


Step 5: Complete Authorization


Enter the authorized signer's details and send the authorization letter for electronic signature. If Agency identity verification is required, complete the verification journey presented by MxP.


Step 6: Track Hosting and Complete SMS Readiness

  1. Open the Hosted Numbers tab.

  2. Monitor the request until its status becomes Hosted.

  3. Complete any outstanding identity, messaging registration, or sender setup requirements.

  4. Confirm the number is SMS Ready before sending messages.



For Sub-Account Users: Open Settings → Phone System → Manage Numbers to discover the hosting option or review an existing request. Contact an Agency Owner or Admin to initiate hosting.

Hosted Numbers Availability and Requirements


Hosted Numbers is available through Labs for eligible accounts. The initial release supports the following:

RequirementDetails
Supported numbersEligible US local and toll-free numbers
MessagingSMS hosting
Voice serviceRemains with the current carrier
RequestsOne phone number per request
Supported LocationsMxP-managed Locations
Request managementAgency Owners and Admins


Hosting requires successful number eligibility and ownership checks, a US physical service address, and electronic authorization. Additional identity verification and messaging compliance requirements may apply.

Hosted vs. SMS Ready


A number becoming Hosted does not automatically mean it can send SMS. Messaging becomes available only after all applicable compliance and sender setup requirements are satisfied.

StatusMeaning
HostedThe number has successfully completed hosting.
SMS ReadyHosting and all applicable messaging requirements are complete.


SMS readiness may require:

  1. Completed number hosting.

  2. Applicable Location identity verification.

  3. Approved messaging registration or verification.

  4. Completed messaging sender setup.


For US local numbers, applicable A2P 10DLC registration is required. MxP reuses an existing approved Location-level registration where applicable.


For toll-free numbers, a separate Toll-Free Verification process applies instead of A2P 10DLC.

When a Sub-Account User selects Host a Number, MxP informs them that an Agency Owner or Admin must initiate the request.

Managing and Troubleshooting Hosting Requests


MxP provides options for managing incomplete requests and addressing hosting issues without losing visibility into their progress.

  • Save or Resume: Save, resume, or delete a draft before submission.

  • Cancel and Restart: Where supported, select Cancel request and start again. MxP retains request history, performs cleanup, and generates new request identifiers.

  • Resolve Issues: Follow the available action when a request displays Needs attention.

  • Contact Support: For delayed or failed requests, copy the Request ID and create a separate ticket from the Support page.

Frequently Asked Questions


Q: Do I need to port my number to MxP?

No. Hosting enables SMS through MxP while voice service remains with your existing carrier.

Q: Can I host multiple numbers in one request?

No. The initial Labs release supports one number per request.


Q: Can Sub-Account Users initiate hosting?

No. Only Agency Owners and Admins can initiate or manage hosting requests.


Q: Why is my number Hosted but not SMS Ready?

Additional identity, messaging registration, or sender setup requirements may still be outstanding.


Q: Do I need to complete A2P registration again?

Not necessarily. MxP reuses an applicable approved Location-level A2P registration for eligible local numbers.


Q: Can I host Canadian numbers?

Canadian numbers are not included in the stated scope of this initial Labs release.


Q: What happens if my hosting request fails?

Review the available recovery action or contact Support with the Request ID.


Q: How long does number hosting take?

Completion depends on verification, authorization, carrier processing, and final checks. A specific timeframe has not been confirmed for the Labs workflow.
