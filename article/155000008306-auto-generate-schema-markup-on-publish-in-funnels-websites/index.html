What is Auto-Generate Schema Markup?

Auto-Generate Schema Markup is a setting in MxP that uses AI to automatically create schema markup for pages published without structured data. Schema markup helps search engines and AI answer engines understand and present your content in rich results, improving both SEO and AEO (Answer Engine Optimization) visibility.

Previously, schema markup had to be added manually in the page editor, one page at a time. If you forgot or didn't have time, pages went live without structured data, potentially reducing search visibility and AI citation opportunities.

When Auto-Generate Schema is enabled, MxP automatically adds schema markup to any page published without it, ensuring every page has structured data from the moment it goes live — with no extra work or publishing delays.

How Auto Generate Schema Markup on Publish Works

When Auto-Generate Schema is enabled and you publish a page, MxP checks if schema markup already exists. If the page doesn't have schema, AI generates it automatically in the background.

Step 1
You publish a page

You click Publish in the Builder, trigger a save-based publish, or restore a version from history.

Step 2
MxP checks for existing schema

If the page already has schema markup, MxP leaves it untouched and publishes the page immediately.

Step 3
AI generates schema markup

If no schema exists, AI generates structured data for the page in the background. This process runs in parallel and does not delay publishing.

Step 4
Schema is added to the page

The generated schema markup is automatically added to the page, ensuring it has structured data from the moment it goes live.

Important

Existing schema is never overwritten. Auto-generation only runs when a page has no schema markup at the time of publishing.

4

Default Behavior for New and Existing Assets

Auto-Generate Schema has different default settings depending on when your Website, Funnel, or Webinar was created.

Existing Assets
Created Before This Release

Auto-Generate Schema defaults to OFF. Nothing changes unless you manually enable the setting. Existing schema and publishing behavior remain exactly the same.

New Assets
Created After This Release

Auto-Generate Schema defaults to ON. Pages published without schema will automatically receive AI-generated structured data. You can turn this off at any time in Settings.

Control Per Asset

Auto-Generate Schema is configured individually for each Website, Funnel, and Webinar. You can enable or disable it per asset in the SEO & AEO section of Settings.

How to Enable Auto-Generate Schema Markup

Follow these steps to enable Auto-Generate Schema for an existing Website, Funnel, or Webinar.

Step 1
Navigate to Sites

In the left sidebar, click Sites. Select the Funnels, Websites or Webinar tab, depending on the asset type you want to configure.


Step 2
Edit the asset

Click the asset name or the three-dot menu next to it, then select Edit.


Step 3
Go to Settings

Click the Settings tab in the asset editor.


Step 4
Enable the toggle

Turn on the Auto-generate schema toggle under the SEO & AEO section. The description reads: "Automatically add schema markup to pages that don't have it when published."


Step 5
Save your changes

Click Save at the bottom of the Settings page to apply the change.


Done

Auto-Generate Schema is now enabled. Pages published without schema will automatically receive AI-generated structured data.

Frequently Asked Questions

Q: Will auto-generated schema overwrite existing schema on my pages?
No. Auto-Generate Schema only adds markup to pages that have no schema at the time of publishing. If a page already has schema markup, MxP leaves it untouched.
Q: Does auto-generation delay publishing?
No. Schema generation runs in the background in parallel with publishing. Your page goes live immediately, and schema is added without any delay.
Q: What types of assets support Auto-Generate Schema?
Auto-Generate Schema is available for Websites, Funnels, and Webinars. You enable it individually in the SEO & AEO section of each asset's Settings.
Q: Is Auto-Generate Schema enabled by default for my existing Websites and Funnels?
No. Assets created before this release default to OFF. Nothing changes unless you manually enable the setting. Assets created after the release default to ON.
Q: Can I turn off Auto-Generate Schema after enabling it?
Yes. You can toggle Auto-Generate Schema on or off at any time in the SEO & AEO section of Settings. Be sure to click Save after making changes.
Q: How does Auto-Generate Schema improve my SEO and AEO?
Schema markup helps search engines understand your content and display rich results like star ratings, FAQs, and event details. It also helps AI answer engines (like ChatGPT, Perplexity, and Gemini) cite and reference your content accurately, improving your visibility in AI-generated answers.
Q: Does Auto-Generate Schema work when I publish from version history?
Yes. Auto-generation runs on all page-specific publish paths, including Builder Publish, save-triggered publish, and version-history publish.
Q: Do I need to do anything to existing pages after enabling Auto-Generate Schema?
No. Auto-generation only runs when you publish a page. Existing published pages remain unchanged unless you re-publish them. If they already have schema, it will not be overwritten.
