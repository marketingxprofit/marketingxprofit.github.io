Generate Schema Markups Using AI in Funnels & Websites

Schema Markup AI helps you generate structured data for website and funnel pages directly inside the MxP Website & Funnel Builder using AI in minutes. This article explains what the feature does, how to access it, how to generate and refine schema with AI, and what to review before publishing it live.


Note: Schema Markup Generator is a FREE Tool.

What is Schema Markup AI Generator?


Schema Markup AI is designed to turn page content into structured data with fewer manual steps. Understanding the workflow helps you know what AI handles automatically and what still needs your review before publishing.


When you open Schema Markup AI, MxP reads the content already on the page and identifies schema types that best match what the page contains. AI can generate one or more schemas, populate the available fields, validate the result, and save it. After generation, you can continue refining the schema through conversation by asking AI to add a schema, remove a schema, update a value, or switch to a different schema type.


Examples of refinements you can ask for:


  • Add FAQ schema to this page

  • Remove the Article schema

  • Change this schema from Organization to Local Business

  • Update the business phone number

  • Add a custom description


Schema Markup AI works on a page-by-page basis, so each page or funnel step can have its own schema setup. Once the schema is generated and reviewed, you still need to publish the page for the schema to go live.

Key Benefits of Generating Schema Markup Using AI


  • Faster setup: Generate schema in minutes instead of manually selecting types and filling out fields one by one.

  • Smarter schema selection: AI reviews your live page content and recommends the most relevant schema types for that page.

  • Pre-populated fields: Available schema fields are filled in automatically based on page content, reducing manual entry.

  • Conversational editing: Add, change, or remove schema by chatting with AI instead of editing everything manually.

  • Built-in validation: AI-generated schema is validated before it is saved, helping reduce formatting issues.

  • Flexible access: Use Schema Markup AI whether Funnel AI is enabled or disabled.

  • Page-level control: Customize schema for each website page or funnel step independently.

How To Generate Schema Markup Using AI


Proper setup starts after your page content is already in place. Because AI reads the page to determine the right schema types and values, completing your page content first helps generate more accurate schema markup.


Note: Schema is page-specific and does not carry over to other pages or funnel steps.


  1. Go to Sites.

  2. Click Funnels or Websites (whichever you want to add schema to).



  3. Create a new Funnel/Website, or edit an existing one.



  4. Click Edit on the specific Website page or Funnel step you want to update.



  5. Click on SEO & AI search optimization.

  6. Click on Schema Markup. (Make sure the page already has content. Schema Markup AI cannot generate schema for an empty page.)



  7. Click + New Schema button and select Create with AI option.



  8. Enter a well detailed and relevant prompt and click on the Send Message button.



  9. Wait for AI to analyze the page and generate the most relevant schema markup.



  10. Click on the View Schema Markup button and Review the generated schema and any populated values in Form and JSON view.



  11. In AI-generated schemas, Form view may not display every field. If you see a warning banner, click View details to review the hidden fields, or click JSON view to edit the full schema.



  12. You can add, modify and delete the schemas directly from the chat window.



  13. Click on Validate and Save.



  14. Confirm the generated schema appears under Active Schemas.

  15. Publish the page to make the schema live.

Important Notes and Limitations


Knowing the current behavior and limitations helps you avoid setup issues and use the feature more effectively. These details are especially useful when troubleshooting why schema was not generated or why it may not appear on another page.


  • Schema Markup AI must be triggered manually. It is not generated automatically when a new page is created with AI.

  • The page must contain content before running Schema Markup AI. Empty pages will return an error and no schema will be generated.

  • Custom value field mapping, such as {{custom_values.field_name}}, is not supported in Schema Markup AI at this time.

  • Schema is page-specific. It does not carry over automatically to other website pages or funnel steps.

  • AI-generated schema is auto-saved after validation, but the page must still be published for the schema to go live.

Frequently Asked Questions


Q: How does schema selection differ between manual setup and AI-generated schemas?
In manual setup, the available schema types are limited to a predefined list—usually the most commonly used ones for SEO, AEO (Answer Engine Optimization), and GEO (Generative Engine Optimization).

With AI, there is no such limitation. The AI can generate any valid schema type based on the content of the page.


Q: Can AI generate schema types that are not available in the manual list?
Yes. AI can analyze the page content and create schema markup using any valid schema type, even if it is not included in the manual selection options.


Q: Do I need to publish the page after Schema Markup AI saves the schema?

Yes. The schema is saved in the builder after validation, but it only goes live after you publish the page.


Q: Can Schema Markup AI generate more than one schema for a page?
Yes. AI can generate one or more schema types depending on the content on the page.


Q: What happens if my page has no content?
Schema Markup AI will not generate schema for an empty page and will show an error.


Q: Can I remove or change a schema after AI creates it?
Yes. You can ask AI to add, remove, or modify schema, and you can review the saved schemas from the Schema Markup area.


Q: Does schema from one page apply to all pages in my website or funnel?
No. Schema is page-specific and must be managed separately for each page or funnel step.


Q: Does Schema Markup AI work only when Funnel AI is disabled?
No. If Funnel AI is disabled, a dedicated Schema Markup AI pane opens in the left panel for schema-only actions.


Q: Can I still add schema manually instead of using AI?
Yes. MxP also supports manual schema setup for users who want direct control over schema types and field values.
