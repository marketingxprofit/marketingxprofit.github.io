How to Set Up Multi-Tier Commissions

Affiliate Manager

How to Set Up Multi-Tier Commissions

Configure up to seven commission tiers in an Affiliate Manager campaign and set default or product-specific commission rates for each tier.
What You'll Learn

Multi-tier commissions let you distribute commissions across an affiliate hierarchy instead of rewarding only the affiliate who generates a qualifying sale. This guide explains how the tier structure works and how to configure it during affiliate campaign creation.

What is Multi-Tier Commission Setup?

Multi-tier commissions let a campaign distribute commissions across multiple levels of an affiliate hierarchy. The affiliate responsible for a qualifying sale can receive the Tier 1 commission, while eligible parent affiliates can receive commissions from higher configured tiers.

Each campaign can contain up to seven commission tiers. Each tier can use its own commission rate, allowing the reward structure to change as commissions move through the affiliate hierarchy.

TIER 1
Sale-producing affiliate

The affiliate responsible for the qualifying sale receives the applicable Tier 1 commission.

TIER 2
Parent affiliate

The eligible parent affiliate can receive the configured Tier 2 commission.

TIER 3
Next eligible parent

The next eligible parent in the hierarchy can receive the configured Tier 3 commission.

Example 1: Five-Tier Commission Distribution

Let's say your commission structure is set up as follows:

  • 1st Tier: 20%
  • 2nd Tier: 10%
  • 3rd Tier: 5%
  • 4th Tier: 3%
  • 5th Tier: 2%

The affiliate who generates the sale receives the first-tier commission. The remaining commissions are distributed to eligible referring affiliates higher in the chain according to their configured tier percentages.

If Jan generates a $100 sale:
  1. Jan (1st tier affiliate) earns $20.
  2. Toby (Jan's recruiter, 2nd tier) earns $10.
  3. Ryan (Toby's recruiter, 3rd tier) earns $5.
  4. Jim (Ryan's recruiter, 4th tier) earns $3.
  5. Michael (Jim's recruiter, 5th tier) earns $2.
Total Paid to Affiliates: $40
$20 + $10 + $5 + $3 + $2

In this example, all five configured tiers are represented in the affiliate chain, so commissions are distributed across all five levels.

Example 2: Shorter Affiliate Chain

Using the same commission structure, assume Stanley generates a $100 sale but only three affiliate levels are represented in the referral chain.

If Stanley generates a $100 sale:
  1. Stanley (1st tier affiliate) earns $20.
  2. Dwight (Stanley's recruiter, 2nd tier) earns $10.
  3. Michael (Dwight's recruiter, 3rd tier) earns $5.
Total Paid to Affiliates: $30
$20 + $10 + $5

In this example, the referral chain contains only three affiliate levels, so commissions are distributed across those three represented tiers.

Key Benefits of Multi-Tier Commissions

Multi-tier commissions give you more control over how affiliates and their referral networks are rewarded within a campaign.

Flexible commission structures — Configure up to seven tiers within one affiliate campaign.
Tier-specific rewards — Set different commission values for different levels of the affiliate hierarchy.
Product-level control — Use product-specific commissions when individual products require different payout rates.
Support for sub-affiliate networks — Reward eligible parent affiliates when affiliates beneath them generate qualifying sales.
3

Prerequisites and Limitations

A multi-tier campaign needs the appropriate campaign and commission settings before MxP can distribute commissions through a sub-affiliate hierarchy.

  • Create or select an Affiliate Manager campaign.
  • Configure at least 2 tiers if the campaign will use sub-affiliates.
  • MxP supports a maximum of 7 commission tiers per campaign.
  • If you use product-specific commissions, make sure the applicable products are included in the campaign product list.
Campaign-level tier structure

The campaign controls the number of commission tiers. Individual affiliate commission settings can change commission rates, but they do not change the campaign's tier count.

How To Set Up Multi-Tier Commissions

Multi-tier commissions are configured during the Commissions stage of affiliate campaign creation. Start from the Sub-Account view so the campaign source, products, tier count, and commission values are configured in the correct order.

STEP 1
Open the Affiliate Campaign creation flow
  1. From the Sub-Account view, select Marketing in the left menu.
  2. Select Affiliate Manager.
  3. Select Campaign.
  4. Click + Add to create a campaign.
STEP 2
Configure the campaign details

The campaign source determines what the campaign tracks and which products are available for commission configuration.

  1. In Campaign details, select the campaign source.
  2. Select the applicable source details.
  3. Configure the campaign link or landing destination shown for the selected source.
  4. Review the product list associated with the campaign.
  5. Add or remove products so the list contains the products eligible for commissions.
  6. Continue to the Commissions step.
STEP 3
Set the campaign's default commission

The default commission provides the base commission value for the campaign before you configure additional tiers.

  1. In the Commissions step, enter the default commission.
  2. Select whether the commission is a percentage of the product price or a flat amount.
  3. If individual products need different rates, use the product-level commission controls to configure those products separately.
STEP 4
Open Advanced commission settings

Advanced commission settings control the campaign's multi-tier structure.

  1. From the Commissions step, select Advanced commission settings.
  2. Locate Number of tiers.
  3. Select the number of commission tiers required for the campaign.
Tier count

MxP supports up to seven tiers. Leave the number of tiers at 1 when the campaign does not need a multi-tier commission structure.

STEP 5
Configure the commission for each tier

Each additional tier can have its own default commission or product-specific commission values.

  1. After selecting the tier count, open the next tier, such as Tier 2.
  2. Enter the Default commission for all products for that tier.
  3. If needed, use Customize commission by products to assign different rates to individual products.
  4. Repeat these steps for each additional tier.
  5. Review the rates across all configured tiers before continuing.
Optional commission controls

Commission Length and Variable Commissions provide additional control for recurring product commissions. They are separate from the campaign's multi-tier structure.

STEP 6
Finish the campaign setup

After configuring commissions, complete the remaining campaign settings before making the campaign available to affiliates.

  1. Continue to Finish.
  2. Add a campaign description if needed.
  3. Select Assign Affiliate if you want to assign affiliates during campaign creation.
  4. Review the remaining campaign settings.
  5. When the campaign is ready, select Finish.

Frequently Asked Questions

Q: Does my campaign need multiple tiers before I can add sub-affiliates?
Yes. Configure at least two commission tiers before using sub-affiliate functionality in the campaign.
Q: Can I change the number of tiers from an individual affiliate's commission settings?
No. The campaign controls the tier structure. Affiliate-level settings can customize commission rates, but they cannot change the campaign's number of tiers.
Q: Can an affiliate have different commission rates from the campaign defaults?
Yes. Custom affiliate-level commission settings can override campaign-level commission rates for that affiliate.
Q: Which commission applies if I use product-based, variable, and default commissions together?
MxP documents the priority as product-based commissions first, variable commissions second, and default commissions third.
