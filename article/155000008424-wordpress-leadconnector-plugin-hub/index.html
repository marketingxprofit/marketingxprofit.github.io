What is the WordPress Plugin Hub?

The WordPress Plugin Hub is a dedicated platform hosted at wordpress.leadconnectorhq.com where users can download, use, and share the latest versions of LC WordPress plugins. This hub serves as a reliable, always-available alternative to traditional plugin distribution channels.

The plugin hub operates in parallel with WordPress's official plugin directories, giving users access to the same plugin updates through multiple channels. This dual-channel approach ensures continuous availability and reduces the risk of access disruptions.

Users can access all current LC WordPress plugins from the hub, with additional plugins planned for future release. The platform provides direct download links and version information for each available plugin.

How to Download Plugins from the Hub

Follow these steps to download LC WordPress plugins from the dedicated hub.

Step 1
Navigate to the Plugin Hub

Visit wordpress.leadconnectorhq.com in your web browser. The homepage displays all available LC WordPress plugins with version information and download options.


Step 2
Download the Plugin File

Click the download button for your selected plugin. The plugin file downloads as a .zip archive to your computer's default download location.


Step 3
Install the Plugin in WordPress

Log into your WordPress admin dashboard, navigate to Plugins > Add New, click "Upload Plugin," select the downloaded .zip file, and click "Install Now." Once installed, activate the plugin from the Plugins page.

Frequently Asked Questions

Q: Do I still need to download plugins from WordPress's official directory?
No. The WordPress Plugin Hub provides the same plugin versions available on WordPress's official directory. You can download plugins from either source. The hub serves as an alternative distribution channel maintained in parallel with the official directory.
Q: Will the plugins receive automatic updates if I download them from the hub?
Plugin update behavior depends on how your WordPress site is configured. Plugins downloaded from the hub function identically to those installed from WordPress's official directory. You can manually update plugins by downloading the latest version from the hub and reinstalling, or configure automatic updates through WordPress's standard update mechanisms.
Q: Can I share plugins downloaded from the hub with clients?
Yes. You can share the plugin hub URL (wordpress.leadconnectorhq.com) with clients or team members, or download plugin files and distribute them directly. The hub exists specifically to make plugin sharing and distribution more convenient.
Q: What happens if a plugin is delisted from WordPress's official directory?
The WordPress Plugin Hub continues to provide access to all LC plugins regardless of their status on WordPress's official directory. This prevents disruptions to your WordPress integrations and ensures continuous availability.
Q: Are the plugins on the hub the same versions as those on the official WordPress directory?
Yes. The plugin hub is maintained in parallel with WordPress's official plugin directory, meaning both sources receive the same updates simultaneously. You always get the latest version regardless of which source you use.
Q: How often are plugins updated on the hub?
The hub receives plugin updates at the same time as WordPress's official directory. When LC releases a new plugin version, it becomes available on both distribution channels simultaneously.
Q: Will more plugins be added to the hub in the future?
Yes. Additional LC WordPress plugins are planned for future release on the hub. The platform currently hosts MxP, MxP Migrator, and Visibility, with more integrations coming.
