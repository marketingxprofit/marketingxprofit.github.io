Import Products / Price From Stripe

Import existing products and recurring prices from Stripe into MxP without having to recreate them manually. This feature makes it easy to bring your existing subscription products into MxP for use in your sales funnels, websites, and other payment processes.

Import Products and Prices from Stripe


Importing products and prices from Stripe into MxP allows you to use existing recurring subscription products without recreating them manually. Only eligible recurring prices can be imported using the Import From Stripe feature. One-time prices cannot be imported from Stripe and must be created directly in MxP. 

Which Pricing Plans can be Imported?


Before importing products from Stripe, it's important to understand which pricing types are supported. MxP only supports importing eligible recurring or subscription prices through this feature. Prices that do not meet the requirements will not appear as available import options.


  • Recurring/Subscription Prices: Only recurring subscription prices can be imported from Stripe. One-time prices cannot be imported.

  • Live Mode: Prices must exist in Stripe's Live mode. Test-mode prices cannot be imported.

  • Metered Prices: "Metered" prices can not be imported when importing a recurring plan/price.

  • Previously Imported Prices: Stripe plans/prices that have already been imported into MxP will not show as options when using the "Import From Stripe" function, as they have already been imported.


Important: If you've created plans/prices in Stripe, you can use the "Import From Stripe" button to import them into MxP as MxP Products.' (One Time Products cannot be imported.)

What Happens When You Import a Price from Stripe?


When you import a recurring price, MxP creates the necessary product and pricing records so the product can be used within the platform.


  • Product Creation: MxP imports the Stripe product associated with the selected price and creates the product in MxP if it does not already exist.

  • Price Creation: The selected price is created under the corresponding MxP product.

  • Stripe Test Mode and PayPal: The same product and price are created in Stripe Test mode and in PayPal, if the integration is connected.


Important: This process applies to recurring products only. One-time prices cannot be imported from Stripe and must be created directly in MxP.

Understanding the 3 Types of Pricing Plans in your Stripe Account


Stripe pricing plans can originate from different locations, including the MxP SaaS Configurator, MxP Products, or Stripe itself.



1. Prices Created Through the SaaS Configurator in the Agency Level


  • Prices created via the SaaS Configurator will have an "Agency Plan" tag with the product and price name in product listing and product details page.

  • Prices created with the SaaS Configurator cannot be edited in MxP Payments

  • If you update a price directly in Stripe, the change will not be reflected in the MxP Product/price. 

  • If you need to change the price of a product created via the SaaS Configurator, edit the price in Stripe and then use the "Import From Stripe" button to import the new price, which will create a new MxP Product with an "Agency Plan" tag, which you can then go select in your Funnel or Website page settings. 

  • If you've created plans/prices in Stripe, you can use the "Import From Stripe" button to import them into MxP as MxP Products.' (One Time Products cannot be imported.) 




2. Prices which were created by creating a product in MxP


  • When a product is created in MxP (excluding one time products), a corresponding plan/price will be created in Stripe.

  • Any edits to MxP product pricing will automatically sync to Stripe by creating a new pricing on Stripe. This is due to limitation on Stripe's APIs to edit the existing prices.

  • Any edits to Stripe pricing will not auto-sync to MxP. Changed pricing in Stripe would need to imported into MxP as a new product.

  • If you've created plans/prices in Stripe, you can use the "Import From Stripe" button to import them into MxP as MxP Products.' (One Time Products cannot be imported.)



3. Prices Created Directly in Stripe


  • If you've created plans/prices in Stripe, you can use the "Import From Stripe" button to import them into MxP as MxP Products. 

  • If you need to edit an imported product's price, make the edit in MxP and the change will sync to Stripe by creating a new pricing on Stripe.

  • If you edit an imported plan/price in Stripe, the change will not be reflected in the MxP product - you'd need to import the changed plan/price as a new MxP Product.

  • If you've created plans/prices in Stripe, you can use the "Import From Stripe" button to import them into MxP as MxP Products.' (One Time Products cannot be imported.
