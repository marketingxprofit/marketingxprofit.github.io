Workflow Notes, Action Notes & Sticky Notes


Workflow Notes, Action Notes, and Sticky Notes help you document automations and collaborate with your team in MxP's Workflow Builder. Use these tools to add instructions, explain workflow actions, and organize important information directly on the canvas.

What are Workflow Notes, Action Notes, and Sticky Notes?


MxP provides three types of notes to help users document workflows and communicate important information. Each type serves a different purpose, from explaining an entire workflow to highlighting individual actions.

  • Workflow-Level Notes: Document the purpose, instructions, and important details of an entire workflow.

  • Action-Level Notes: Add comments and explanations to specific workflow actions.

  • Sticky Notes: Display customizable, color-coded reminders directly on the workflow canvas.

Key Benefits of Workflow Notes, Action Notes, and Sticky Notes


Workflow notes make automations easier to understand, manage, and update. They help teams share information without relying on external documentation.

  • Better Collaboration: Share instructions and feedback with team members.

  • Improved Documentation: Explain workflow logic and important decisions.

  • Easy Access: Find action-specific notes through the centralized Notes panel.

  • Visual Organization: Highlight important information using color-coded Sticky Notes.

  • Simplified Maintenance: Preserve context for future workflow updates.

Workflow-Level Notes


Workflow-Level Notes allow administrators to document important information about an entire workflow. They are visible to users with workflow access and include details about who created or edited them and when. These notes are saved when the workflow is saved.

Action-Level Notes


Action-Level Notes, formerly called Comments, let users add information to individual workflow actions. They are useful for explaining conditions, delays, or other automation steps.

  • Hover over an action to access its Notes icon.


  • Add comments or explanations to the selected action.

  • Review the history of added notes.

  • Search action-level notes using the centralized Notes panel.


Once an action contains a note, its Notes icon remains visible.

Sticky Notes


Sticky Notes provide visual reminders and instructions directly on the workflow canvas. They help organize complex workflows without modifying automation logic. Available customization options include:

  • Different note colors.

  • Rich text formatting.

  • Image attachments.

  • Controls to hide or show Sticky Notes.


The Advanced Workflow Builder also supports enhanced Sticky Notes with images and links.

Workflow Builder Sidebar


The Workflow Builder Sidebar provides access to notes and other workflow tools. It helps users navigate workflow information while working on automations.


The sidebar includes:

  • Notes: Access workflow-level and action-level notes.

  • Sticky Notes: Add visual annotations to the canvas.

  • Stats View: Review available workflow statistics.


Workflow editing is unavailable while Stats View is active.

How to Add Workflow Notes, Action Notes, and Sticky Notes


Adding notes directly within the Workflow Builder keeps documentation connected to the automation. Choose the appropriate note type depending on whether the information relates to the entire workflow, a specific action, or a visual reminder.


Add Workflow-Level Notes

  1. Navigate to Automations > Workflows.

  2. Open the workflow you want to document.

  3. Click Notes in the sidebar.


  4. Enter the workflow description or instructions.


  5. Click Save to retain the changes.


Add Action-Level Notes

  1. Open the workflow in the Workflow Builder.

  2. Hover over the desired action.

  3. Click the Notes icon in the upper-right corner.

  4. Enter your comment or explanation.

  5. Submit the note using the available interface control.


To review existing notes, open the main Notes panel and use the search functionality.


Add and Customize Sticky Notes

  1. Open the workflow.

  2. Click Sticky Notes in the sidebar.

  3. Select a note color.


  4. Enter your text on the note that appears on the canvas.

  5. Use the available formatting tools to customize the note.

  6. Use Hide Notes when you want to temporarily hide Sticky Notes from the canvas.

Frequently Asked Questions


Q: Who can add Workflow-Level Notes?

Administrators can add Workflow-Level Notes, while users with workflow access can view them.

Q: Can I search Action-Level Notes?

Yes. Use the centralized Notes panel to search for notes associated with workflow actions.


Q: Can Sticky Notes include images?

Yes. Sticky Notes support image attachments. The Advanced Builder also supports links.


Q: Can I hide Sticky Notes without deleting them?

Yes. Use the Hide Notes control to temporarily remove Sticky Notes from the canvas display.


Q: Are Workflow Builder Sticky Notes the same as Workflow Maps Sticky Notes?

No. Workflow Builder Sticky Notes annotate individual workflows, while Workflow Maps Sticky Notes are used to 
document workflows and related assets within maps.

Q: Does saving a workflow automatically publish it?

No. Saving and publishing are separate actions. A workflow can remain in Draft mode after it has been saved.
