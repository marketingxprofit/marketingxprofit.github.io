This quick guide walks you through getting the mac/Windows/Linux app onto your computer and logging in for the first time.

Install the Desktop App (macOS, Windows & Linux)


Choose your operating system below. Each path is short and direct; follow the four steps in order.

macOS


  1. Download the installer - Use the macOS (.dmg) link above.



  2. Install -  Open the .dmg and drag MxP into Applications.



  3. Open MxP - Launch from Applications, Launchpad, or Spotlight.

  4. Sign in - Click Sign In in the desktop app. Your default browser opens. If you’re already signed in to the MxP web app in that browser, you’ll be routed back to the desktop app automatically. If not, complete the browser login (whitelabeled domain if enabled), then you’ll return to the app.


Windows


  1. Download the installer — Use the Windows (.exe) link above.



  2. Install - Open the .exe and finish the setup wizard.



  3. Open MxP — Launch from the Start menu.

  4. Sign in - Click Sign In in the desktop app. Your default browser opens. If you’re already signed in to the MxP web app in that browser, you’ll be routed back to the desktop app automatically. If not, enter your credentials in the browser (whitelabeled domain if enabled), then you’ll return to the app.



Linux 


  1. Download the Linux installer for your distribution and architecture from the links above.

  2. Install using your system’s standard installer flow.

  3. Open the Desktop App from your applications menu.



  4. Click Sign In. Your default browser opens to complete sign-in, then routes you back to the desktop app.

Frequently Asked Questions


Q: Is the desktop app different from the MxP web app?
The experience and data are the same; the desktop app packages MxP in a dedicated, optimized window with native notifications.


Q: Can I use multiple accounts or sub‑accounts?
Yes - sign in normally, then switch using the account menu if you have access to multiple sub‑accounts.


Q: Will my whitelabeled domain affect login?
Yes - if enabled, you’ll be routed through your branded login during sign‑in before returning to the app.


Q: What if I don’t see notifications?
Enable OS‑level notifications for MxP and then review in‑app preferences.
