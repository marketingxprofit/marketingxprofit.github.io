The Internationalization Of MxP Has Begun!


MxP lets businesses and team members choose the language used in supported parts of the CRM. Set a default Platform Language for a sub-account, or choose a personal language preference that overrides it. This guide covers supported languages, localized product areas, notification behavior, and the steps to update language settings.

What Is MxP Platform Language?

Platform Language is the preference that determines which available translations MxP displays in supported areas of the platform. A sub-account can establish a default for its users, while each user can select a different language in My Profile. System-generated interface text and notifications follow the appropriate language preferences, while untranslated items fall back to English.

Key Benefits of MxP Platform Language

Choosing the right language makes everyday work easier for multilingual teams and helps users understand the platform's menus, feedback, and system notifications.

  • Localized workspace: Use supported CRM screens, labels, and system messages in a familiar language.

  • Flexible team preferences: Set a sub-account default while allowing individual users to choose another language.

  • Clearer notifications: Receive supported notification titles, messages, and email notifications in the recipient's preferred language.

  • Broader feature coverage: Use localized experiences across customer management, marketing, payments, portals, and other listed product areas.

  • Reliable English fallback: See English content when a specific translation is unavailable instead of a blank message.

How Platform Language Is Applied

Different MxP experiences may use different language preferences. Understanding the priority of each setting helps explain why one screen or message may appear in a different language from another.

ExperienceLanguage behavior
Sub-account interfaceUses Settings > Business Profile > Platform Language as the default.
Individual user interfaceThe user's Settings > My Profile > Platform Language overrides the sub-account default.
System notificationsNotification titles and message bodies follow the recipient's Platform Language.
Email notificationsSupported subject lines and notification templates are localized for each recipient.
Funnels and Funnel Stats messagesUse the location's locale when available, then the user's Platform Language, then English.
Email Builder system contentSupported starter templates, default campaign content, and system prompts use the selected user language.
Missing translationThe relevant content or message appears in English.

Important: Platform Language is separate from Outbound Communication Language for Custom Values in the Business Profile. That setting controls how supported custom values are displayed in outbound communications and other applicable areas.

WordPress Localization

WordPress-related screens have full internationalization coverage for supported platform languages. Previously missing translation strings have been added to provide more consistent localized labels and messages throughout the WordPress experience.


Funnels and Funnel Stats Localization

Funnels and Funnel Stats localize system-provided validation messages, errors, and success confirmations to make editing and troubleshooting easier in the appropriate language. When a location locale is available, it takes priority; otherwise, MxP uses the user's Platform Language and then English.


Email App Localization

The Email app uses the user's selected language for supported system-provided content in the campaign-building experience. This section covers starter templates, system messages, and new-campaign defaults separately from recipient-based email notifications.

  • Starter email templates: System-provided starter templates appear in the selected language when a translation is available.

  • Error and success messages: Supported prompts and confirmations use the selected language.

  • New-campaign default content: System-provided content inserted when creating a campaign uses the selected language where available.

  • English fallback: Unavailable translations are replaced with the English version.

For editing details, see Localized Email Content and System Messages. For campaign creation, see Getting Started - Launch an Email Campaign.

How to Set Up MxP Platform Language

Set the sub-account language first to establish the shared default, then adjust individual user preferences as needed. Checking both settings helps ensure each person sees supported content in the language they expect.


Set the Default Language for a Sub-account

The sub-account default is a practical starting point for teams that primarily work in one language. Users can still choose a different personal preference.

  1. Open the appropriate MxP sub-account.

  2. Go to Settings > Business Profile.

  3. Find Platform Language and select the preferred language.

  4. Click Update in the Business Physical Address section.


Set an Individual User's Language

Personal preferences allow people in the same sub-account to work in different supported languages without changing the account-wide default.

Users can configure their personal Platform Language under Sub-Account View > Settings > My Profile > Platform Language. This preference overrides the sub-account's default language.

How to Report Translation Issues

Translation feedback helps MxP correct unclear, inaccurate, or missing interface text. Agency Owners and Agency Admins using a non-English Platform Language can submit reports directly in MxP; the reporting icon is not shown to sub-account-only users or when English is selected.

  1. Open the page containing the translation issue.

  2. Select the Report Translation Issue icon in the top bar, if available.

  3. Choose the issue type and attach a screenshot showing the wording in context.

  4. Explain what is incorrect and include the preferred wording, if known.

  5. Submit the report for review.

For full instructions, see Report Translation Feedback from the MxP Interface.

Frequently Asked Questions

Q: Why do some words or messages still appear in English?

A: A translation may not be available for a particular string. MxP falls back to English rather than leaving the content blank.

Q: Why might a Funnel Stats message use a language different from my profile preference?

A: Funnel and Funnel Stats messages use the location's locale first when available. Your personal Platform Language is used only when no location locale applies.

Q: Are the CRM and Client Portal language settings the same?

A: No. The Client Portal and child apps have their own language settings and instructions. 

Q: Does Platform Language also control how dates and times appear in outbound custom values?

A: Not by itself. Review Outbound Communication Language for Custom Values in the Business Profile for supported date, time, and other custom-value formatting.

Q: Why can't I see the translation feedback icon?

A: It is available only to Agency Owners and Agency Admins using a supported non-English platform language, and it may not appear on every page.
