What is Global Search V2?

Global Search V2 is a unified search interface that allows you to find any record, page, or route in MxP from a single entry point. It indexes 530+ platform routes across both agency and location levels, and searches across 8 core products including contacts, opportunities, products, calendars, funnels, workflows, social planner, and conversations.

The search runs on the backend with parallel product queries, enforcing access control based on user roles, assigned-data-only permissions, feature flags, and deprecated features. This eliminates client-side latency and provides a lightning-fast search experience similar to Mac Spotlight or Windows Search.

Global Search V2 replaces the need to hunt through nested menus or remember where specific features are located. Access it instantly from the search bar in the left sidebar or press Cmd/Ctrl + K from anywhere in MxP to start searching.

Key Benefits

Global Search V2 transforms platform navigation from a time-consuming process into an instant action. The unified search interface reduces friction, eliminates confusion about feature locations, and scales performance as the product catalog grows.

Universal Platform Coverage — Search across 530+ routes and 8 products from a single interface, with more products being onboarded continuously to provide complete platform coverage.
Backend-Powered Speed — Server-side search runs product queries in parallel with no client-side latency stacking, delivering results in a single round trip regardless of how many products are searched.
Smart Fuzzy Matching — Spelling mistakes are handled automatically, and typing a section name surfaces every sub-page under it without requiring exact text matches.
Permission-Aware Results — Search results are automatically filtered by user roles, assigned-data-only permissions, feature flags, and deprecated features, ensuring you only see what you have access to.
Keyboard-First Navigation — Full arrow-key and Enter navigation, Cmd/Ctrl+K to open, and Cmd/Ctrl+1..9 to switch search scopes provide a fast, hands-on-keyboard workflow.
Voice Command Support — Use voice dictation with commands like "open", "tab", and shortcuts for hands-free navigation and accessibility.

The Search Interface

The Global Search V2 interface opens as a centered modal overlay with a clean, focused design. The search bar appears at the top with four action icons, followed by product filter pills and grouped results below.

Component 1
Search Bar and Action Icons

The search bar displays dynamic placeholder text based on your selected filter, such as "Search", "Search for Conversations...", or "Search apps...". Four action icons appear to the right of the search input: a microphone icon for voice commands, a magnifying glass for standard search, a navigation/routes icon, and a help icon for assistance.

Component 2
Product Filter Pills

Below the search bar, a row of pill-shaped filters displays your search scope options. The "All" pill searches across all products and routes, while individual product pills (Contacts, Opportunities, Products, Calendars, Funnels, Workflows, Social Planner, Conversations) narrow results to specific product types. The active filter is highlighted in blue.

Component 3
Grouped Search Results

Results appear in grouped sections such as PAGES, CONTACTS, PRODUCTS, FUNNELS, with result counts displayed next to each section header (e.g., "PAGES 3", "FUNNELS 5"). Each result shows the record or page name, breadcrumb navigation path, and relevant metadata. A "See all" link appears for sections with more results than displayed.

Component 4
Search Apps View

When you click into the search bar without typing, a "Search apps..." view appears showing all 8 product icons in a grid layout: Contacts, Opportunities, Products, Calendars, Funnels, Workflows, Social Planner, and Conversations. Click any icon to filter your search to that specific product.

Component 5
Keyboard Shortcuts Footer

At the bottom of the search modal, a keyboard shortcuts reference displays available commands: Navigate (arrow keys), Tab, Switch tab (Cmd/Ctrl+number), Open (Enter), and ESC to Dismiss. The label "Global Search" appears in the bottom right corner.

Access Point

Global Search V2 is triggered from the search bar located in the left sidebar of MxP, displaying the keyboard shortcut "⌘K" next to it. Click the search bar or press Cmd/Ctrl+K from anywhere in the platform to open the search interface instantly.

Search Modes and Filters

Global Search V2 provides multiple search modes to match different workflows. You can perform a global search across all products and routes, narrow the scope to a single product, or focus on navigation-only searches.

Mode 1
All Scope

The default "All" mode searches across every enabled product and all platform routes simultaneously. This provides a comprehensive sweep of MxP, returning both records (contacts, opportunities, funnels, etc.) and navigation pages that match your query. Results are grouped by category with counts displayed.

Mode 2
Product-Specific Filters

Click any of the 8 product filter pills (Contacts, Opportunities, Products, Calendars, Funnels, Workflows, Social Planner, Conversations) to narrow your search to that specific product. The search bar placeholder updates to reflect your selection, such as "Search for Conversations..." when the Conversations filter is active. This mode is useful when you know the product type but not the specific record.

Mode 3
Search Apps View

When you first open Global Search or clear your query, the interface displays a "Search apps..." view with all 8 product icons arranged in a grid. Click any icon to instantly filter your search to that product category, making it easy to browse by product type before entering specific search terms.

Switching Modes

Use keyboard shortcuts Cmd/Ctrl+1 through Cmd/Ctrl+9 to switch between search scopes quickly without leaving the search interface. The active filter pill is highlighted in blue, and the search placeholder text updates to match your selection.

How to Enable and Use Global Search V2

Global Search V2 is available under MxP Labs. Once enabled, you can invoke the search interface using the keyboard shortcut, clicking the search bar in the left sidebar, or using voice commands.

Enabling Global Search V2
Step 1
Navigate to Labs Settings and Enable Global Search V2

From your MxP account, go to Labs > Subaccounts to access the Labs feature settings. Locate "Global Search V2" in the Labs features list and toggle it to the enabled position. Changes take effect immediately.


Step 2
Access the Search Interface

Click the search bar in the left sidebar (next to the ⌘K shortcut label), or press Cmd/Ctrl + K from anywhere in MxP at the subaccount level to open the Global Search interface.


Using Global Search V2
Step 3
Enter Your Search Query

Type the name of a contact, opportunity, page, or feature you want to find. Global Search uses fuzzy matching, so spelling mistakes are automatically handled. You can also click the microphone icon to use voice commands.

Step 4
Review and Navigate Results

Results appear grouped by type (PAGES, CONTACTS, PRODUCTS, FUNNELS, etc.) with result counts displayed. Use arrow keys to navigate through results, and press Enter to open the selected item. Results are automatically filtered by your permissions and access level.


Step 5
Filter by Product or Browse Apps

Click any of the product filter pills to narrow results to a single product (Contacts, Opportunities, Calendars, etc.), or click the search bar without typing to view the "Search apps..." grid showing all 8 product icons. Press Cmd/Ctrl + 1..9 to switch scopes quickly using keyboard shortcuts.

Tip

If you type a section name (e.g., "Settings"), Global Search automatically surfaces all sub-pages under that section, making it easy to discover nested features without navigating through multiple menu levels. Breadcrumb paths show the full navigation hierarchy for each result.

Frequently Asked Questions

Q: Which products are currently included in Global Search V2?
Global Search V2 currently searches across 8 core products: contacts, opportunities, products, calendars, funnels, workflows, social planner, and conversations. Additional MxP products are being onboarded continuously to provide complete platform coverage.
Q: How do I enable Global Search V2?
Navigate to Labs > Subaccounts and enable the "Global Search V2" feature. Once enabled, click the search bar in the left sidebar (next to the ⌘K label) or press Cmd/Ctrl + K from anywhere at the subaccount level to access the search interface.
Q: Does Global Search V2 respect user permissions and role-based access?
Yes. Global Search enforces access control on the backend, filtering results by user roles, assigned-data-only permissions, feature flags, and deprecated features. You will only see records and pages you have permission to access.
Q: Can I search for platform pages as well as data records?
Yes. Global Search V2 indexes 530+ sidebar routes covering both agency and location levels, plus data records from 8 products. You can search for any navigable page in MxP, and results display with breadcrumb navigation paths showing the full menu hierarchy.
Q: What keyboard shortcuts are available in Global Search V2?
Press Cmd/Ctrl + K to open Global Search. Use arrow keys to navigate results and Enter to select. Press Cmd/Ctrl + 1..9 to switch search scopes, Tab to move between elements, and Esc to close the search interface. A keyboard shortcuts reference is displayed at the bottom of the search modal.
Q: Does Global Search V2 handle spelling mistakes?
Yes. Global Search uses fuzzy matching to handle spelling mistakes automatically. You don't need to type exact names or routes — the search will return relevant results even with approximate text.
Q: Can I filter search results to a single product?
Yes. Click any of the product filter pills (Contacts, Opportunities, Calendars, Funnels, Workflows, Social Planner, Products, Conversations) to narrow results to that specific product. You can also view all product icons in a grid by clicking the search bar, or use Cmd/Ctrl + number shortcuts to switch filters quickly.
Q: Are voice commands supported in Global Search V2?
Yes. Global Search V2 supports voice dictation with commands like "open [page name]" and "tab [product name]" for hands-free navigation. Click the microphone icon in the search bar to activate voice commands. Screen-reader announcements are also included for accessibility.
Q: Where is the Global Search trigger located?
The Global Search trigger is located in the left sidebar of MxP, displaying as a search bar with the keyboard shortcut "⌘K" next to it. Click the search bar or press Cmd/Ctrl + K from anywhere in the platform to open the search interface instantly.
