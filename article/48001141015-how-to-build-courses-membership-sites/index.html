How To Build Courses / Membership Sites
MxP Courses let you create, organize, publish, and sell online learning experiences from your sub-account. You can build course content, package courses into offers, choose free or paid access, and deliver the learning experience to customers through MxP. The updated Course Editor provides a focused workspace for managing modules, lessons, quizzes, assignments, and other course content. This guide covers the core process for creating and launching a course and points you to additional resources for advanced configuration.
What You'll Learn

Learn how to create a course, organize content with the current Course Editor, publish an offer, deliver course access through the Client Portal, automate enrollment, and find additional course training in MxP Training.

Important

Course upload limits vary by file type. Supported Course video formats currently allow files up to 5GB, while other file types can have lower limits. Review the Media Storage file-limit reference before uploading large course files.

What Are Courses and Membership Sites in MxP?

MxP Courses provide the tools to build and deliver structured online learning content. Course creators can organize content into modules and lessons, add videos and other learning materials, create offers, and provide free or paid access to learners.

Course creation and management are available under Memberships → Courses in the sub-account.

Learners can access membership courses through MxP's customer-facing experience, including the Client Portal.

Courses can also be made available through the Learning experience in MxP Communities when applicable.

2

Key Benefits of MxP Courses

MxP combines course creation, monetization, and customer access so businesses can manage learning experiences without separating course content from the rest of their customer journey.

  • Flexible Course Creation: Build structured courses with modules, lessons, videos, quizzes, assignments, and downloadable learning materials.
  • Focused Course Editing: Use the Course Editor's course map and editing workspace to navigate and organize course content efficiently.
  • Flexible Monetization: Create free, one-time, or recurring course offers based on how you want customers to access your content.
  • Automated Access: Connect purchases to course offers or use workflows to grant course access automatically.
  • Centralized Learner Experience: Customers can access courses alongside other supported resources through the Client Portal.
  • Community Learning Options: Courses can also be made available through the Learning area in MxP Communities.
3

Prerequisites and Limitations

Preparing your course content, access model, and payment configuration before building helps reduce setup changes later in the launch process.

Before creating a course, make sure:

  • You have access to Memberships → Courses in the appropriate sub-account.
  • Your course content is prepared, including videos, lessons, PDFs, quizzes, assignments, or other resources you plan to use.
  • You have a course thumbnail available if you want to add one.
  • A supported payment provider is connected if you plan to sell paid course access.
  • You know whether learners will receive free, one-time, or recurring access.

Current considerations include:

  • UI labels and button names can vary by account rollout.
  • Supported Course video formats have a maximum file size of 5GB.
  • Other Course file limits vary by file type.
  • Advanced access methods, Client Portal configuration, Communities, and workflow-based enrollment have separate configuration options and may require additional setup.

How To Set Up and Launch a Course

Creating the course establishes the learning product that contains your modules, lessons, and educational content. Build the course structure before publishing an offer so learners receive the intended experience.

Step 1: Open Courses

Start from the Courses product area so the new course is created inside the correct sub-account.

  1. From the Sub-Account View, click Memberships.
  2. Select Courses.
  3. Open Products.

Step 2: Start a New Course

Starting from scratch gives you a new course structure that you can configure with your own title, description, pricing, thumbnail, and learning content.

  1. Click Create New.
  2. Select Start from scratch.

Step 3: Enter the Course Details

Course details identify the learning experience and establish the initial configuration learners will see when accessing the course.

  1. Enter the Course Title.
  2. Enter the Course Description.
  3. Upload a course thumbnail if desired.
  4. Complete the available pricing and course settings.
  5. Click Create Course.

Build and Organize Your Course Content

A clear course structure helps learners move through your material in a logical order. The current Course Editor keeps the course map and selected content visible in one workspace, reducing the need to move between separate screens.

Open the Course Editor

Opening the editor gives you access to the course structure and individual content items from the same focused workspace.

  1. Go to Memberships → Courses → Products.
  2. Select the course you want to edit.
  3. Open the course editor.

Use the Course Map

The Course Map acts like a table of contents for the course and helps you move between content, reorganize items, and review supported status information.

  • Use the Course Map on the left to review the course structure.
  • Select lessons, quizzes, assignments, or other supported content to edit them.
  • Use drag-and-drop controls to reorganize supported content.
  • Expand or collapse modules to focus on a specific portion of the course.
  • Review supported content status information and quick actions.

Course media: Supported Course video formats currently allow files up to 5GB. Other Course file types can have different upload limits.

Create and Publish a Course Offer

An offer determines how learners receive access to your course. After the course content is ready, create an offer to package one or more courses for free or paid distribution.

Step 1: Open Offers

Offers package your course content into the access option that learners will receive.

  1. Go to Memberships → Courses.
  2. Open Offers.
  3. Click + Create Offer.

Step 2: Configure the Offer

Offer configuration determines which course products are included and how learners are charged for access.

  1. Enter the offer details.
  2. Select the course product or products you want to include.
  3. Configure the available pricing for the offer.
  4. Click Create or Save, depending on the current interface.

Step 3: Publish the Offer

Publishing makes the configured offer available for supported sales and access workflows.

  1. Open the offer after creating it.
  2. Review the attached course products and pricing.
  3. Change the offer from Draft to Published.
  4. Save the offer.

After publishing the offer, review and test the learner experience before distributing it. A separate Payments product can also be linked to a published Membership Offer when your sales flow requires it. Only published membership offers appear when selecting an offer for that configuration.

Course Access and the Client Portal

The Client Portal gives customers a centralized place to access supported resources associated with your business, including membership courses. Using the Client Portal can provide a consistent customer-facing location for course access alongside other supported client experiences.

Configure Client Portal Settings

Client Portal settings control supported customer-facing branding, domain, authentication, language, and portal behavior.

Go to: Sub-Account View → Memberships → Client Portal → Settings

From Client Portal settings, businesses can manage supported options such as branding, domain configuration, language settings, authentication options, and other portal settings.

Automate Course Access

Workflows can grant course access automatically when a contact meets the trigger and conditions you configure.

Use the Course Grant Offer workflow action to grant access to an existing course offer when the appropriate automation conditions are met.

Legacy Memberships: Businesses migrating from Legacy Memberships should review the dedicated Client Portal migration guidance before changing their existing course-access experience.

8

Access Course Training from MxP Training

MxP Training provides additional guided training for users who want a video-based walkthrough of creating courses and building offers. The Course Creator's Playbook is available from the University area of an Agency account.

  1. From Agency View, click University.
  2. Click Go to MxP Training.
  3. MxP Training opens in a new browser tab.
  4. In the top navigation menu, click Learning.
  5. Locate The Course Creator's Playbook.
  6. Click Open to begin the course.

Frequently Asked Questions

Q: Can I include multiple courses in one offer?
Yes. Course offers can package one or more membership courses so learners can receive access through the configured offer.
Q: Can I give someone access to a course without requiring a purchase?
Yes. MxP workflows support the Course Grant Offer action, which can grant contacts access to an existing course offer based on the workflow's trigger and conditions.
Q: Can I add captions or subtitles to course videos?
Yes. MxP supports .srt subtitle files for course videos. Multiple subtitle languages can be added, and supported subtitle content can be edited inside MxP.
Q: Can courses be offered through MxP Communities?
Yes. MxP Communities includes a Learning experience where supported courses can be offered to community members, including supported paid-course configurations.
Q: Can learners access courses without entering a password every time?
MxP supports customer-specific Magic Links for supported course and Client Portal access. Magic Links authenticate the intended customer but do not grant course access by themselves; the customer must already have permission to the content.
Q: Where should I check the latest upload limits for course files?
Review the Media Storage File Types, Limits & Advanced Features article. Upload limits differ by file type and MxP product.
