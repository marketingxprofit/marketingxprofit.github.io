Getting Started - Launch a Website From Template

Launching a website in MxP involves building the site, connecting and assigning a domain, and publishing the final version. Following this order helps prevent broken URLs, unpublished changes, and domain errors. Complete the final checklist before sharing the website with visitors.

What Is a Website Launch in MxP?

A website launch moves your saved website from a draft to a live version that visitors can access through an assigned domain. Save stores your latest changes without updating the public website, while Publish makes the saved version live.

Key Benefits of Following the Correct Launch Process

A structured launch process helps ensure your website is complete, accessible, and ready for visitors.

  • Clear setup: Complete each launch task in the correct order.

  • Safer publishing: Review changes before making them public.

  • Branded web address: Connect the website to your own domain or subdomain.

  • Fewer launch issues: Verify the domain, pages, forms, and mobile layout before sharing the site.

Before You Begin

Preparing your website content and domain access in advance helps prevent delays during setup.

Confirm that you have:

  • Access to the MxP sub-account containing the website.

  • Your logo, images, written content, and required pages.

  • A domain purchased through MxP or another domain provider.

  • Access to your domain provider’s DNS settings when manual setup is required.

  • A decision to use a root domain, such as example.com, or a subdomain, such as www.example.com.

  • A designated homepage and URL paths for the remaining pages.

Important: DNS changes may take up to 24 hours to update. MxP automatically provisions SSL after the domain is connected and the required DNS records are verified.

How To Set Up and Launch a Website on Your Domain

A successful website launch follows five steps: create, customize, connect, assign, and publish.

Step 1: Create the Website

Creating the website establishes the design and page structure you will customize before launch.

  1. Go to Sites → Websites.

  2. Click + New Website.

  3. Choose a starting point:

    • From Blank: Build the website from scratch.

    • From Templates: Start with a prebuilt design.

  4. Enter the website name.

  5. Click Create.

  6. When using a template, preview the available designs and select the one you want to use.




Step 2: Customize and Save the Website

Reviewing the content and responsive layouts before connecting the domain helps prevent incomplete pages from reaching visitors.

  1. Open each page in the Website Builder.

  2. Update the text, images, colors, navigation, buttons, forms, and other elements.

  3. Confirm that navigation links point to the correct pages.

  4. Review the desktop and mobile layouts.

  5. Use Preview to test the page as a visitor.

  6. Add the page title and meta description under the page’s SEO settings.

  7. Click Save.

Important: Saving does not update the public website. The saved version becomes live only after you click Publish.


Step 3: Connect the Domain

Connecting the domain allows MxP to verify that the website address points to the correct location.

  1. Exit the Website Builder.

  2. Open the website’s Settings tab.

  3. Under Domain, click Connect Domain.


  1. If MxP opens the Domains page, click + Connect a domain.

  2. Select Connect beside Funnel/Website/Store/Blog/Webinar.

  1. Enter the root domain or subdomain visitors will use.

  2. Click Continue.


  1. Complete the connection using the option MxP provides:

    • Automatic connection: Sign in to the supported domain provider and authorize MxP to add the required records.

    • Manual connection: Copy the DNS records provided by MxP and add them through your domain provider.

  2. Wait for the domain to show as connected or verified.

Cloudflare users: Set the website’s A or CNAME record to DNS only, not Proxied.

Domain still pending? Allow up to 24 hours for DNS changes. After that, compare every record with the values provided by MxP and remove conflicting records.


Step 4: Assign the Domain to the Website

Assigning the connected domain links the verified address to the correct website.

  1. Return to Sites → Websites.

  2. Open the website.

  3. Select the Settings tab.

  4. Open the Domain dropdown.

  5. Select the connected domain.


  1. Review the Path:
    • Keep a path such as /services when the website should open at example.com/services.

    • Use the intended homepage as the domain’s default page when it should open directly at example.com.

  2. Scroll to the bottom and click Save.

Step 5: Publish the Website

Publishing makes the current saved version available through the assigned domain.

  1. Return to the Website Builder.

  2. Preview the page one final time.

  3. Click Save.

  4. Click Publish.

  5. Publish every page that should be available on the live website.

Final Live-Site and Domain Verification Checklist

Opening the website in a private browser window confirms what visitors will experience without cached data or an active MxP session.

  • The domain shows as Connected, Verified, or Active in MxP.

  • The public URL opens in an incognito or private browser window.

  • The site loads over https:// without a security warning.

  • The correct homepage appears instead of a 404 page.

  • The root and www versions behave as intended.

  • Navigation links and buttons open the correct pages.

  • Forms, calendars, popups, and checkout elements work when applicable.

  • A test form submission creates the expected record or notification.

  • The desktop and mobile layouts display correctly.

  • The latest published content appears on the live website.

  • No placeholder text, template images, test prices, or broken links remain.


Frequently Asked Questions

Q: Why does the live website still show old content?

The latest version may have been saved but not published. Open the affected page, click Publish, and test the URL in an incognito window.

Q: Why is my domain still pending?

DNS changes may still be updating, or a record may not match the value provided by MxP. Allow up to 24 hours, then review the record type, host, and value.

Q: Why does the website display an SSL or privacy warning?

Check for incorrect or conflicting DNS records. Cloudflare records should be set to DNS only. After correcting the records, allow time for MxP to issue the SSL certificate.

Q: Why does the domain open a 404 page?

Confirm that the domain is assigned to the correct website, the intended page is published, and the default page or URL path is configured correctly.

Q: What should I do if automatic domain connection is unavailable?

Use the manual connection option and add the exact DNS records displayed by MxP through the provider managing your domain.

Q: Do I need to verify a domain purchased through MxP?

No. Domains purchased through MxP are automatically verified. Configure them under Settings → Domains → Purchased Domains.
