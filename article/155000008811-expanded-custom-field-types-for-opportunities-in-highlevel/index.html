Expanded Custom Field Types for Opportunities in MxP

Expanded custom field types are now supported for Opportunities in MxP, giving teams more flexibility to capture and manage deal-specific information. Store proposal URLs, contract dates, formatted deal summaries, team assignments, and visual service selections directly on opportunity records. These fields also support Opportunity List View columns and Advanced Filters, making deal information easier to organize and access.

This update is available for Contacts earlier, now its available in oppurtunities.

What Are Expanded Custom Field Types?


Expanded custom fields provide additional options for collecting, validating, and displaying information in MxP. Previously available for Contacts, these capabilities now extend to Opportunities, allowing you to manage important deal information without relying on contact fields or unstructured notes.


The expanded field types include URL, Date & Time, Rich Text, User, and visual Checkbox and Radio Select options.

Key Benefits of Expanded Custom Fields for Opportunities and Contacts


Expanded custom fields help teams maintain accurate information, collaborate on deals, and quickly identify important opportunity details.

  • Centralized Deal Information: Store proposal links, contract dates, and deal summaries directly on opportunities.

  • Better Team Collaboration: Associate multiple team members with deals using User fields.

  • Flexible Formatting: Organize detailed deal information using Rich Text.

  • Visual Selections: Use images and icons to identify services, priorities, and categories.

  • Improved Pipeline Visibility: Display custom fields in List View and use Advanced Filters.

  • More structured URL collection: Capture website addresses, profile URLs, resource links, and other URLs using a dedicated field with domain controls.

  • Greater control over dates and times: Choose whether a field captures a date and time, date only, or time only, and control which dates can be selected.

  • Improved team collaboration: Use Users fields to associate one or multiple team members with a record and provide selected users with follower-level access.

  • More recognizable radio choices: Add images or icons to radio button options when users need to select a single choice.

  • Mobile Field Updates: View and edit supported custom fields directly on contact and opportunity records in the mobile app.

Supported Custom Field Types and Configuration Options


Each expanded field type offers different configuration options to help capture information in the most appropriate format. Selecting the right field type improves consistency and makes opportunity details easier to review.

Field TypeConfiguration OptionsOpportunity Use Case
URLAllow all domains, allow only specified domains, or block specified domainsProposal and contract links
Date & TimeDate only, time only, or both; past/future dates, date ranges, and weekdaysContract start dates and project deadlines
Rich TextText formatting, headings, lists, links, and emojisDeal summaries and scope notes
UserSingle-user or multiple-user selectionSales and implementation teams
CheckboxText with image; multiple selectionsServices included in a deal
Radio SelectText with image or icon; single selectionDeal priority or service package


Important Configuration Details

  • URL Validation: URLs that violate domain restrictions are rejected with the message: "This URL isn't allowed. Use an allowed domain."

  • Date Restrictions: Future Dates Only excludes today. Select Any Date if today's date should be allowed.

  • Rich Text: Supports bold, italics, underline, strikethrough, colors, highlighting, lists, links, emojis, and headings using # or ##.

  • User Fields: Selected users receive follower-level access without becoming the opportunity owner. The Allow multiple users setting cannot be changed after field creation.

  • Visual Options: Checkbox fields support images, while Radio Select fields support images or icons.



For additional details about field configuration, mobile editing, and snapshot support, see Expanded Custom Field Types and Configuration Options.

Mobile and Snapshot Support


Expanded custom fields can also support mobile record management and reusable configurations across MxP locations. This helps teams maintain consistent information when working from different devices or setting up new sub-accounts.

  • Mobile: Supported expanded fields can be viewed and edited on Contact and Opportunity records in the mobile app. Configured validation rules also apply.

  • Snapshots: Supported expanded custom fields and configurations, including URL restrictions, date settings, and visual options, can be included in snapshots.

How to Set Up Expanded Custom Fields for Opportunities


Creating custom fields under the Opportunity object ensures information is associated with the correct deal. Configure field restrictions and selection settings before saving, especially for User fields where multiple-user selection cannot be changed later.

  1. Navigate to Settings > Custom Fields.

  2. Select Opportunity and click Create Field.



  3. Choose URL, Date & Time, Rich Text, User, Checkbox, or Radio Select.



  4. Configure the field name and applicable settings. For visual options, choose Text with image for Checkbox or Text with image / Text with icon for Radio Select.

  5. Choose a folder and click Create custom field.

  6. Navigate to Opportunities, open a deal, and populate the new field in its Fields area.

How To Set Up Expanded Custom Fields


Properly configuring the field type and its available settings helps ensure users capture information in the format your business process requires. Custom fields are managed from the Custom Fields area, where you can select the appropriate object and configure the field based on its intended use.

  1. Go to Settings.


  2. Select Custom Fields.

  3. Select the object where you want to create the custom field.

  4. Click Create Field or the available option to create a new custom field.


  5. Select the field type appropriate for the information you want to capture.

  6. Configure the field name and other applicable field settings.

  7. Configure any settings specific to the selected field type:

    • For a URL field, configure the appropriate domain controls.

    • For a Date and Time field, select the required date/time format and applicable date restrictions.

    • For a Rich Text field, create the field for content that requires supported text formatting.

    • For a Users field, configure it based on whether the record should associate the applicable user or users.

    • For a Checkbox field, add images to applicable individual options when visual choices are needed.

    • For a Radio field, add images or icons to applicable individual options when visual context is needed.


  8. Review the field configuration and available preview.

  9. Save the custom field.

Important: Custom field availability can vary based on the object or area where the field is being used. Confirm that the selected field type is available for the intended object and use case before building a process around it.

Display and Filter Custom Fields in Opportunity List View


Expanded custom fields can be added as columns in Opportunity List View and used with Advanced Filters. This makes it easier to review deal information and locate opportunities based on their custom field values.


To display custom fields:

  1. Navigate to Opportunities > List View.

  2. Open Manage Fields.

  3. Select the custom fields you want to display as columns.


To filter opportunities:

  1. Open Advanced Filters in Opportunities.

  2. Select the appropriate custom field.

  3. Choose an available filter condition and value.

  4. Apply the filter to view matching opportunities.


Filter operators vary by field type, and column visibility does not necessarily mean the field supports sorting.

Public API Support for Expanded Custom Fields


MxP's public APIs now support the expanded custom field types, allowing developers and integration partners to create, retrieve, and update custom fields programmatically. This enhancement makes it easier to work with custom fields across external applications, integrations, and automated processes.


Supported Custom Field Types


Public API support is available for the following six custom field enhancements:

  • URL Fields: Create, retrieve, and update URL custom fields, including configurations with domain restrictions.

  • Date and Time Fields: Work with Date & Time, Date Only, and Time Only custom fields.

  • Rich Text Fields: Manage rich text custom fields through public APIs.

  • Users Fields: Work with custom fields configured for single-user or multiple-user selections.

  • Checkbox Fields with Images: Work with checkbox custom fields that include image-based options.

  • Radio Button Fields with Images: Work with radio button custom fields that include image-based options.


API Documentation


Developers can use the following API endpoints to work with supported custom fields:

  • Create Custom Field

  • Get Custom Fields

  • Get Custom Field

  • Update Custom Field


Refer to the API documentation for supported request parameters, field configurations, and response formats.

Frequently Asked Questions


Q: Why can't I see the expanded custom field types for Opportunities?

These capabilities are part of the Opportunity-First private beta. Confirm that your location is enabled.


Q: Can I change a User custom field to allow multiple users after creation?

No. Allow multiple users must be enabled before creating the field.


Q: Does adding users through a User custom field change the opportunity owner?

No. Selected users receive follower-level access, but ownership remains separate.


Q: Why can't I select today's date in a Date & Time field?

Future Dates Only excludes today. Use Any Date or a suitable date range if today should be selectable.


Q: Can I use these fields in Opportunity List View and Advanced Filters?

Yes. The expanded field types can be displayed as List View columns and used with Advanced Filters. Available filtering options depend on the field type.


Q: Can I convert an existing Contact custom field into an Opportunity custom field?

No. Custom fields are associated with the object selected during creation. Create a new field under Opportunity to store the information directly on deals.
