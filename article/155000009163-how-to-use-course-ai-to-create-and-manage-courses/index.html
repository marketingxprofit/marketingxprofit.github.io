How to Use Course AI to Create and Manage Courses

Course AI helps you create courses in MxP using simple prompts and existing materials. You can generate course outlines, modules, lessons, quizzes, assignments, and images, then customize everything before sharing it with learners.


This article covers how to create a course with Course AI and use its tools throughout the Course Builder.

How to Create a Course with Course AI


  1. Go to Memberships > Courses > Products.



  2. Click Create New > Start from scratch to open Course AI.



  3. Choose a course type:

    • Self-paced skill course

    • Mini-course / lead magnet

    • Daily bootcamp / challenge

    • Certification program

    • Recording library / vault

  4. Describe your course, including the topic, target audience, and what learners should achieve.

  5. Optionally, attach images, PDFs, or public reference links. You can also use voice input.

  6. Submit your prompt to generate a course outline.

How to Customize Your Course Outline


Course AI Studio displays your conversation on the left and a live course outline on the right.


You can refine the course before creating it.


  1. Review the generated course title, description, modules, lessons, and quizzes.

  2. Use the chat to request changes or select suggested follow-up responses.

  3. Edit or delete titles, modules, and lessons as needed.

  4. Use AI rewriting options such as Clarify, Rephrase, Make specific, or Shorten to improve titles.

  5. Generate a course cover image or upload your own.

  6. Click Confirm when you're satisfied with the outline.

How to Generate Lesson Content from Videos


Course AI can analyze newly uploaded or imported lesson videos and suggest supporting content based on their transcripts.


  1. Open your course and select a lesson.

  2. Upload or import a lesson video.

  3. Once Course AI has processed the video, review the suggestions in the Course AI panel.

    Depending on the video's content, suggestions can include:

    • Lesson description: A summary of the video.

    • Quiz questions: Questions based on important moments in the lesson.

    • Downloadable PDF recap: A summary learners can save for reference.

  1. Click Accept beside an individual suggestion, Accept all to use every suggestion, or Dismiss to skip one.

  2. Save your changes using the available save or publishing option.


Accepted PDF recaps are added to the lesson's downloadable resources.


Note: Automatic transcript-based suggestions are available only for newly uploaded or imported videos.



How to Write or Edit Lesson Descriptions with AI


You can use Course AI to create descriptions or improve text you've already written.


  1. Open a lesson in the Course Builder.

  2. If the description is empty, use Course AI to generate one from the lesson title or an available video transcript.

  3. If the description already contains text, open the AI Edit options.

  4. Enter your own editing instructions or choose a quick edit:

    • Rewrite

    • Make it shorter

    • Make it longer

    • More professional

    • More casual

  5. Review the updated description and save your changes.


How to Generate Quiz Questions with AI


Course AI can generate quiz questions from an individual lesson, an entire module, or the whole course.


  1. Open a quiz in the Course Builder and choose Generate quiz questions.

  2. Select the source content you want AI to use.

  3. Choose a Question type:

    • Single choice

    • Multiple choice

    • Mix

  4. Select the difficulty: Easy, Medium, or Hard.

  5. Set the Number of questions (1–20).

  6. Click Generate, review the questions, and save your changes.


You can edit the generated questions before making the quiz available to learners.


How to Generate Thumbnails with AI


You can create AI-generated thumbnails for lessons, quizzes, and assignments.

  1. Open the lesson, quiz, or assignment you want to update.

  2. Access its AI thumbnail generation option.

  3. Describe the image you want to create.

  4. Choose a style:

    • Photographic

    • Illustrated

    • Bold text overlay

    • Minimal

  5. Click Generate.

  6. Review the image and save your selected thumbnail.

Important Things to Know


  • File limits: You can attach up to 5 files, with a maximum size of 25 MB per file, when providing materials for course creation.

  • Reference links: URLs must be public and accessible to AI.

  • Video processing: Automatic lesson content suggestions work with newly uploaded or imported videos only.

  • AI content: Generated outlines, descriptions, quizzes, and images can be reviewed and edited.

  • Manual creation: Select Skip and set up manually if you prefer to build your course without AI.


Once your course content is ready, review its settings, preview the learner experience, and complete the necessary publishing and access setup.
