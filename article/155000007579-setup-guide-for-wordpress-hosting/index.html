What is the WordPress Hosting Setup Guide?


The WordPress Hosting Setup Guide is an in-app onboarding checklist that appears after a new WordPress Hosting subscription. It helps users complete the most important setup actions in the right order, with clear calls to action, progress tracking, and in-app guidance along the way. This makes it easier to understand what to do next, whether you are creating a brand-new site or bringing over an existing WordPress website.

The Setup Guide is designed to help users move through key setup milestones, including site creation, migration, domain connection, SSL readiness, logs, user management, and analytics. Once all setup steps are completed, the guide hides automatically, while the related areas remain accessible from the WordPress Dashboard.

Key Benefits of the WordPress Hosting Setup Guide


Understanding the value of the Setup Guide helps users move through onboarding with less confusion and fewer missed steps. Instead of searching across multiple areas of the platform, users can follow a guided path that highlights the actions most likely to help them get their WordPress site live and usable sooner.


  • Guided onboarding: Helps users follow a clear sequence of setup tasks after subscribing to WordPress Hosting.

  • Faster time-to-value: Reduces uncertainty by showing what needs to be done next and where to do it.

  • Flexible setup flow: Supports both new site creation and importing an existing WordPress site.

  • Progress visibility: Uses progress tracking so users can quickly see what has already been completed.

  • Centralized next steps: Connects users to key setup areas like domains, logs, users, and reports from one onboarding experience.

Setup Guide Steps


Each step in the Setup Guide is meant to help users complete an important part of WordPress Hosting setup without needing to guess the next action. Some steps help launch a new site, while others support migration, security, access management, and performance visibility.


Create Site


Creating a site is the first step for users who are starting from scratch in WordPress Hosting. This gives you a place to begin building your website and may also include setup choices such as site type, plugin selection, and server location depending on your workflow.


  • Choose the type of site you want to create.

  • Continue through the creation flow to generate your WordPress site.

  • Complete any initial setup selections presented during site creation.



Import Your Existing Site


Importing a site is helpful for users who already have a WordPress website and want to move it into MxP WordPress Hosting. This step supports migration-based onboarding so users do not need to rebuild an existing site manually.

  • Use the importer if you want to migrate an existing WordPress site.

  • Follow the migration prompts to move your current site into MxP.

  • Review the imported site after migration is complete.


Related article: Getting Started - Migrate a Wordpress Site


Log in to Your WP Admin Dashboard


Access to WP Admin helps connect users to the WordPress administration experience for site management tasks. This is useful for editing content, managing plugins, handling settings, and working within the WordPress environment connected to MxP Hosting. Single sign-on access may also be available depending on your setup.


  • Open your WP Admin Dashboard from the Setup Guide.

  • Use your admin access to manage your WordPress site directly.

  • Return to the Setup Guide to continue the next onboarding steps.


Related article: WordPress: Single Sign On Admin


Customize Your Domain and SSL


Connecting a domain is a key step toward making your WordPress site publicly accessible under your own branding. SSL helps secure the site after the domain is properly connected and verified, which is why domain setup and SSL are closely tied in the WordPress Hosting experience.


  • Add a custom domain or confirm your assigned subdomain settings.

  • Complete any required DNS updates for your domain connection.

  • Verify that the domain is connected successfully so SSL can be issued and confirmed.


Related articles: How to Add a Domains to a WordPress Site in MxP, WordPress: Domain Connect Integration



Enable Access & Activity Logs


Access & Activity Logs help improve visibility into what is happening on your WordPress site. They are useful for monitoring activity, identifying issues, and supporting a more secure hosting experience over time.


  • Turn on logs for your WordPress site.

  • Review available activity and access information from the logging area.

  • Use logs to monitor important actions and investigate unexpected behavior.


Related article: WordPress Access & Activity Logs



Manage Users and Permissions


User and role management helps keep site access organized and secure. Adding the right users with the right permissions makes collaboration easier while reducing the risk of giving unnecessary access.


  • Add new WordPress users as needed.

  • Assign the appropriate role, such as Editor or Admin.

  • Review permissions before inviting users or changing access levels.


Explore Site Analytics and Reports


Analytics and reports help users understand how a WordPress site is performing after setup. Reviewing traffic and performance data can support better decisions around content, optimization, and ongoing site management. The current Setup Guide article also points users to a WordPress Website Performance Report resource for deeper reporting context.


  • Open the analytics or reporting area from the Setup Guide.

  • Review available traffic and performance insights.

  • Use reporting data to monitor site health and engagement over time.


Related article: WordPress Website Performance Report

How To Setup the WordPress Hosting Setup Guide


A guided setup flow is most useful when users know where to find it and how to move through it intentionally. Completing the checklist in order can help avoid missed dependencies, especially for steps like migration, domain verification, SSL, and user access.


  1. Subscribe to WordPress Hosting in MxP. The Setup Guide appears after a new subscription.

  2. Navigate to the guide:

    • If no site has been created yet, go to Sites → WordPress Dashboard → Setup Guide.

    • If a site already exists, go to Sites → WordPress Dashboard → Go to Site → Setup Guide.

  3. Start with Create Site if you are building a new website.

  4. Use Import Your Existing Site if you want to migrate an existing WordPress website instead of starting from scratch.

  5. Open your WP Admin Dashboard to manage your WordPress site.

  6. Complete Domain and SSL setup so your site can use your preferred domain and secure connection.

  7. Turn on Access & Activity Logs for visibility into actions and site activity.

  8. Add users and assign the correct permission levels for your team.

  9. Review Analytics and Reports to begin monitoring site performance.

  10. Continue until all checklist items are complete. The Setup Guide will hide automatically after completion, and you can still access key areas from the WordPress Dashboard.

Frequently Asked Questions


Q: Does the Setup Guide appear for every new WordPress Hosting subscription?
A: The Setup Guide is designed to appear after a new WordPress Hosting subscription to help users complete the initial setup workflow.


Q: Do I need to complete every step in one session?
A: No. The guide uses progress tracking so you can complete steps over time and keep track of what is already done.


Q: Is importing a site required?
A: No. Importing is useful only if you already have a WordPress site you want to migrate into MxP. Users creating a brand-new site can start with Create Site instead.


Q: Can I still access setup areas after the guide disappears?
A: Yes. Areas such as Domains, Users, and Analytics remain accessible from the WordPress Dashboard after the guide is completed.


Q: Does SSL work automatically as soon as I add a domain?
A: SSL depends on a successful domain connection and verification. In practice, DNS and verification status affect 

when SSL can be issued and confirmed.


Q: What are Access & Activity Logs used for?
A: They help track user actions and access-related activity so you can monitor changes, investigate issues, and support site security.


Q: Can I add more users to help manage the site?
A: Yes. The Setup Guide includes a user and permissions step so you can add WordPress users and assign appropriate roles such as Editor or Admin.


Q: When will analytics and reports start showing useful data?
A: Reporting becomes more useful as traffic and site activity build over time. After setup, review the available analytics regularly to track performance trends.
