CRM Loading States: Troubleshooting Lags and Impact of Custom CSS and JS

MxP uses loading indicators to show when the CRM is initializing, retrieving data, or switching between sub-accounts. If a page takes too long to load, browser issues, custom CSS/JavaScript, or account access settings may be contributing factors.

Types of CRM Loading States

  • Initializing the App: Appears when the CRM or a new page starts loading.

  • Loading Fresh Data: Indicates that updated information is being retrieved.

  • Retrieving Sub-account Details: Appears when switching between sub-accounts or loading account information.

  • Infinite Loading: Occurs when a page remains stuck on the loading screen. A refresh option may appear to help reload the page.

How Custom CSS and JavaScript Affect Loading


Custom CSS or JavaScript may interfere with CRM loading behavior.

  • Custom CSS: May override loading indicator styles, affecting their appearance or animations.

  • Custom JavaScript: May interfere with page functionality or prevent loading actions from working correctly.


Temporarily disable custom code, where possible, to identify potential conflicts.

Troubleshooting CRM Loading Issues


Step 1: Refresh the Page


If the CRM remains stuck loading, use the available refresh option or reload the browser page.


Step 2: Clear Browser Site Data


If refreshing does not resolve the issue:

  1. Open the browser's Developer Tools by right-clicking and selecting Inspect.

  2. In Chrome, navigate to Application → Storage.

  3. Select Clear site data.

  4. Reload the CRM and sign in again if required.


Note: Clearing site data may remove locally stored settings and sign you out.


Step 3: Verify Sub-account Access


If a user cannot access the CRM:

  1. Switch to Agency View.

  2. Navigate to Settings → Team.

  3. Locate the affected user and open their settings.

  4. Review their assigned roles and sub-account access.

  5. Ensure the user has access to the appropriate sub-account.


If you do not have permission to manage users, contact your agency administrator.


Step 4: Check Custom CSS and JavaScript


If loading issues continue, review recently added custom CSS or JavaScript. Temporarily disable the relevant code and test whether the CRM loads correctly.

Frequently Asked Questions


Q: Why does my CRM keep loading?

A: This may happen because of browser data, custom code conflicts, or account access issues.


Q: What should I do if refreshing doesn't work?

A: Clear browser site data, verify account access, and check whether custom CSS or JavaScript is interfering.


Q: Can custom CSS affect the loading screen?

A: Yes. Custom CSS can override loading styles and animations.
