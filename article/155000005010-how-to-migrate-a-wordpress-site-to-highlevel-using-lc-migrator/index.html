How to Migrate a WordPress Site to MxP Using LC Migrator

Migrating your WordPress website to MxP is easier with LC Migrator. Instead of manually creating backups and transferring large files, you can migrate your website through a streamlined process. LC Migrator transfers your website files, database, and settings while keeping your original site accessible during migration.

What is LC Migrator?


LC Migrator is a WordPress plugin that simplifies transferring existing WordPress websites to MxP WordPress Hosting. It automates the migration process, reducing manual work and helping agencies move websites more efficiently.


MxP offers two migration options:

  • LC Migrator: Self-service migration using the LC Migrator plugin.

  • White-Glove Migration: Assisted migration handled by MxP's migration specialists.

Key Benefits of LC Migrator


LC Migrator simplifies website transfers while providing visibility into migration progress and reducing the need for manual file management.

  • Easy Migration: Transfer websites without manually downloading and uploading backups.

  • Minimal Downtime: Keep your original website live during migration.

  • Complete Transfer: Migrate website files, database, and settings.

  • Progress Tracking: Monitor migration progress through the plugin.

  • No Plugin File-Size Limit: Migrate larger websites, subject to your hosting plan's resources.

  • White-Glove Assistance: Request expert migration support when needed.

LC Migrator Migration Options


MxP provides two migration methods based on whether you prefer to manage the transfer yourself or request assistance.


Self-Service Migration


Use LC Migrator to initiate and monitor your WordPress migration. The plugin handles transferring website content and settings to MxP.


White-Glove Migration


Agency users can request an assisted migration from MxP's migration team. Most migrations are completed within 1–3 business days, depending on website size and complexity.

Migration Progress Tracking


LC Migrator displays migration progress so you can monitor the transfer and identify when the website is ready for review.

  • View migration progress through the plugin.

  • Open the migrated website using View Your New Website after completion.

  • Agency users can access migration failure notifications and logs.

How to Set Up and Use LC Migrator


Proper setup helps ensure your WordPress website is transferred to the correct MxP hosting environment. You'll need agency access, administrator access to the existing WordPress website, and an appropriate WordPress Hosting destination.


Step 1: Download LC Migrator

  1. Log in to your MxP agency account.

  2. Navigate to Sites → WordPress.

  3. Start a new migration and select LC Migrator.

  4. Download the LC Migrator plugin.


You can also obtain the plugin from the MxP Plugin Hub.


Step 2: Install the Plugin

  1. Log in to your original WordPress website.

  2. Navigate to Plugins → Add Plugin → Upload Plugin.




  3. Upload the LC Migrator .zip file.

  4. Click Install Now, then Activate Plugin.


Step 3: Start the Migration

  1. Return to the MxP migration workflow.

  2. Log in to the CRM when prompted.

  3. Select your destination WordPress site.


  4. Click Start migration.

  5. Monitor the progress bar until the transfer finishes.


Step 4: Verify Your Website


After migration finishes:

  1. Click View Your New Website.

  2. Check your pages, images, navigation, and links.

  3. Test forms, plugins, and other important functionality.

  4. Configure your domain and SSL settings if needed.


Important: Keep your original site accessible until you've verified the migrated website. DNS changes are separate from the migration process.

How to Request White-Glove Migration


White-Glove Migration allows agencies to request assistance without sharing WordPress administrator passwords. The LC Migrator plugin generates a temporary, revocable link that provides secure access to the source website.


Step 1: Generate a Secure Access Link

  1. Install and activate LC Migrator on the original WordPress site.

  2. Open LC Migrator in WordPress.

  3. Click Generate secure access link.

  4. Select the link duration and confirm.


Secure links are valid for 24 hours to 7 days, with a default of 3 days. Links generated Friday through Sunday have a minimum duration of 4 days.


Step 2: Submit Your Request

  1. Navigate to Sites → WordPress in MxP.

  2. Start a new migration and select White-Glove Migration.


  3. Complete the request form.

  4. Paste your secure access link.

  5. Submit the migration request.


Step 3: Monitor and Complete Migration


Track your request through the WordPress Hosting dashboard. After the migration finishes, review your website and revoke the secure access link if it is no longer needed.


Note: Only one secure access link can remain active at a time. Generating a new link invalidates the previous one.

Frequently Asked Questions


Q: Does LC Migrator have a file-size limit?

No. The plugin does not impose a migration file-size limit, but your hosting plan's storage limits still apply.


Q: Will my original WordPress website remain live during migration?

Yes. The original website remains available during the transfer. Domain changes may require separate configuration.


Q: Does LC Migrator automatically transfer my domain?

No. Website migration and domain configuration are separate processes.


Q: What happens if my migration fails?

Agency users can review migration failure alerts and logs. Contact MxP Support if additional assistance is required.


Q: Is LC Migrator the same as the MxP WordPress plugin?

No. LC Migrator transfers WordPress websites, while the standard MxP plugin integrates WordPress with MxP CRM features.


Q: Can I revoke a White-Glove secure access link?

Yes. Open LC Migrator in WordPress and select Revoke to disable the active link.
