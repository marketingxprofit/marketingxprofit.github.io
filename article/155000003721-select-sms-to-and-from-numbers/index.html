Select SMS To and From Numbers

Conversations • SMS • Phone Numbers
Select SMS To and From Numbers in Conversations
MxP lets you choose both the business phone number that sends an SMS and the contact phone number that receives it. This is especially useful when a sub-account has multiple messaging numbers or a contact has more than one phone number. When you do not manually choose a sender, MxP uses sender-priority rules to keep conversations consistent.
What You'll Learn

Learn how MxP chooses an SMS sender, how to manually select From and To numbers in Conversations, how multiple contact numbers behave, and how to verify the sender used for a message.

Important

Manually selecting a From number takes priority over automatic sender selection. The selected number must still belong to the applicable sub-account, support SMS, and meet applicable messaging registration and compliance requirements.

What Are SMS To and From Numbers?

The From number is the business phone number MxP uses to send an SMS. The To number is the contact phone number receiving the message.

When multiple eligible numbers are available, the Conversations composer lets you choose the appropriate sender and recipient before sending.

If you do not manually select a From number, MxP uses its sender-priority rules to determine which business number should send the message.

2

Key Benefits of Selecting SMS Numbers

Choosing the correct sender and recipient helps keep SMS conversations accurate when businesses or contacts use multiple phone numbers.

  • Choose the Correct Business Identity: Send from the appropriate business number when a sub-account has multiple numbers.
  • Maintain Conversation Continuity: MxP can continue using the number already associated with the conversation.
  • Support User-Specific Numbers: A number assigned to the sending user can be selected automatically.
  • Reach the Correct Contact Number: Choose between a contact's saved numbers when multiple options are available.
  • Override Automatic Selection: Manually choosing a From number takes priority over automatic sender selection.
3

Prerequisites and Limitations

Valid sender and recipient numbers, correct permissions, and applicable messaging compliance help prevent SMS failures or unexpected sender selection.

  • The From number must belong to the relevant sub-account.
  • The selected From number must support SMS.
  • The contact must have a valid phone number.
  • If a contact has multiple phone numbers, review which number is marked Primary.
  • Applicable messaging registration, compliance, DND, and opt-out requirements still apply.

Keep in mind: Workflow and bulk-SMS sender selection use their own configuration. The sender behavior in this article focuses primarily on manual SMS messages sent from Conversations.

4

How MxP Chooses the From Number

MxP follows a sender-priority order when deciding which business number should send an SMS. Understanding this order helps explain why a message may come from a different number than expected.

Sender Priority: Manually selected From number → number assigned to the sending user → number already associated with the conversation → default outbound number.

1. Manually Selected From Number

If you explicitly choose a From number for the message, MxP uses that number first. This gives you direct control when a specific business, department, or team number should be used.

2. User-Assigned Number

If no number is manually selected, MxP checks whether the sending user has an eligible phone number assigned. If that number cannot send SMS, the applicable fallback number can be used instead.

3. Existing Conversation Number

If no applicable user-assigned number is used, MxP checks the number already associated with the contact's SMS conversation. Reusing the existing number helps maintain conversation continuity.

4. Default Outbound Number

If none of the higher-priority options apply, MxP uses the sub-account's default outbound number.

How To Select the From Number in Conversations

Manually selecting the From number is useful when a message needs to come from a specific business line instead of relying on automatic sender selection.

  1. From the Sub-Account View, click Conversations.
  2. Open the conversation with the contact you want to message.
  3. Select SMS in the message composer.
  4. Locate the From number selector.
  5. Click the From dropdown.
  6. Select the business phone number you want to use.
  1. Compose your SMS.
  2. Review the selected From number.
  3. Click Send.

Which Sender Numbers Can Users Access?

Number availability can depend on the user's role and number assignments.

  • Admins: Can access the phone numbers configured for the account.
  • Users: Can access applicable default, last-used, user-assigned, and unassigned numbers available to them.
6

How To Select the Contact's To Number

Selecting the recipient number helps ensure your message goes to the correct phone when a contact has multiple numbers saved.

  1. From the Sub-Account View, click Conversations.
  2. Open the contact's conversation.
  3. Select SMS in the message composer.
  4. Locate the To field.
  5. If the contact has multiple phone numbers, click the To number dropdown.
  6. Select the phone number you want to message.
  1. Confirm the selected recipient number.
  2. Compose and send the SMS.

Multiple Contact Numbers: A contact can store up to 11 phone numbers, with one number marked as Primary. If there is no previous conversation, the primary contact number is used by default.

7

How To Check Which Number Sent an SMS

Message details help you confirm the exact sender number used after an SMS has been sent, which is useful when troubleshooting unexpected sender behavior.

  1. From the Sub-Account View, click Conversations.
  2. Open the relevant conversation.
  3. Locate the SMS you want to inspect.
  4. Hover over the message.
  5. Click the three-dot menu (⋮).
  6. Select Details.
  7. Review the sending phone number shown in the message details.

Frequently Asked Questions

Q: What happens if I manually choose a From number?
The manually selected From number takes priority over user assignment, conversation history, and the default outbound number.
Q: What happens if I do not select a From number?
MxP checks the sending user's assigned number, then the number associated with the existing conversation, and finally the default outbound number.
Q: Why is an SMS still sending from an older number?
The existing conversation may still be associated with that number. Manually select the desired From number when you need to change the sender.
Q: What happens if the user's assigned number cannot send SMS?
If the assigned number is not SMS-capable, MxP can fall back to the applicable default outbound number.
Q: Can I select any phone number as the sender?
No. The selected number must belong to the relevant sub-account and be eligible to send SMS.
Q: What happens when a contact has multiple phone numbers?
Use the To selector in Conversations to choose the appropriate recipient number. The contact record also identifies one saved number as Primary.
Q: How many phone numbers can a contact have?
MxP currently supports up to 11 phone numbers on a contact record.
Q: How do I know which number actually sent a message?
In Conversations, hover over the SMS, click the three-dot menu (⋮) → Details, and review the sender information.
Q: Can I choose a From number for workflow SMS messages?
Yes. Workflow sender settings can specify a From number. Workflow configuration is managed separately from the manual Conversations composer.
Q: Does manually selecting a number override SMS compliance requirements?
No. The selected sender must still meet applicable phone capability, registration, compliance, DND, and opt-out requirements.
