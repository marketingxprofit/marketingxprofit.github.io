How to move from Old Blog to New Blog?

If you created blog posts using MxP's older blogging experience in Funnels or Websites, you can move them from Default Blog to the newer Blog experience. This article explains what changes when you migrate, how to move your existing posts, and what to check afterward.

What Happens to Old Blogs and Blog Posts?


Blog posts created using MxP's legacy blogging experience are available under Default Blog in Sites > Blogs. Existing legacy blogs can continue to work, but they use the older blog setup and do not have all the URL-management and SEO improvements available in the newer Blog experience.


Moving posts to the newer Blog experience helps you use its updated blog management, URL organization, canonical URL settings, and sitemap features. For details about creating and managing blogs in the newer experience, see Getting Started with Blogs and Blog Posts.


Important: Moving a blog post changes its original URL. Record the URLs of your published posts before migrating so you can set up redirects where needed.

How to Move from Old Blog to New Blog


  1. Go to Sites > Blogs.

  2. Open Default Blog, which contains blog posts from the older Funnels and Websites blogging experience.

  3. Review the existing blog posts in Default Blog.

  4. Select the checkbox next to each blog post you want to move.

  5. Click Move Blog to move the selected posts to the newer Blog experience.

Note: The original blog post URLs will no longer point to the migrated posts after their URLs change. Review the new URLs and configure 301 redirects for previously published links, if needed.







  1. Optional: If your funnel or website uses a Blog Post List (Blog Posts) element, edit the element, select the new blog, and republish the funnel or website page.

What to Check After Migration


  • Review migrated posts: Open the destination blog and confirm that the posts you moved are available and display correctly.

  • Check the new URLs: Open each migrated post at its new URL. If an old published URL has changed, create a 301 redirect from the old path to the new post URL. See How to Setup 301 URL Redirects.

  • Check website and funnel pages: If you use a Blog Post List element, make sure it references the new blog and that the page has been republished. See Add Blog Post Element in Funnel Step or Website Page.
