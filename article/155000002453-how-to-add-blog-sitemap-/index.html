How to add Blog Sitemap?

XML sitemaps help search engines discover important pages on your website, funnels, and blogs. MxP allows you to create and manage XML sitemaps for connected domains, select which pages to include, and automatically update blog sitemaps when new posts are published. You can also submit your sitemap to Google Search Console to monitor its processing. 


This article explains how to configure, generate, and submit XML sitemaps in MxP.

What Are XML Sitemaps?


An XML sitemap is a file containing URLs that you want search engines to discover. It helps search engines understand your website's structure and identify pages for crawling.


Note: Adding a URL to a sitemap does not guarantee indexing or higher search rankings. Similarly, excluding a page from a sitemap does not prevent search engines from discovering it through other links.

Key Benefits of XML Sitemaps


XML sitemaps make it easier to organize important URLs and communicate them to search engines.


  • Improved URL Discovery: Help search engines find website, funnel, and blog pages.

  • Page Selection: Choose which website and funnel pages to include.

  • Automatic Blog Updates: Keep the blog sitemap updated when new posts are published.

  • Centralized Management: Create, edit, and manage sitemaps for connected domains.

  • Search Console Integration: Submit sitemaps to Google and monitor their processing.

Requirements for Creating an XML Sitemap


A domain must be connected to your MxP sub-account before you can generate its XML sitemap. The sitemap configuration displays supported website, funnel, and blog content associated with the selected domain.


If you haven't connected a domain, follow How to Use the Domain Connect Feature.

How to Generate an XML Sitemap


MxP provides XML sitemap settings within domain management. You can include entire websites or funnels, or select individual pages.


  1. Go to Domain

  2. Add the domain -Follow this article for Domain setup 

  3. After adding the domain, in three dots the option to visit the XML Sitemap



  4. In XML Sitemap, step one is to select the landing pages/funnel to add by selecting the blog home and blog post option.

  5. In step two, click on generate Sitemap

Frequently Asked Questions


Q: Does creating an XML sitemap guarantee that my pages will appear in Google Search?

A: No. A sitemap helps Google discover URLs, but Google determines whether and when to crawl and index individual pages.



Q: Can I exclude certain pages from an XML sitemap?

A: Yes. Select individual pages during configuration rather than including the entire website or funnel. Excluding a page from the sitemap does not prevent it from being indexed.



Q: Will newly published blog posts automatically appear in the sitemap?

A: MxP automatically updates the configured blog sitemap when new blog posts are published.



Q: Can I edit an existing XML sitemap?

A: Yes. Open the sitemap settings and use the three-dot action menu to edit the sitemap or change its included pages.



Q: What happens if I change the sitemap URL?

A: Submit the new sitemap URL in Google Search Console so Google can discover and process the updated location.



Q: Do I need a separate sitemap for every website or funnel?

A: Not necessarily. MxP allows you to select pages from multiple websites and funnels connected to the same domain.
