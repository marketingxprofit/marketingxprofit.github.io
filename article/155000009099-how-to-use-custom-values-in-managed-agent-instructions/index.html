How to Use Custom Values in Managed Agent Instructions

Custom Values and Business Profile details let Managed Agents automatically use current business information, such as booking links, email addresses, and phone numbers. This makes agents easier to maintain and reuse across sub-accounts, templates, and snapshots.
Managed Agents can be created and edited from both the Agency Account and Sub-Account. However, business-specific Custom Values and Business Profile details are managed within the applicable Sub-Account.



Note: If using "Custom navigation UI" you  will need to access "CRM" tab > Custom Values

How to Insert Custom Values

  1. From the Agency Account or Sub-Account, go to AI Agents > Agent Studio and open a Managed Agent.


  2. In Instructions, click Insert value.

  3. Select Custom values or Business profile.

  4. Choose an existing value or click New custom value… to create one. Custom Values and Business Profile information are stored and managed within the applicable Sub-Account.

  5. Click Publish.

How to Handle Missing Custom Values


If a value is unavailable in the applicable Sub-Account, MxP displays Not set in this sub-account. Missing values must be configured for that Sub-Account before publishing.

  1. Click Publish.

  2. Enter the missing information in Set custom values to publish for the applicable Sub-Account.

  3. Click Save and publish.

Updating Custom Values


Managed Agents automatically use updated Custom Values on their next run.

Switch to the Sub-Account where the Custom Value is stored. Go to Settings > Custom Values, edit the value, and save your changes. Republishing is not required.


For Business Profile details, switch to the applicable Sub-Account and go to Settings > Business Profile to update the information.



Frequently Asked Questions

Q: Can I reuse Managed Agents across sub-accounts?

Yes. Each agent uses the Custom Values stored in its current sub-account.

Q: Do I need to republish after changing a value?

No. Changes apply automatically on the next run.

Q: What happens if a value is missing?

MxP prompts you to enter it before publishing.
