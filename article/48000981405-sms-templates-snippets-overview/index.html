SMS Templates (Snippets) - Overview

Conversations • SMS • Snippets
Create and Use SMS Snippets in MxP
SMS Snippets let you save frequently used text messages and reuse them instead of rewriting the same content. In MxP, reusable SMS content is created as a Text Snippet and can include supported personalization. This guide explains how to create, manage, and use SMS Snippets in Conversations and workflows.
What You'll Learn

Learn how to create a Text Snippet for SMS, organize saved messages, insert Snippets into Conversations, and reuse SMS content in a Send SMS workflow action.

Important

Reusable SMS content is created as a Text Snippet. The current HiRise Snippets experience is automatically enabled, and users accessing Snippets through Conversations need View & Manage Conversations access.

What Are SMS Snippets?

SMS Snippets are reusable Text Snippets for messages you send frequently. They help teams reuse approved SMS content while still allowing the message to be reviewed or edited before sending.

Common uses include:

  • Appointment reminders
  • Lead follow-ups
  • Support responses
  • Business hours or contact information
  • Promotional messages
2

Key Benefits of SMS Snippets

SMS Snippets reduce repetitive typing and make commonly used messages easier for teams to find, personalize, and reuse.

  • Save Time: Reuse frequently sent SMS content instead of rewriting it.
  • Improve Consistency: Give team members standardized messaging for common situations.
  • Personalize Messages: Add supported Custom Values for dynamic contact or account information.
  • Stay Organized: Use folders, search, and management controls to maintain your Snippet library.
  • Support Automation: Reuse saved content when configuring supported Send SMS workflow actions.
3

Prerequisites and Limitations

Using the correct Snippet type and confirming user access helps ensure reusable SMS content is available where your team needs it.

  • Create reusable SMS content as a Text Snippet.
  • Snippets are managed within the relevant Sub-Account.
  • Users accessing Snippets through Conversations need View & Manage Conversations access.
  • The HiRise Snippets page is automatically enabled; no Labs setting is required.
  • RCS Snippets and WhatsApp Templates use separate messaging experiences.
  • SMS length can affect message segments and sending cost.
4

How To Create and Manage an SMS Snippet

Create SMS content as a Text Snippet so it can be saved, organized, and quickly reused by your team.

  1. From the Sub-Account View, go to Conversations.
  2. Select Snippets.
  3. Click + New Snippet.
  4. Select Add Text Snippet.
  5. Enter a descriptive name and message.
  6. Add supported Custom Values when personalization is needed.
  7. Review the message, character count, and SMS segment information.
  8. Click Save.

Alternate Access: Snippets can also be accessed from Marketing → Snippets.

Organize and Update Snippets

Keeping your Snippet library organized makes approved messages easier to find and reduces the chance of outdated content being reused.

  • Use Search to find Snippets by name or keyword.
  • Use New Folder to group related messages.
  • Use the three-dot menu (⋮) to move, edit, duplicate, or delete a Snippet.
5

How To Use an SMS Snippet in Conversations

Inserting a Snippet into Conversations quickly populates prepared SMS content while still allowing you to review and edit the message before sending.

  1. Go to Conversations and open the contact conversation.
  2. Select the appropriate text messaging channel.
  3. Click the Snippets icon in the message composer.
  4. Search for or select the Text Snippet you want to use.
  5. Review the populated message and dynamic information.
  6. Make any necessary edits.
  7. Send the message.
6

How To Use SMS Content in Workflows

The Send SMS workflow action includes a Templates selector that can populate the message with saved reusable content, helping keep automated messages consistent.

  1. Go to Automation → Workflows.
  2. Open or create a workflow.
  3. Add or open a Send SMS action.
  4. Locate Templates.
  5. Select the reusable message you want to use.
  6. Review the populated message and personalization.
  7. Use Send test SMS when you want to verify the message.
  8. Save the action and test the workflow.
  9. Publish the workflow when it is ready.

Frequently Asked Questions

Q: Are SMS Snippets and Text Snippets the same thing?
Reusable SMS content is created as a Text Snippet. Some areas may refer to saved reusable content as Templates.
Q: Can I personalize an SMS Snippet?
Yes. Text Snippets support Custom Values and other supported dynamic content for personalization.
Q: Can I edit a Snippet after inserting it into a Conversation?
Yes. Review and edit the populated message before sending it.
Q: Can I organize SMS Snippets into folders?
Yes. Use New Folder from the Snippets page and move related Snippets into the appropriate folder.
Q: Can I test an SMS before publishing a workflow?
Yes. The Send SMS action includes a Test Phone Number field and Send test SMS option.
Q: Are RCS Snippets the same as SMS Snippets?
No. RCS Snippets use a separate creation and sending experience designed for RCS-specific message formats and features.
