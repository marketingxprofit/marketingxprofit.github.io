Project Management Workflow Triggers and Actions

MxP allows you to automate Project Management tasks using workflow triggers and actions. You can start workflows when tasks are added or completed, schedule reminders, and automatically create tasks with the right details. This article explains how these features work and how to configure them in Workflow Builder.

What are Project Management Workflow Triggers and Actions?


Project Management workflow triggers and actions help you automate task-related activities.

A trigger starts a workflow when a specific event occurs. An action performs a task after the workflow starts.

For example, when a design task is completed, a workflow can automatically create a development task, assign it to a team member, and set its due date.


MxP supports the following Project Management workflow features:

TypeFeaturePurpose
TriggerTask AddedStarts when a task is created
TriggerTask CompletedStarts when a task is completed
TriggerTask ReminderStarts before or after a task-related date
ActionAdd TaskCreates a task automatically


Availability: Project Management is currently in Private Beta. The workflow features must be available in your sub-account.

Key Benefits of Project Management Workflow Automation


These features reduce manual task management and help teams follow consistent processes.

  • Automated Task Creation: Create follow-up tasks when specific events occur.

  • Targeted Automation: Use filters to run workflows only for matching tasks.

  • Timely Reminders: Schedule workflows around important task dates.

  • Flexible Assignments: Assign tasks to specific users or use dynamic values.

  • Consistent Task Details: Set priorities, statuses, dates, descriptions, and custom fields automatically.

  • Organized Workflows: Create tasks in the appropriate Space, Folder, and List.

Task Added and Task Completed Triggers


These triggers start workflows when tasks are created or completed. Filters determine which tasks qualify.


Task Added

Starts a workflow when a new task matches the selected conditions.

Example: Start a workflow when a high-priority task is added to the Website Design List.


Task Completed

Starts a workflow when a task is completed and matches the selected conditions.

Example: Create a development task when a design task is completed.

You can use status filters to target specific completion statuses.


Task Reminder Trigger


The Task Reminder trigger runs a workflow before or after a selected task date. It helps automate reminders and follow-up activities.


You can schedule a reminder using:

  • Due Date: When the task should be completed.

  • Start Date: When work is scheduled to begin.

  • Custom Date Field: A date stored in a task custom field.


Choose how many days before or after the selected date the workflow should run.

You can also filter tasks by status, assignee, priority, or name.

For example, you can trigger a reminder one day before a high-priority task is due, excluding tasks that are already completed.


Workflow Trigger Filters


Filters control which Project Management tasks can start a workflow. They help ensure automations run only when the required conditions are met.


FilterAvailable conditions
LocationSelect a Space, Folder, or List
AssigneeMatch or exclude users, or check whether an assignee is set
PriorityMatch or exclude priorities, or check whether one is set
StatusInclude or exclude selected statuses
Task NameUse contains, does not contain, equals, does not equal, or regex
Task Custom FieldsMatch supported custom field values


Note: Folder and List options depend on the selected location. Available filters may vary by trigger.

Add Task Workflow Action


The Add Task action creates a new Project Management task when the workflow reaches that step. You can choose where the task is created and configure its details.


SettingWhat it does
Task NameSets the task title
Space, Folder, and ListDetermines where the task is created
StatusSelects a status available in the chosen List
AssigneeAssigns a specific user or supported dynamic value
PrioritySets Urgent, High, Medium, or Low priority
Start Date and Due DateSets dates relative to workflow execution
DescriptionAdds task details using a rich text editor
Custom FieldsStores additional task information


For example, the action can create a task named Begin Website Development, assign it to a developer, and set its due date to two days after the workflow runs.

Using Dynamic Values and Custom Fields


Dynamic values allow you to insert information from available workflow data instead of entering fixed text. Custom fields allow you to store additional information on the task being created.


Dynamic Values

The Task Name, Description, and supported assignment fields can use dynamic values.


Available task-related values include:

  • Task ID

  • Title

  • Description

  • Due Date

  • Assigned User


Task Custom Fields


To populate a task custom field:

  1. Open the Add Task action.

  2. Click Add custom field.

  3. Select the field you want to populate.

  4. Enter a fixed value or select a supported dynamic value.

  5. Repeat for additional fields if needed.

For more information, see Use Custom Fields on Tasks.

Setting Task Dates and Skipping Weekends


The Add Task action lets you set start and due dates based on when the workflow runs. This allows tasks to be scheduled automatically.


To configure a date:

  1. Enter a number in Value.

  2. Select a Unit: days, weeks, months, or years.

  3. Choose the time.

  4. Enable Skip weekends if needed.


If the calculated date falls on a weekend and Skip weekends is enabled, it moves to the next weekday.

For example, you can set a task to be due two days after the workflow runs.

How to Set Up Project Management Workflow Automation


You can combine a Project Management trigger with the Add Task action to automate follow-up work.

The example below creates a task in the Website Development List when a task is completed in the Website Design List.


Step 1: Create or Open a Workflow

  1. Go to Automation → Workflows in your MxP sub-account.

  2. Create a workflow or open an existing one.

  3. Open the Workflow Builder.


Step 2: Add the Task Completed Trigger

  1. Click Add New Trigger.

  2. Search for and select Task Completed.

  3. Choose the appropriate Space.

  4. Select the Website Design List, choosing its Folder first if needed.

  5. Add any other required filters, such as Status or Priority.

  6. Save the trigger.


Step 3: Configure the Add Task Action

  1. Click the + icon below the trigger.

  2. Search for and select Add Task.

  3. Enter Begin Website Development as the Task Name.

  4. Select the destination Space and Website Development List.

  5. Set the Status, Priority, and Assignee as needed.

  6. Add a Description or task custom fields if needed.

Step 4: Set the Due Date

  1. Under Due Date, enter 2 in Value.

  2. Select Days as the Unit.

  3. Choose the required time.

  4. Enable Skip weekends if needed.

  5. Click Save action.


The new task's due date will be calculated when the workflow runs.


Step 5: Save, Test, and Publish

  1. Click Save in Workflow Builder.

  2. Use Test workflow where supported.

  3. Confirm the workflow creates the task in the correct List with the expected details.

  4. Change the workflow from Draft to Publish when ready.


Important: Saving a workflow does not automatically publish it.


Frequently Asked Questions


Q: What is the difference between Task Added and Add Task?

A: Task Added is a trigger that starts a workflow. Add Task is an action that creates a new task.

Q: Can I create a task in another List?

A: Yes. Select the destination Space, optional Folder, and List in the Add Task action.

Q: Can I run workflows only for high-priority tasks?

A: Yes. Use the Priority filter in a supported trigger.

Q: Can I schedule reminders before a task's start date?

A: Yes. Task Reminder supports start dates, due dates, and supported custom date fields.

Q: Can I automatically assign tasks?

A: Yes. You can select a specific user or use a supported dynamic value.


Q: Can I use task information in the new task's name or description?

A: Yes. Use dynamic values to insert supported task information.


Q: What happens when a due date falls on a weekend?

A: If Skip weekends is enabled, the due date moves to the next weekday.


Q: Why isn't my workflow running?

A: Check that the workflow is published, its trigger filters match the task, and the required Project Management features are available.
