WhatsApp Template Builder Update and Dynamic Media URLs

WhatsApp Template Builder Update and Dynamic Media URLs

A rebuilt template builder with live phone preview, and media headers that resolve per contact at send time — so one approved template serves every contact's unique asset.

Send every customer their own invoice, ticket, or personalized image from a single template. No more cloning a template for every asset and waiting on Meta to approve each copy.

What's New

✓Rebuilt builder — Category, type, name, body, media, buttons, and variables all in one modern single-page layout.
✓Live phone preview — see exactly how the message lands on WhatsApp as you type, before Meta ever sees it.
✓Dynamic media URLs — media header fields now accept custom fields and dynamic values that resolve per contact at send time.
✓Clear failure behaviour — invalid or empty resolved values fail clearly. No silent wrong media sent.

Rebuilt Create and Edit Experience

The Create and Edit Template experience has been completely rebuilt. All template fields — category, type, name, body, media, buttons, and variables — now live together in a single redesigned layout, matching the templates and folders experience you already use for managing your library.

One Layout for Everything

Category, type, naming, body, media, buttons, and variables are all on the same page. No switching between separate sections or modals.

Consistent Across Authoring Surfaces

AI template generation now runs through the same builder end to end. The WhatsApp template builder opened from Reputation uses it too. One interface to learn, not three.

Note: This update covers the Create / Edit builder. Template list and folder management shipped separately under a previous update.

Live Phone Preview

The builder includes a live phone preview that updates as you type. As you edit the header, body text, media, and buttons, the preview reflects your changes in real time — showing exactly how the message lands on WhatsApp.

Catching a layout problem in the builder costs you seconds. Catching it after Meta approval costs you another approval cycle.

If the preview appears blank or is not updating, confirm you are in the updated builder via Settings → WhatsApp → Templates → Create / Edit.

Dynamic Media URLs

Media header fields now accept custom fields and dynamic values — not just one static public URL. At send time the value resolves for that specific contact and Meta receives a concrete URL for that message.

One Template Instead of Many

Previously, a different image or document meant a different template — and every new template goes to Meta for approval. Now a single approved template serves every contact's unique asset. The approved template stays the same; only the resolved URL varies.

Works Across All Send Surfaces

Dynamic media headers are supported wherever you send WhatsApp templates:

Workflows Conversations Bulk Actions Calendar Appointments Reputation Review Requests Missed Call Text Back

Clear Failure Behaviour

A dynamic value that resolves to a valid public URL sends normally. One that resolves to something invalid or empty fails clearly — so you never discover the wrong document went out by hearing it from your client.

What Resolves Successfully vs. What Fails

✓A publicly reachable HTTPS URL that Meta can download — sends successfully.
✘Private Drive links or URLs that require a login — Meta cannot access them and the message will fail.
✘An empty field — fails clearly with no silent wrong media sent.

How to Use Dynamic Media

For per-contact documents (invoices, contracts, IDs)

1

Store a publicly reachable HTTPS URL on a contact custom field.

2

In your template's media or header field, map to that custom field instead of pasting a fixed URL.

3

Send from a workflow, bulk action, or conversation. Each contact receives their own file.

For personalized images at scale

1

Create your image design in a service like NiftyImages, with a placeholder for the contact's name or any other detail.

2

Use the personalized image URL as your media header value, with the contact's detail supplied dynamically via a custom field.

3

Run a bulk action. Every contact receives an image rendered just for them.

Requirement: The resolved value must be a publicly reachable URL that Meta can download. Private Drive links, URLs behind a login, and empty fields will fail.

Why This Matters

Personalized media used to carry a hidden tax. Every variation meant another template, and every template meant another round of Meta approval before you could send anything. That made per-customer invoices, tickets, certificates, and personalized campaign images impractical for most businesses — so they either skipped them or built fragile workarounds.

✓Run personalized image campaigns at bulk scale instead of sending the same flat creative to everyone.
✓Send genuinely personalized documents without multiplying your template library.
✓Skip the approval queue for asset changes — the approved template stays the same and only the resolved URL varies.
✓Keep automations stable — workflows reference a dynamic value rather than a URL you hand-edit after every clone.
✓Catch layout mistakes before Meta sees them, with a preview that matches the real message.
