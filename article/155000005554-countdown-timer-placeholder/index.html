Countdown Timer Placeholders in Shared Email Templates
When an email template containing a countdown timer is copied to another sub-account, the original timer is replaced with a static placeholder. The copied template must be connected to a countdown timer in the destination sub-account before the timer will work.
What You'll Learn

Learn why countdown timers become placeholders when email templates are copied between sub-accounts, how to copy the template, and how to connect the placeholder to a working timer in the destination sub-account.

What Is a Countdown Timer Placeholder?

A Countdown Timer Placeholder appears when an email template containing a countdown timer is copied to another sub-account. The placeholder preserves the timer's position in the template but does not function as a countdown until a timer from the destination sub-account is selected.

Countdown Timer placeholders are currently documented for shared email templates.

Important: A Countdown Timer Placeholder is not a working timer. Before using the copied email template, select an existing countdown timer from the destination sub-account or create a new one.

2

How to Copy an Email Template With a Countdown Timer

Copy the email template normally. The countdown timer will automatically become a placeholder when the template is copied to another sub-account.

  1. Go to Marketing → Emails → Templates.
  2. Create or open an email template that contains a countdown timer.
  3. Return to the Templates list.
  4. Open the template's three-dot menu and select Share.
  5. Configure the sharing permissions and copy the template link.
  6. Open the share link and select Add Template.
  7. Select the destination sub-account, rename the template if needed, and clone the template.
3

How to Replace the Countdown Timer Placeholder

The copied template cannot use the original countdown timer automatically. Select a countdown timer available in the destination sub-account before using the email.

  1. In the destination sub-account, go to Marketing → Emails → Templates.
  2. Open the copied email template.
  3. Select the Countdown Timer Placeholder.

  4. Choose an existing countdown timer from the destination sub-account
  5. If no suitable timer exists, go to Marketing → Countdown Timers and create one. Then return to the email template and select the new timer.
  6. Save and test the email before using it in a campaign.

Frequently Asked Questions

Q: Why did my countdown timer become a placeholder?
The email template was copied to another sub-account. Countdown timers in copied email templates are replaced with placeholders until a timer from the destination sub-account is selected.
Q: Does the placeholder automatically use the original countdown timer?
No. Select a countdown timer available in the destination sub-account.
Q: What if the destination sub-account does not have a countdown timer?
Create a countdown timer under Marketing → Countdown Timers, then return to the copied email template and select it.
Q: Does this placeholder behavior apply to funnels and websites?
Current documentation confirms this placeholder workflow for shared email templates. For funnels and websites, follow the applicable countdown-timer placement instructions.
