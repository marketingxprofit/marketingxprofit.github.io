How to Add and Edit SEO Information for Blog Posts

Add or update SEO information for blog posts in MxP, including the SEO title, cover image, alt text, and post description. This article shows how to add SEO information when creating a blog post and edit it for an existing post.

What is SEO for Blog Posts?


SEO information helps define how a blog post is described and presented for search engines and visitors. MxP lets you manage key SEO details for each blog post during the publishing process or update them later for an existing post.

Key Benefits of SEO for Blog Posts


  • Better search visibility: Add relevant titles and descriptions that help search engines understand your blog post.

  • Improved accessibility: Add alt text to the cover image to describe the image for visitors using assistive technologies.

  • Easy SEO management: Add SEO information while creating a post or update it later without recreating the blog post

How to Add SEO Information to a Blog Post


SEO information can be added after you finish writing your blog post and move to the publishing settings. This lets you prepare the post's SEO details before saving, scheduling, or publishing it.


  1. In your MxP sub-account, go to Sites > Blogs.

  2. Open the blogsite where you want to create the post. (To create a blog site, checkout our article on Getting Started with Blogs and Blog Posts) 



  3. Click + New Post.

  4. Create and format your blog post content. (If you need help creating a blog post, check our article on Create Blog Posts)

  5. When your post content is ready, click Continue in the upper-right corner.

  6. Complete the applicable post settings, such as the category, author, and keywords.



  7. Locate the SEO Metadata settings.

  8. Add or update the following information:

    • Title: Enter the SEO title for the blog post.

    • Cover Image: Upload or select the cover image for the post.

    • Alt Text: Add descriptive alt text for the cover image.

    • Post Description: Add a short description that gives readers a preview of the post. A description between 100 and 250 characters works best.

  9. Select the appropriate publishing option.

  10. Click Publish to publish the post, or use the available draft or scheduling option as needed.

How to Edit SEO Information for an Existing Blog Post


Existing blog posts can have their SEO information updated directly from the blog post list, allowing you to revise metadata without creating the post again.


  1. Go to Sites > Blogs.

  2. Open the blog site containing the post you want to update.



  3. Find the applicable blog post.

  4. Click the three-dot menu on the right side of the post.

  5. Select Change Blog Post SEO Details.



  6. Update any of the following fields as needed:

    • Title
    • Cover Image
    • Alt Text
    • Post Description

  7. Click Update Blog Post to save the changes.

Frequently Asked Questions


Q: Do I need to recreate a blog post to change its SEO information?
No. SEO information for an existing post can be updated directly from the blog post's SEO settings.

Q: What SEO information can I edit for a blog post?
You can update the title, cover image, cover image alt text, and post description.

Q: How long should my blog post description be?
A post description between 100 and 250 characters works best.
