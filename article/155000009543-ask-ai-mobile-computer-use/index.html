Ask AI Mobile - Computer Use

Ask AI Computer is now available in the MxP mobile app, bringing your private cloud computer to your phone. Start tasks, watch the browser work, and take control when needed. You can also approve actions, sign in securely, manage files, and continue work across devices. This guide covers the mobile features and controls available in Ask AI Computer.

What Is Ask AI Computer on Mobile?

Ask AI Computer gives Ask AI access to a private cloud computer with a Chrome browser, terminal, and file manager. It can browse websites, complete forms, run code, and create files on your behalf.

Mobile connects to the same cloud computer used on web. You can monitor tasks, interact with the desktop, and manage work directly from your phone.

Key Benefits of Ask AI Computer on Mobile

Ask AI Computer lets you handle browser-based tasks without staying at your desk.

  • Work anywhere: Start and monitor Computer tasks from your phone.

  • Take control: Interact with the live browser and hand control back to Ask AI.

  • Secure access: Approve actions and sign in without sharing passwords in chat.

  • File management: Attach files, download results, and review Computer activity.

  • Cross-device continuity: Continue Computer conversations started on web.

Prerequisites and Limitations

Ask AI Computer on mobile follows the existing agency and sub-account access controls. No additional Computer setup is required for mobile.

  • Access: Ask AI Computer requires Ask AI Level Up in an eligible sub-account and the applicable agency, sub-account, and user-level permissions.

  • Storage: Each user has 15 GB of Computer storage across sub-accounts, with a 25 MB individual file limit.

  • Network: Computer accesses the public internet, not private networks.

  • App activity: Keep Ask AI open while Computer works. Leaving the mobile app pauses the task.

How to Set Up Ask AI Computer on Mobile

Start Computer from any new Ask AI chat. Existing Computer conversations are available in History.

  1. From your Sub-Account in the MxP mobile app, open the App Drawer → Ask AI.

  2. Start a new chat and tap Computer above the Ask anything... message field.

  3. If Computer is asleep, tap Turn on.

  4. Enter your task and send the message.


Computer begins working and displays its progress in the conversation. To reopen a task, navigate to Ask AI → History → Computer.

Watch and Take Control of the Computer

Computer displays a live desktop preview and its current status, including Working, Idle, Done, Needs you, or You're in control.

Watch and Control the Browser

The live browser lets you watch Computer's progress and intervene when a step needs manual input. Return control to Ask AI after you finish so the task can continue.

  1. Open your Computer conversation and tap Open browser.

  2. Tap Take control of the browser when you need to interact with the desktop.

  3. Tap to click, drag with two fingers to scroll, or type with your phone's keyboard.

  4. Tap Hand back when finished.

Ask AI continues from where you left off.


Keep Chatting While Computer Works

You can switch between Ask AI chats while Computer runs. A live status pill follows you between chats.

Tap the pill to return to the Computer conversation.


Manage Approvals and Private Sign-Ins

Computer requests your permission before performing certain actions. Website sign-ins use a private form that keeps credentials out of your Ask AI conversation.

Approve Computer Actions

When Computer pauses for approval, review the action card and choose:

  • Approve: Permit the requested action.

  • Allow for this chat: Save the displayed permission for 30 days.

  • Deny: Reject the action.

You can review or revoke saved permissions under Settings → Computer use → Allowed actions.


 — Approve, Allow for this chat, and Deny options.


Sign In Securely


When a website requires login credentials:

  1. Review the website address in the private sign-in form.

  2. Enter your Email or username and Password.

  3. Optionally enable Save to Secure Store.

  4. Tap Sign in.

You can also select Take over to sign in or Not now.

Credentials entered through the private form go directly to the website. Ask AI does not see the password in chat.


 — Private sign-in form and Secure Store option.

Manage Secure Store and Computer Settings

Open Settings → Computer use in the MxP mobile app to manage saved logins, permissions, browsing data, and storage.

Manage Saved Logins

Saved logins let Computer access websites without placing credentials in your Ask AI chat. Set the permission level that matches how you want Ask AI to use stored credentials.

Under Let Ask AI use saved logins, choose:

  • Never: Do not use saved logins.

  • Ask: Request approval before using a saved login.

  • Allow on matching sites: Use saved logins on matching websites.

The preference applies across your sub-accounts. Saved credentials are managed separately for each sub-account, and passwords are not filled on look-alike sites.

To add a login:

  1. Under Saved logins, tap Manage saved logins.

  2. Select the option to add a login.

  3. Enter the URL, optional Username, and Password.

  4. Tap Save.

You can also edit or delete existing saved logins.


— Add a login form.


Manage Permissions, Storage, and Browser Data

Computer settings let you review stored data and revoke previously granted permissions when your access needs change.

The Computer use settings screen also includes:

  • Clear browsing data: Remove browser cookies, cache, and history.

  • Allowed actions → Review: Revoke individual saved permissions or all permissions.

  • Storage: Review usage against the 15 GB storage allocation.

  • Reset profile: Remove Computer data for the selected sub-account, including files, browser history, saved logins, terminal history, and activity.

Resetting one sub-account's Computer profile does not affect other sub-accounts.


— Computer use settings.

Work with Files and Review Activity

Computer can use attached files, generate results, and record the actions performed during a task.

Files and Results

You can share input files with Computer and retrieve finished work from the conversation. The Files sheet helps you locate recent items and monitor storage usage.

Use the paperclip icon in the Computer chat to attach a file and include it in your request.

Generated spreadsheets, documents, and PDFs appear as file cards. Tap a card to open or download the result.

The Files sheet lists recent files and displays a storage meter.


— Generated file card in Computer chat.


Computer Activity

The Activity sheet records Computer actions in chronological order, including visited websites, commands, and changes in browser control.


 — Computer activity history.

Continue Tasks Across Devices

Computer conversations are shared between web and mobile. You can review previous messages, return to an active desktop, and resume interrupted tasks.

  1. Open Ask AI → History → Computer.

  2. Select the existing conversation to review work started on web.

  3. If the desktop is already open on another device, tap Show here to bring the live view to your phone.


— Show here control for switching the Computer desktop between devices.

Computer also supports task recovery:

  • Turn on: Wake a sleeping Computer with existing files and saved sign-ins preserved.

  • Automatic reconnection: Computer reconnects when the connection drops.

  • Resume: Continue an interrupted task when the option appears.

Frequently Asked Questions

Q: Can Computer use the browser installed on my phone?

No. Computer runs Chrome on its private cloud desktop. You view and control that desktop from your phone.

Q: What if a website requires a one-time verification code?

Open the browser, take control, enter the code directly on the website, and hand control back to Ask AI.

Q: Can Computer install software or run commands?

Yes. Computer can run commands and install supported tools. Software installations may require approval.

Q: What happens when Computer is inactive?

Computer sleeps after 15 minutes of inactivity and can wake again when needed.
