Add Custom Templates to Template Library

Template Library • Agency Admin • Reusable Assets
Add Custom Templates to the MxP Template Library
MxP's Template Library lets agencies turn reusable assets into templates that can be shared across supported sub-accounts and product areas. Agency Admins can create templates centrally from Agency View or upload supported assets directly from individual MxP products. Templates can include categories, tags, descriptions, previews, cover images, and prerequisites to make reusable assets easier to discover and understand. This guide explains how to create, upload, configure, save, publish, and control access to custom templates.
What You'll Learn

Learn the requirements for creating custom templates, how to create templates centrally from Agency View, how supported products upload reusable assets, how to configure template information, how Draft and Published templates behave, and how to control Template Library visibility for sub-accounts.

Important

Creating new custom templates requires an Agency Admin on the $497/month Pro plan. Agency Admins on the $97 Starter and $297 Unlimited plans can browse the Agency Template Library and use supported visibility-management features, but they cannot create new custom templates.

What Is a Custom Template in the Template Library?

A custom template is a reusable asset an agency adds to its MxP Template Library. Published templates can be made available to sub-accounts so users can start with agency-approved content or configurations instead of rebuilding the same asset from scratch.

The Template Library supports multiple MxP product areas. Available template types and creation options vary by product, so use the product choices and upload actions displayed in your account to confirm whether a specific asset type is supported.

2

Key Benefits of Custom Templates

Custom templates help agencies standardize reusable assets, reduce repetitive setup, and make proven content easier for sub-account users to discover and reuse.

  • Reuse Proven Assets: Turn existing agency content into reusable templates across supported product areas.
  • Create Centrally: Build Template Library entries directly from Agency View without repeatedly switching between sub-accounts.
  • Maintain Consistency: Give sub-accounts access to agency-approved designs, content, and configurations.
  • Improve Discoverability: Add categories, tags, descriptions, previews, cover images, and prerequisites to make templates easier to understand and find.
  • Control Publication: Keep templates in Draft while preparing them, then publish them when they are ready for use.
  • Manage Visibility: Control which templates and categories appear for sub-accounts.
3

Prerequisites and Limitations

Confirming your agency plan, permissions, Template Library visibility, and source asset before creating a template helps prevent missing controls or inaccessible templates later.

Before creating a custom template, confirm:

  • Your agency is on the $497/month Pro plan to create new custom templates.
  • You are signed in with an Agency Admin role.
  • Template Library access is enabled when sub-account users need to browse published templates.
  • The source asset already exists when you want to create a template from an existing sub-account asset.

Enable the Template Library for Clients

The agency-level Template Library setting controls whether clients can access the library. Enable it before expecting published templates to appear in supported sub-account experiences.

  1. From Agency View, open Settings.
  2. Select Company.
  3. Scroll to Template Library for Clients.
  4. Turn on the toggle when sub-account users should have access to templates.

$97 and $297 plans: Agency Admins on these plans can browse the Agency Template Library and use supported visibility controls such as hiding templates or categories. Creating new custom templates still requires the $497 Pro plan.

Understand Source Template Updates

Changes made to the original source asset do not automatically update an already published Template Library template. Treat the published template as its own reusable asset and review it separately when the original content changes.

How To Create a Custom Template from Agency View

Creating a template centrally from Agency View lets an Agency Admin select an existing sub-account asset, preview it, rename it, and create a reusable Template Library entry without navigating through the source product first.

Step 1: Start the Template

Start from the agency Template Library so the source sub-account and product can be selected from one centralized creation flow.

  1. From Agency View, open Template Library.
  2. Click + Create template.

Step 2: Select the Source Asset

Selecting the source sub-account and product type tells MxP which existing assets should be available for the new template.

  1. Select the sub-account containing the source asset.
  2. Select the applicable product.
  3. Choose the template or source asset.
  4. Click Continue.

Step 3: Preview, Rename, and Create

Previewing the source asset gives you a final opportunity to confirm that the correct template was selected before creating the reusable Template Library entry.

  1. Review the template preview.
  2. Open the preview if you need to inspect the asset more closely.
  3. Rename the template if needed.
  4. Click Create.

After the template is created, MxP opens the Template Library management experience so you can update template details, save it as a Draft, or publish it for reuse.

How To Upload a Template from a Product

Supported MxP products can send an existing asset directly to the Template Library. The exact upload action varies by product, but the workflow generally starts from the asset's three-dot menu and continues in Template Library admin mode.

ProductStarting AreaUpload Action
Email TemplatesMarketing → Emails → TemplatesUpload to email templates
Social PlannerMarketing → Social Planner → Content → CSVUpload to social templates
WorkflowsAutomation → WorkflowsUpload to Template Library
Supported Sites AssetsSites → Select supported productUpload to [product] templates
Ad ManagerMarketing → Ad ManagerUpload to Template Library
Custom ReportsReporting → Custom ReportsUpload Report Template

Upload an Email Template

Email templates can be uploaded directly from the Email Marketing template list, allowing established designs to become reusable Template Library assets.

  1. From the sub-account, go to Marketing → Emails → Templates.
  2. Locate the email template you want to reuse.
  3. Open the template's three-dot action menu.
  4. Select Upload to email templates.
  5. Enter a display name.
  6. Select a category.
  7. Click Upload.

Upload Social Planner Content

Social Planner lets Agency Admins upload supported reusable content to the Template Library directly from the Content area.

  1. From the sub-account, go to Marketing → Social Planner.
  2. Open Content.
  3. Open the CSV tab or another supported Template Library content area.
  4. Locate the content you want to reuse.
  5. Open its three-dot action menu.
  6. Select Upload to social templates.
  7. Enter the template name and select a category.
  8. Continue to Template Library admin mode to complete the template information.

Upload an Ad Manager Campaign

Supported Ad Manager campaigns can be saved as reusable templates. After upload, the campaign is created as a Draft template so its information can be reviewed before publication.

  1. From the sub-account, go to Marketing → Ad Manager.
  2. Open the campaign list.
  3. Locate the supported campaign you want to reuse.
  4. Open the campaign's ellipsis (⋮) menu.
  5. Select Upload to Template Library.
  6. Enter the template name.
  7. Select a category.
  8. Click Upload.

Ad Manager Drafts: Uploaded supported campaigns are saved as Draft templates. You can edit the template, keep it as a Draft, or publish it for reuse.

Upload a Custom Report

Custom Reports require an additional permissions and cleanup step before upload so the reusable report works across sub-accounts without exposing client-specific information.

  1. From the sub-account, go to Reporting → Custom Reports.
  2. Locate the completed report on Reports Overview.
  3. Open the report's three-dot menu.
  4. Select Manage permissions.
  5. Grant at least Read access to Agency User, Account Admin, and Account User.
  6. Finalize the reusable layout, branding, page order, date ranges, and widget settings.
  7. Replace client-specific text, screenshots, or other information with reusable content.
  8. Return to the report's three-dot menu.
  9. Select Upload Report Template.

Other Supported Product Uploads

Additional supported product areas can also upload reusable assets to the Template Library. The exact menu label varies based on the product.

  • Workflows: Go to Automation → Workflows, open the workflow's three-dot menu, and select Upload to Template Library.
  • Sites Products: For supported funnels, websites, stores, blogs, emails, forms, surveys, and quizzes, open the asset's three-dot menu and use the available Upload to [product] templates action.

How To Configure and Publish a Template

Template information helps sub-account users understand what an asset contains, what is required before using it, and when it is appropriate for their use case. Complete the available metadata before publishing.

Complete the Template Information

The available fields can vary by product, but Template Library admin mode can include the following information.

FieldPurpose
NameThe display name shown in the Template Library.
CategoryGroups the template with related content.
PreviewHelps users inspect the template before using it.
Cover ImageProvides a thumbnail or visual representation of the template.
TagsAdds searchable terms that improve template discovery.
PrerequisitesIdentifies setup requirements needed before users apply the template.
Short DescriptionProvides a brief summary displayed with the template.
Long AboutProvides detailed use cases, setup guidance, content tips, feature information, or other helpful context.

Save the Template as a Draft

Draft status keeps the template available for administrative editing without making it available for normal sub-account use.

  1. Review the template information.
  2. Complete the metadata you want included.
  3. Save your changes.
  4. Keep the template in Draft until it is ready for users.

Publish the Template

Publishing makes the finished template available through the applicable Template Library experience for sub-account users who have access.

  1. Review the template name, category, preview, prerequisites, descriptions, and other available information.
  2. Save any outstanding changes.
  3. Click Publish Template.
  4. Confirm publication when prompted.

Control Template Library Visibility by Sub-Account

Agency Admins can customize which templates and categories appear for individual sub-accounts. This helps agencies show only the assets that are relevant to a client's needs, niche, or plan.

  1. From Agency View, open Template Library.
  2. Open Settings.
  3. Select Customize for Subaccounts.
  4. Locate the sub-account you want to manage and click Edit.
  5. Hide or show templates and categories as needed.
  6. Click Save.

Frequently Asked Questions

Q: Who can create custom templates?
Custom template creation requires the Agency Admin role and an agency on the $497/month Pro plan.
Q: Can Agency Admins on the $97 or $297 plans create custom templates?
No. Agency Admins on those plans can browse the Template Library and use supported visibility-management features, but creating new custom templates requires the $497 Pro plan.
Q: Can I create a template without opening the source product first?
Yes. Go to Agency View → Template Library → + Create template, then choose the source sub-account, product, and source template.
Q: Do I have to publish a template immediately?
No. Supported templates can remain in Draft while you review and complete their information before making them available to sub-account users.
Q: Do changes to the original source asset automatically update a published template?
No. Changes made to the original source asset do not automatically flow through to the corresponding published Template Library template.
Q: Can I control which sub-accounts see templates?
Yes. Agency Admins can customize Template Library access by sub-account and hide or show templates and categories as needed.
Q: Are all MxP products available for custom template creation?
No. Template availability and upload options vary by product. Use the current product choices and upload actions displayed in your account to confirm whether an asset type is supported.
Q: Can I sell a custom template?
Eligible templates can be submitted through the connected Template Library Marketplace workflow. From the template preview, use Sell Template On The Marketplace, continue to the Seller Portal, complete the required listing, support, and pricing information, and submit the template for review.
