How to Setup Voicemail in MxP

MxP lets you upload a custom audio recording for company voicemail, individual user voicemail, or a voicemail drop in a workflow. For reliable playback, prepare the recording in a supported format and test it after uploading.

Audio File Requirements

Before uploading a voicemail recording, use the following recommended settings:

RequirementRecommended Setting
File formatMP3 or WAV
Audio quality64 kbps
ContentClear, pre-recorded voice message


Important: Higher-quality audio is not always better for voicemail delivery. If the recording does not play correctly, convert or export it at 64 kbps, upload it again, and retest.

Set Up Company Voicemail

Use company voicemail when you want a default voicemail recording for the Sub-Account.

  1. Go to Sub-Account → Settings → Phone System.

  2. Scroll to Call & Voicemail Settings.

  3. Upload the MP3 or WAV voicemail file.

  4. Save your changes.

  5. Call the MxP phone number from another phone and allow the call to reach voicemail.


Set Up User Voicemail

You can configure a separate voicemail recording for an individual user.

  1. Go to Sub-Account → Settings → Users.

  2. Open the applicable user.

  3. Open the user's call and voicemail settings.

  4. Upload the MP3 or WAV voicemail file.

  5. Save the user's settings and test the call flow.

When creating a user from Users, available setup options can include call-forwarding defaults and voicemail configuration.

A user's voicemail can take precedence when the contact or phone number is assigned to that user.

Add a Voicemail Drop to a Workflow

Use the Voicemail workflow action when you want to deliver a pre-recorded voicemail through automation.

  1. Open the appropriate Workflow.

  2. Click the + button to add an action.

  3. Search for and select Voicemail.



  4. Upload the pre-recorded MP3 or WAV file. For best compatibility, use 64 kbps.


  5. Click Save Action.



  6. Save or publish the workflow as appropriate.

Test the workflow with a test contact before using the voicemail drop with your intended audience.

Prepare Your Recording

You can create the voicemail with any recording or audio-editing tool that can export a compatible file.

  • Record in a quiet environment.

  • Speak clearly and at a consistent volume.

  • Keep background noise to a minimum.

  • Export the recording as MP3 or WAV.

  • Use 64 kbps for voicemail compatibility.

If you already have a recording, you do not need to record it again. Convert or export the existing file to the recommended format and quality when necessary.

Third-party audio tools can be used for recording or conversion. MxP does not require a specific external tool.

Test and Troubleshoot Your Voicemail

Test Company or User Voicemail

  1. Call the MxP phone number from a different phone.

  2. Allow the call to reach voicemail.

  3. Confirm that the correct recording plays.

  4. Listen for distortion, unusually low volume, or playback problems.

Test a Workflow Voicemail Drop

Run the workflow with a test contact and confirm that the expected recording is delivered.

If the Audio Does Not Play Correctly

  1. Confirm the file is MP3 or WAV.

  2. Convert or re-export the recording at 64 kbps.

  3. Upload the new file.

  4. Save your changes.

  5. Test the call or workflow again.

For company or user voicemail, also review the Incoming Call Timeout. If the timeout is too long, a forwarding number's carrier voicemail may answer before the uploaded MxP voicemail can play.

Frequently Asked Questions

Q: What file format should I use for voicemail?

Use an MP3 or WAV file. For reliable voicemail playback, 64 kbps is recommended.

Q: Why does my voicemail file upload successfully but not play correctly?

The audio encoding or quality may not be compatible with reliable carrier playback. Re-export the recording at 64 kbps, upload it again, and retest.

Q: Can an individual user's voicemail override the company voicemail?

Yes. A user's voicemail can take precedence when the contact or phone number is assigned to that user.

Q: Where do I configure voicemail for an individual user?

Go to Sub-Account → Settings → Users, open the applicable user, and access the available call and voicemail settings.

Q: Can I use the same recording for a voicemail greeting and a workflow voicemail drop?

Yes, provided the file meets the supported format and audio-quality requirements for the intended use.
