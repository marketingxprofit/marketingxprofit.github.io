Use Trigger Links, Values, Flows & Snippets on Mobile

MxP mobile Conversations gives you faster access to the tools you use to personalize messages, track engagement, and reuse common responses. From the message composer, you can insert Trigger Links, dynamic values, WhatsApp Flows, and Snippets without leaving the conversation. These tools help teams respond efficiently while maintaining relevant, consistent communication with contacts.

What Are Mobile Conversation Tools?


Mobile Conversation tools bring commonly used messaging resources directly into the MxP mobile message composer. By tapping the + icon while responding to a contact, you can access supported Trigger Links, Custom Values and dynamic values, WhatsApp Flows, and Snippets. This makes it easier to add personalized or interactive content while working away from your desktop.


The available tools include:

  • Trigger Links: Insert trackable links that can record contact engagement and support click-based workflow automation.

  • Custom Values: Insert reusable or dynamic information into messages without manually entering the data each time.

  • WhatsApp Flows: Send supported interactive WhatsApp experiences that allow contacts to complete actions within WhatsApp.

  • Snippets: Find and insert reusable text from your organized Snippet library.

Key Benefits of Mobile Conversation Tools


Having these tools directly in mobile Conversations reduces the number of steps required to create relevant, actionable messages. Instead of switching between different areas of MxP or repeatedly typing the same information, users can access existing messaging resources from the conversation they are already working in.

  • Save Time: Reuse existing content and dynamic information instead of repeatedly typing common messages.

  • Increase Engagement: Add trackable links and interactive WhatsApp experiences that encourage contacts to take action.

  • Improve Personalization: Insert supported dynamic information into messages while reducing manual data entry.

  • Maintain Consistency: Use approved Snippets and saved values to keep messaging aligned across team members.

  • Support Automation: Use Trigger Links with workflows to respond automatically when a contact clicks a tracked link.

  • Stay Productive on Mobile: Access commonly used Conversation tools while communicating from the MxP or MxP mobile app.

Trigger Links


Trigger Links are trackable URLs that help you understand when a contact interacts with a link you send. When a contact clicks a Trigger Link, MxP can record the interaction, and a Trigger Link Clicked workflow trigger can use that activity to start automated follow-up actions. Trigger Links can be used across supported messaging channels, including SMS, email, Facebook and Instagram messages, and WhatsApp.


From mobile Conversations, selecting Trigger Link from the + menu allows you to add an existing Trigger Link to your outgoing message.


A Trigger Link can be useful when you want to:

  • Track interest in an offer or resource.

  • Identify contacts who click a particular URL.

  • Start a follow-up workflow after a click.

  • Apply tags or update contact information based on engagement.

  • Segment contacts according to link activity.


Creating or inserting a Trigger Link does not automatically create the follow-up automation. If you want an action to occur when the link is clicked, configure a workflow using the Trigger Link Clicked trigger.


Learn more about Trigger Links in MxP and the Trigger Link Clicked workflow trigger.

Custom Values and Dynamic Values


Dynamic values help you insert information without manually typing it into every conversation. MxP supports reusable Custom Values as well as other merge-field categories that can reference information associated with contacts, appointments, accounts, and other supported records. The available options can vary depending on the feature and context where the value is being inserted.


Custom Values are especially useful for information that stays consistent, such as:

  • Business phone numbers.

  • Support email addresses.

  • Website URLs.

  • Office hours.

  • Standard disclaimers.

  • Frequently used links.


Information that is unique to an individual contact or record is generally handled through the appropriate contact, appointment, or other dynamic merge field rather than a reusable account-level Custom Value.


From mobile Conversations, tap the + icon and select Custom Value to browse the supported dynamic information available for the message.


Whenever possible, select values using the available picker instead of typing merge-field syntax manually. This helps ensure that you insert a value supported by the current messaging context.


Learn more about using Custom Values in MxP.

WhatsApp Flows


WhatsApp Flows create guided, interactive experiences that contacts can complete within WhatsApp. Depending on the Flow you have configured, customers can provide information, make selections, or complete supported actions such as appointment booking without being redirected through a separate conversation experience.


Before using a Flow, your WhatsApp integration and the applicable Flow must be configured in MxP. WhatsApp settings, templates, phone numbers, and Flows are managed under Settings → WhatsApp.


From a supported WhatsApp conversation on mobile:

  1. Tap the + icon in the message composer.

  2. Select WhatsApp Flow.

  3. Choose the appropriate available Flow.

  4. Review the message or Flow selection.

  5. Send it to the contact.


Specific Flow requirements or limitations depend on how the Flow was created. For example, MxP's appointment-booking Flow documentation notes that calendars with payments enabled are not supported for that booking experience.


Learn more about WhatsApp Flows for appointment booking and WhatsApp Settings.

Snippets


Snippets are reusable text or email messages that help teams respond quickly while maintaining consistent communication. MxP's Snippet system supports folders and search, making it easier to manage larger libraries of approved responses. Supported Snippets can also contain personalization such as Custom Values and Trigger Links.


From mobile Conversations, use the Snippet picker when you need a prepared response without recreating the message manually.


You can:

  • Browse organized Snippet folders.

  • Search for a Snippet by name or keyword.

  • Select reusable content for the current conversation.

  • Review the inserted content before sending.

  • Edit or personalize the populated message when needed.


Selecting a Snippet populates prepared content in the composer rather than immediately sending the message, allowing you to review or modify it first.


Users accessing Snippets through Conversations need the Conversations → View & manage conversation permission.

How to Set Up and Use Mobile Conversation Tools


Preparing the supporting assets before starting a mobile conversation helps ensure that the correct links, values, Flows, and reusable messages are available when you need them. Most of these resources are configured elsewhere in MxP and then selected while composing a mobile message.


Use a Tool From Mobile Conversations

  1. Open the MxP or MxP mobile app.

  2. Open Conversations.

  3. Select the contact conversation you want to respond to.

  4. Confirm that you are using the appropriate messaging channel.

  5. Tap the + icon in the message entry area.

  6. Select the tool you want to use:

    • Trigger Link

    • Custom Value

    • WhatsApp Flow

    • Snippets

  7. Select the appropriate link, value, Flow, or Snippet.

  8. Review the content added to the message.

  9. Make any necessary changes.

  10. Send the message.

Frequently Asked Questions


Q: Do Trigger Links automatically start a workflow when I insert one into a mobile message?

No. The link can track a contact's click, but you must configure a workflow with the Trigger Link Clicked trigger if you want the click to initiate specific automated actions.


Q: Can I create a new Trigger Link from the mobile message composer?

The mobile enhancement is designed to provide access to Trigger Links while composing a message. Create and manage your Trigger Links in MxP before selecting them from the mobile conversation.


Q: What happens if a dynamic value does not have data available?

Behavior can vary depending on the feature and value. In many contexts, a merge field without corresponding source data can resolve as blank. Verify important contact or record data before sending live communications.


Q: Are Custom Values the same as contact-specific information?

Not always. Reusable Custom Values are intended for information that remains consistent, such as a support email or business URL. Contact-specific information is generally supplied by contact fields or other supported merge-field categories.


Q: Can I edit a Snippet after inserting it into a mobile conversation?

Yes. Inserting a Snippet populates prepared content so it can be reviewed and adjusted before it is sent.


Q: Why can't I find a WhatsApp Flow while composing a message?

Confirm that you are working in the appropriate WhatsApp conversation and that WhatsApp and the intended Flow have already been configured. WhatsApp Flows are managed from Settings → WhatsApp → Flows.


Q: Why don't I see these options in my mobile app?

Confirm that you are running MxP v3.98.1 or later or MxP v3.98.1 or later. White-labeled apps may require an updated version to make newly released mobile functionality available.
