How to add blog search and category navigation?

Blog Search and Category Navigation in MxP help visitors find and browse blog posts more easily. The Category Navigation element allows you to add links to blog categories and display a search bar. You can also customize navigation items, visibility, and appearance. 


This article explains how to add and configure these options in the Blog Builder.

What Is Blog Search and Category Navigation?


Category Navigation is an element in the MxP Blog Builder that displays links to selected blog categories. It can also include a search bar, allowing visitors to find blog content without navigating through individual categories.

Key Benefits of Blog Search and Category Navigation


Category Navigation provides a simple way to organize blog content and improve navigation for visitors.


  • Category-Based Navigation: Help visitors browse posts by category.

  • Blog Search: Allow visitors to search for blog content.

  • Customizable Navigation: Add, edit, duplicate, delete, or reorder navigation items.

  • Flexible Display: Control the search bar, Home icon, and appearance settings.

Category Navigation Settings


The Category Navigation element provides options for managing category links, search visibility, and appearance.

 These settings allow you to customize how visitors navigate your blog.


SettingDescription
TitleSet the name displayed for a navigation item.
Go ToChoose the navigation destination, such as Go to Category URL.
CategorySelect the blog category associated with the navigation item.
Open in New TabOpen the selected destination in a new browser tab.
Include search barShow or hide the blog search bar.
Show Home IconShow or hide the Home icon.
TypographyAdjust font settings, including size and weight.
StylesCustomize the element's appearance.

How to Add Blog Search and Category Navigation


Adding the Category Navigation element allows you to create category links and enable blog search from one location.


  1. Navigate to Sites → Blogs and open the blog you want to edit.

  2. Click Edit Site to open the Blog Builder.

  3. Click + Add Elements, select Elements, and search for Category Navigation.

  4. Drag the Category Navigation element onto the page.



  5. Select the added element to open its settings panel.



  6. Under General, locate the navigation items. You can add, duplicate, delete, or reorder them using the available controls.



  7. Click the three horizontal lines icon next to a category to open Configure Category.

  8. Enter the Title, select the Go To destination and Category, and enable Open in New Tab if needed.

  9. Click Submit to save the category configuration. Repeat for additional categories.

  10. Enable or disable Include search bar and Show Home Icon as needed.

  11. Adjust Typography or Styles if required.

  12. Save your changes and click Publish when ready.

Frequently Asked Questions


Q: Can I add multiple category links to my blog navigation?

A: Yes. You can add multiple navigation items and configure each with its own title and destination.



Q: Can I change the order of category links?

A: Yes. Drag the navigation items using the reorder handle in the General settings.



Q: Can I display Category Navigation without the search bar?

A: Yes. Disable Include search bar to hide the search field while keeping the category links visible.



Q: Can I link a category item to a specific blog category?

A: Yes. Open Configure Category, select Go to Category URL under Go To, and choose the appropriate blog category.



Q: Can I hide the Home icon from Category Navigation?

A: Yes. Disable Show Home Icon under General settings.
