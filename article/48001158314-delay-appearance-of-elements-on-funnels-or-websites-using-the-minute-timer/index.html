Delay Appearance of Elements on Funnels or Websites using the Minute Timer

The Minute Timer in MxP allows you to display hidden elements on your funnels or websites after a specified delay. For example, you can make a Sign up button appear 10 seconds after a page loads without using custom CSS. You can also hide the timer so visitors only see the button appear.

Key Benefits of the Minute Timer


The Minute Timer helps control when visitors see specific content, allowing you to create a more intentional page experience.

  • Delayed Element Display: Show hidden elements after a specified time.

  • No Coding Required: Configure delays using built-in timer settings.

  • Flexible Visibility: Hide the countdown while still revealing the selected element.

How to Set Up the Minute Timer


Setting up the Minute Timer involves hiding the target element, configuring the countdown, and choosing what happens when the timer expires.


  1. Open your funnel or website in the builder and select the element you want to delay, such as a button.

  2. Navigate to Styles → Visibility and hide the selected element.
    Tip: If you accidentally hide an element, use the Layers panel to find and restore it.



  3. Click the + icon, open Quick Add, search for Timer, and add the Minute Timer element to your page.



  4. Select the Minute Timer, open General → Timer Settings, and set the duration to 10 seconds.

  5. Set the expiration action to Show/Unhide Element, select the previously hidden button, and save your changes.

  6. To hide the countdown from visitors, hide the Minute Timer using its visibility settings.



  7. Click Preview and verify that the hidden button appears after 10 seconds.


Frequently Asked Questions


Q: Can I use the Minute Timer without displaying a countdown?

Yes. The original tutorial demonstrates hiding the timer while allowing its expiration action to run.

Q: Can I delay elements other than buttons?

The tutorial demonstrates a button. Check the timer's target-element options for other supported elements.

Q: Do I need custom CSS to delay an element?

No. You can use the Minute Timer to configure the delayed appearance of an element without custom CSS.

Q: What if my button doesn't appear after the timer expires?

Verify that the button is initially hidden, the timer duration is correct, and the expiration action targets the correct element.
