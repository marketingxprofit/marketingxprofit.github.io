Skills in the AI Agent Action

Overview


Skills are reusable procedures that your AI Agent loads only when a situation needs them. Use skills for rules that apply to some runs but not all, such as how to write a cold email, how to write a text message, or what to do when a lead reports an emergency.


The AI Agent Instructions describe the job of one action and go into every run. A skill sits in your skills library, can be attached to any AI Agent action, and stays out of the way until it is relevant. The agent reads a short description of every attached skill on each run, and loads the full instructions of a skill only when the situation matches that description.



Key Benefits


  • Shorter, focused Instructions: Move situational rules out of the Instructions box so each action only describes its own job.
  • Write once, reuse everywhere: A skill lives in your library and can be attached to any AI Agent action in the sub-account.
  • Lower cost per run: Only the skill description goes into every run. The full instructions load only when the skill is used.
  • Ready to use: Every sub-account includes four built-in writing skills that you can attach, edit, or delete.
  • Easy to set up: Create a skill with the AI Assistant, write it yourself, or attach one from your library.



Skill Details


Every skill has three fields.


FieldDescriptionMandatory
NameA short name for the skill, such as "Emergency service requests". This is how the skill appears in the action and in your library.Yes
When should the agent use this?One or two sentences that describe when the agent should use the skill. The agent reads this field on every run to decide whether to load the skill, so name concrete situations, keywords, or conditions.Yes
InstructionsThe procedure the agent follows when it uses the skill. Write numbered steps, decision rules, and anything the agent must never do. The agent reads this field only when it uses the skill.Yes

Built-in Skills


Every sub-account includes four built-in skills, marked with a Built-in tag in your library. They work like any other skill: you can attach them to any AI Agent action, edit them, or delete them.


SkillWhen the agent uses it
HumanizerWhen it writes any message or text, on any channel. Removes the known signs of AI-generated writing.
Write-wellWhen it writes any message or text, on any channel. Removes AI writing patterns and keeps the writing clear, simple, and direct.
Cold-emailWhen it sends a first-touch or follow-up email to a lead who has not replied or spoken to you before, such as outreach, prospecting, or re-engagement.
Sms-writerWhen it sends an SMS to a contact, such as reminders, follow-ups, confirmations, win-backs, or promotional texts.



How to Add a Skill


  1. Open a workflow and add or select an AI Agent action.
  2. In the action panel, scroll down and expand the Skills section.
  3. Click + Add skill. If the action already has skills, click + Add next to the Skills title.
  4. Choose one of the three options described below.


The Skills section before any skill is added.


The three ways to add a skill.



Option 1: Create with AI


The AI Assistant opens on the left and asks what the skill should do, when it should be used, and what it must never do. Answer in your own words. The assistant asks a short follow-up only if something is missing, then drafts the skill.


Review the draft in the skill form, make any changes, and click Create & attach.


Create with AI starts a short conversation in the AI Assistant.



Option 2: Write skill instructions


  1. Enter a Name.
  2. Fill in When should the agent use this? with the situations that should load the skill.
  3. Write the Instructions. Use the toolbar to add lists and headings. Click Enhance prompt to let AI improve the wording.
  4. Click Create & attach. The skill is saved to your library and attached to this action.


The skill form with all three fields filled in.



Option 3: Add existing skill


  1. Search or scroll your library. Built-in skills show a Built-in tag.
  2. Click a skill row to read its full description and instructions before you attach it.
  3. Click Attach. Attached skills move to the Attached group at the top of the list.
  4. Click Done when you finish.


Your skills library, with the four built-in skills.


Click a skill to read it before you attach it.



Manage Skills


  • Edit a skill: Hover over a skill row in the action and click the pencil icon. You can also open the skill from Add existing skill and choose Edit from the options menu.
  • Detach a skill: Hover over a skill row and click the X icon. The skill is removed from this action but stays in your library.
  • Delete a skill: Open the skill from Add existing skill and choose Delete from the options menu. Deleting removes the skill from your library and from every action that uses it.


Note: A skill is shared by every action it is attached to. When you edit a skill, the change applies to all of those actions.


Hover over a skill to edit or detach it.



Example: Lead Follow-up Agent


A heating and cooling company wants to follow up with every lead who submits a quote request. Most leads need a friendly email and text. A few report emergencies, such as a gas smell or no heat, and those need a different response.


Setup


  • Trigger: Form Submitted (Request a quote form).
  • Action Name: Lead follow-up agent.
  • Instructions: "You follow up with new leads for Apex Heating and Cooling. A lead just submitted the Request a quote form. Send the lead one email and one SMS that thank them, restate their request, and offer a time to talk."
  • Tools: Send email and Send SMS, with Let AI decide all field values turned on.
  • Skills: Cold-email (built-in), Sms-writer (built-in), and a custom skill called Emergency service requests.

NameEmergency service requests

InstructionsIf the lead reports a gas smell, tell them to leave the building and call the gas company first. Never book a visit for a gas smell. The finished action with two tools and three skills.


What happens on a run


  • A routine quote request: The agent loads Cold-email to write the email and Sms-writer to write the text. Emergency service requests stays unloaded.
  • A lead who writes "no heat since last night": The agent loads Emergency service requests along with Cold-email and Sms-writer, and offers a same-day slot without quoting a price.
  • A lead who reports a gas smell: Emergency service requests tells the agent to send safety instructions first and not to book a visit.



How the Agent Uses Skills


  • More than one skill can apply: When a situation matches several skills, the agent loads all of them and follows them together.
  • Action Instructions come first: If a skill and the action Instructions disagree, the agent follows the action Instructions.
  • Specific rules win over general rules: A rule such as "keep the subject under five words" wins over a general rule such as "write short".
  • "Never" rules win: If one skill says to do something and another skill says never to do it, the agent does not do it.



Tips for Writing Good Skills


  • Name concrete triggers: Write "Use when a lead reports no heat or a gas smell" instead of "Handles emergencies". The agent decides from this field alone.
  • Keep one purpose per skill: Two small skills are easier to manage than one large skill that covers many situations.
  • Put prohibitions last: End the instructions with clear "Never" lines.
  • Do not repeat the action's job: The job of one action belongs in its Instructions. Rules you reuse across actions, or that apply only sometimes, belong in a skill.



FAQs


What is the difference between Instructions and a skill?

Instructions describe the job of one AI Agent action and are sent on every run. A skill is a reusable procedure that lives in your library, can be attached to many actions, and is loaded only when its description matches the situation.


Does a skill run every time the action runs?

No. The agent reads the name and description of every attached skill on each run, and loads a skill's instructions only when the situation matches its description.


What happens if two skills apply at the same time?

The agent loads both and follows them together. If they disagree, the action Instructions win first, then the more specific rule, and a "Never" rule wins over a rule that says to do something.


Can I use the same skill in more than one workflow?

Yes. Skills are saved to the sub-account library. Attach the same skill to any AI Agent action in any workflow.


If I edit a skill, does it change everywhere?

Yes. A skill is shared by every action it is attached to, so an edit applies to all of them.


What is the difference between detaching and deleting a skill?

Detaching removes the skill from one action only. Deleting removes it from your library and from every action that uses it.


Can I edit or delete the built-in skills?

Yes. Built-in skills work like any other skill in your library.


Can a skill use a knowledge base?

Yes. Name the knowledge base in the skill instructions, for example "Search the Service policies knowledge base for warranty terms." Make sure the action has the Knowledge base search tool added.


Can a skill send messages or update contacts by itself?

No. A skill tells the agent how to do something. The agent still needs the right tools on the action, such as Send email or Send SMS, to act.


Do I need skills to use the AI Agent action?

No. Skills are optional. Many users start with Instructions and tools, then add skills later as patterns repeat.
