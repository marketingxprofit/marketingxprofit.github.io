What is Event Embedding?

Event embedding allows you to display your public event pages directly on your own websites, funnels, or external platforms using a simple embed code. Instead of redirecting visitors to a separate event URL, the entire event registration experience—including event details, schedules, and the registration form—appears within your own page.

This feature generates an iframe-based embed code that you can copy with one click and paste into any HTML editor, website builder, or content management system. Attendees can browse event information and complete their registration without ever leaving your website.

How to Embed an Event Page

Follow these steps to generate and deploy the embed code for your event page.

Step 1
Navigate to Your Event

Go to the Events section in your MxP account and select the public event you want to embed.


Step 2
Open the Share Event Modal

Click the Share Event button to open the sharing options modal.


Step 3
Access the Embed Code Tab

Within the Share Event modal, select the Embed Code option. The system generates an iframe-based embed code for your event page. Click the Copy button to copy the embed code to your clipboard with a single click.


Step 4
Paste the Code into Your Website

Open the Custom code section of your website, funnel, or platform and paste the embed code where you want the event page to appear. Save and publish your changes.



Success

Your event page is now embedded and ready to accept registrations directly from your website.

Where to Use Embedded Event Pages

Use Case 1

Frequently Asked Questions

Q: Can I embed any type of event?
The embed code is available for public events. Private or restricted events may require additional access controls and may not be suitable for embedding on public websites.
Q: Does the embedded event page include the full registration process?
Yes, the embedded experience includes all event details, schedules, and the complete registration form. Attendees can browse information and register without leaving your website.
Q: Can I customize the appearance of the embedded event page?
The embedded event page reflects the design and branding settings configured in your event settings. Customize your event page appearance within MxP before generating the embed code.
Q: Will the embed code work on mobile devices?
Yes, the embed code generates a responsive iframe that adapts to different screen sizes, providing a seamless experience on desktop, tablet, and mobile devices.
Q: Can I embed the same event on multiple websites?
Yes, you can use the same embed code on as many websites or pages as needed. All registrations will be captured in your MxP account regardless of where the embed code is deployed.
Q: What happens if I update the event details after embedding?
The embedded event page automatically reflects any changes you make to the event in MxP. You do not need to regenerate or update the embed code when you modify event details.
Q: Can I track registrations that come through the embedded event page?
Yes, all registrations made through the embedded event page are tracked and recorded in your MxP Events dashboard, just like registrations made through the direct event URL.
Q: Where do I find the Share Event modal?
Navigate to the Events section in your MxP account, select the event you want to share, and click the Share Event button. The Embed Code option is available within the sharing options modal.
