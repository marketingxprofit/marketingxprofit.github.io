Chat Widget - Send your leads to Whatsapp Chat


What Is the WhatsApp Chat Widget?


The WhatsApp Chat Widget lets website visitors start a WhatsApp conversation with your business directly from your site. It gives leads a simple way to move from your website into WhatsApp while keeping the conversation connected to the WhatsApp channel configured in MxP.


Once the visitor sends the WhatsApp message, the conversation can be managed through MxP Conversations.

Prerequisites


Before using the WhatsApp Chat Widget, make sure a WhatsApp number is configured and connected in the sub-account. The widget uses that connected number as the destination for visitor conversations.

Prerequisite: A WhatsApp number must be configured and connected in the sub-account before you can use the WhatsApp Chat Widget.

How to Set Up the WhatsApp Chat Widget


The WhatsApp Chat Widget can be configured from the Chat Widget settings in MxP. You can customize its appearance, visitor-facing fields, destination number, and message experience before installing it on your site.

  1. Go to Sites > Chat Widget.

  2. Create a new Chat Widget or open an existing widget.



  3. Select WhatsApp Chat as the chat type.


  4. Choose the WhatsApp number visitors should contact.

  5. Configure the widget's appearance and visitor experience.


  6. Save your changes.

Customize the Chat Window


The Chat Window controls what visitors see before they continue to WhatsApp. Use these settings to match the widget to your brand and collect the information you need before the conversation begins.


You can customize elements such as:

  • Heading and welcome message.

  • Colors and branding.

  • Supported visitor information fields.

  • The Message field.

  • Other available Chat Widget display settings.


Available fields can vary depending on the widget configuration.


Prefilled Message


You can configure a suggested message in the Chat Window for visitors starting a WhatsApp conversation. Visitors can use the message as provided or edit it before continuing to WhatsApp.


For example, you might prefill:

Hi, I’m interested in learning more about your services.

How the WhatsApp Chat Widget Works


The widget creates a simple handoff from your website into WhatsApp.


The typical flow is:

  1. A visitor opens the Chat Widget on your website.

  2. The visitor completes the applicable fields.

  3. The visitor continues from the widget.

  4. They are redirected to WhatsApp to start a conversation with the selected WhatsApp number.

  5. The visitor sends the WhatsApp message.

  6. The conversation can then be managed through the connected WhatsApp channel in MxP Conversations.

Note: The exact WhatsApp experience can vary based on the visitor's device, browser, and installed applications. Avoid assuming that every visitor will always open WhatsApp Web or the mobile app.

Install the WhatsApp Chat Widget


After configuring the widget, install it based on where your website is hosted.


MxP Websites and Funnels


For MxP-hosted Websites and Funnels:

  1. Open the applicable Website or Funnel.

  2. Go to the relevant site settings.

  3. Select or enable the Chat Widget you created.

  4. Save and publish the site.


External Websites


For websites hosted outside MxP:

  1. Open the Chat Widget installation options.

  2. Copy the generated embed code.

  3. Add the code to the appropriate area of your external website.

  4. Publish the website.

  5. Test the widget on the live page.

Troubleshooting the WhatsApp Chat Widget


If WhatsApp is unavailable as a chat type or no destination number is available, first confirm that a WhatsApp number is properly configured and connected in the sub-account.


Also check:

  • The correct WhatsApp number is selected in the widget.

  • The widget has been saved.

  • The widget is installed on the intended Website, Funnel, or external site.

  • The site has been published after installation.

  • The visitor completes the applicable widget fields before continuing.

  • The visitor actually sends the message in WhatsApp before expecting the conversation to appear in MxP Conversations.

Frequently Asked Questions


Q: Does the WhatsApp Chat Widget require a connected WhatsApp number?

Yes. A WhatsApp number must be configured and connected in the sub-account before you can use WhatsApp Chat as the widget type.


Q: Does the widget always open WhatsApp Web?

No. The resulting WhatsApp experience can depend on the visitor's device, browser, and installed applications. The widget redirects the visitor to WhatsApp without requiring a specific WhatsApp Web or mobile behavior.


Q: When does the conversation appear in MxP Conversations?

The visitor needs to send the WhatsApp message. Once the message is sent through the connected WhatsApp channel, the conversation can be managed in MxP Conversations.


Q: Can I prefill a WhatsApp message for visitors?

Yes. You can configure a suggested Message in the Chat Window. Visitors can use the message as provided or edit it before continuing to WhatsApp.


Q: Can I use the WhatsApp Chat Widget on an external website?

Yes. Use the generated Chat Widget embed code and add it to the appropriate area of the external website.
