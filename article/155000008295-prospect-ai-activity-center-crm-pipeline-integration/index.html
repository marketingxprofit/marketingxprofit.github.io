What is the Prospect AI Activity Center?

The Prospect AI Activity Center provides comprehensive visibility into AI agent performance and execution history. This centralized interface displays when agents run, how many prospects they discover, which business categories they find, and why they might not be finding results.

The Activity Center transforms Prospect AI from a simple discovery tool into a complete AI SDR platform by offering actionable insights and recommendations when agents underperform. Instead of guessing why an agent isn't finding prospects, you receive specific suggestions to improve discovery results.

Combined with native CRM pipeline integration at the sub-account level, the Activity Center enables you to monitor, diagnose, and optimize your entire AI-powered prospecting operation from a single dashboard.

The Summary tab consolidates agent configuration, performance statistics, and discovery criteria in one view.

Component 1

Current targeting parameters, search radius, conversion score filters, and GBP rating requirements.

Component 2

Total prospects discovered, prospects added in recent runs, and discovery rate trends.

Component 3

Component 5

Component 1

Chronological log of all agent runs with timestamps and results.

Detailed results from past executions including prospects found and business categories discovered.

Diagnostic information for completed runs and any errors encountered during execution.

Activity Center & Execution History

The Activity Center explains what your AI agents have been doing and provides actionable insights when performance needs improvement.

You can review the following information for each agent:

Last Execution Time — When the agent most recently completed a discovery run.
Next Scheduled Run — Upcoming execution time based on schedule configuration.
Prospects Found — Number of qualifying prospects discovered in each run.
Business Categories — Which industry segments and business types were identified.
Historical Execution Logs — Complete run history with timestamps and results.

Actionable Recommendations

When an agent doesn't find prospects, the Activity Center provides specific suggestions to improve discovery performance rather than leaving you to diagnose the issue manually.

Common recommendations include:

Recommendation 1
Increase Search Radius

Expand the geographic area to discover more qualifying businesses.

Recommendation 2
Relax Conversion Score Filters

Lower the minimum conversion score threshold to include more potential prospects.

Recommendation 3
Lower GBP Rating Requirements

Adjust Google Business Profile rating filters to capture a broader prospect pool.

Recommendation 4
Upgrade Monthly Limit or Reallocate Usage

Increase the account's monthly lead limit or redistribute credits across agents to allow more discovery runs.

CRM Pipeline Integration & Setup

Prospect AI integrates directly with MxP CRM pipelines at the sub-account level, enabling automatic prospect routing from discovery to sales workflow. This native integration eliminates manual transfer of prospects between Prospecting and CRM modules.

When configuring an agent within a sub-account, you can select which pipeline and stage newly discovered prospects should enter. Every qualifying prospect is automatically added to your chosen pipeline, making it immediately available for review, automation rules, and outreach campaigns.

Important

CRM pipeline integration is only available when configuring agents at the sub-account level. Agency-level agents do not support automatic pipeline routing.

Integration Options

Setting 1
Target Pipeline

Choose which pipeline prospects should enter when discovered by the agent.

Setting 2
Entry Stage

Select which pipeline stage prospects should be placed in upon discovery.

Automation Benefit

Pipeline integration enables you to apply automation rules, assign tasks, and trigger workflows immediately upon prospect discovery—without manual data transfer.

How to Set Up CRM Pipeline Integration

Follow these steps to configure automatic prospect routing from Prospect AI to your CRM pipeline within a sub-account.

Step 1
Access a Sub-Account

Navigate to the sub-account where you want to configure pipeline integration. CRM pipeline integration is not available at the agency level.

Step 2
Navigate to Prospect AI

Access the Prospect AI module from the MxP main menu within the sub-account.


Step 3
Select an Agent

Click on an existing AI agent or create a new agent to configure.


Step 4
Enter Edit Mode

From the agent workspace, click the Edit button to modify agent configuration.


Step 5
Locate Pipeline Integration Settings

Scroll to the Lead Encrichment stage within the agent configuration screen. Toggle the Save new prospects to Contacts and check on Also add to a pipeline stage button.



Step 6
Select Target Pipeline and Entry Stage

Choose which pipeline newly discovered prospects should be added to from the dropdown menu. Choose which stage within the selected pipeline prospects should enter upon discovery.


Step 7
Save Configuration

Click Save to apply pipeline integration settings to the agent.

Configuration Applied

All future prospects discovered by this agent will automatically be added to the selected pipeline and stage. Existing prospects are not retroactively moved.

Frequently Asked Questions

Q: Does the Activity Center show real-time agent execution status?
Yes. The Activity tab displays when agents last ran, upcoming scheduled executions, and historical logs. Execution data updates after each agent run completes.
Q: Is CRM pipeline integration available at the agency level?
No. CRM pipeline integration is only available when configuring agents within a sub-account. Agency-level agents do not support automatic pipeline routing.
Q: What happens if I change pipeline integration settings for an existing agent?
Only newly discovered prospects will be added to the updated pipeline and stage. Existing prospects remain in their current location and are not automatically moved.
Q: Can different agents add prospects to different pipelines?
Yes. Each agent within a sub-account has independent pipeline integration settings. You can route different prospect types to different pipelines based on agent specialization.
Q: How do I access the actionable recommendations when an agent finds no prospects?
Open the agent workspace and navigate to the Activity tab. If the most recent run returned zero prospects, the Activity Center displays specific recommendations to improve discovery performance.
Q: Does pipeline integration work with custom pipelines?
Yes. You can select any pipeline configured in your sub-account, including custom pipelines and custom stages.
Q: Can I view which business categories an agent discovered without opening execution logs?
Yes. The Activity Center displays discovered business categories for each execution run, providing visibility into prospect composition without reviewing detailed logs.
Q: How does the search bar filter agents on the dashboard?
The search bar matches agent names, descriptions, and targeting criteria. Enter keywords related to industry focus, location, or configuration details to quickly locate specific agents.
Q: Can I disable pipeline integration after setting it up?
Yes. Edit the agent configuration and remove the pipeline and stage selections to disable automatic routing. Future prospects will no longer be added to the CRM pipeline automatically.
