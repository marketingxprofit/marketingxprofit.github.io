How to Use Ask AI Dispatch on WhatsApp

 Connect your WhatsApp number to Ask AI Dispatch so you can message your Ask AI copilot, review conversations, and move your connection when needed. 
What You'll Learn

Ask AI Dispatch lets you reach your Ask AI copilot directly from WhatsApp. This guide covers connecting and verifying your number, using Ask AI from WhatsApp, reviewing Dispatch conversations, and moving an existing connection.

What is Ask AI Dispatch on WhatsApp?

Ask AI Dispatch on WhatsApp gives you another way to reach the same Ask AI copilot available in MxP. After connecting your WhatsApp number, you can send Ask AI requests directly from WhatsApp instead of opening a new Ask AI conversation in MxP.

Ask AI can retrieve platform data, create content and assets, and perform supported platform actions through conversational requests.

Ask AI feature

WhatsApp is a Dispatch channel within Ask AI. It is separate from MxP's customer-facing WhatsApp integration.

2

Key Benefits of Ask AI Dispatch on WhatsApp

Ask AI Dispatch makes your copilot accessible from WhatsApp while keeping the same Ask AI experience. This gives you another way to handle supported work when you are away from your computer.

Work from WhatsApp — Send Ask AI requests from your phone without opening MxP.
Use your existing Ask AI copilot — Access supported Ask AI capabilities through another conversation channel.
Handle CRM tasks on the go — Look up contacts, review opportunities, update supported records, and check calendar information.
Delegate content creation — Request supported content such as blog drafts, email templates, images, video, or audio.
Schedule recurring work — Ask Ask AI to create supported recurring tasks from the conversation.
Use your custom Skills — Run supported Ask AI Skills from your WhatsApp conversation.
Keep your conversations accessible — Review, search, and sort WhatsApp Dispatch conversations from Ask AI in MxP.

Prerequisites and Limitations

Understanding connection ownership and number limits before setup helps prevent conflicts when linking your WhatsApp number to Ask AI Dispatch.

  • Only one WhatsApp number can be connected to a location at a time.
  • Each connected WhatsApp number is tied to the user who connected it.
  • Other users cannot manage or take over your connected number.
  • If your own number is already connected elsewhere, you can move it during the connection process.
  • Verification requires access to WhatsApp so you can receive the verification code.
  • The verification code expires after five minutes.
  • A number already connected by another user cannot be moved into your connection.

How To Setup Ask AI Dispatch on WhatsApp

Connecting your number creates the link between WhatsApp and Ask AI. Verification confirms that you control the number before Ask AI begins accepting requests from it.

  1. Open Ask AI.
  2. Select Customize.
  3. Select Dispatch.
  4. Click Connect WhatsApp.
  1. Select your country.
  2. Enter your WhatsApp number without the country code.
  3. Click Continue.
  4. On the verification screen, locate the QR code and the Enter your verification code field.
  1. Scan the QR code with your phone.
  2. Open the WhatsApp conversation.
  3. Send a message to receive your verification code.
  4. Wait for the verification message in WhatsApp.
  5. Return to MxP.
  6. Enter the code in Enter your verification code.
  7. Click Verify.
  8. After verification succeeds, return to WhatsApp and message the connected Ask AI conversation whenever you want to use your copilot.
Verification code expiration

The verification code expires in five minutes.

Use Ask AI From WhatsApp

Once your number is connected, you can make supported Ask AI requests directly in the WhatsApp conversation. Use natural-language instructions just as you would when working with Ask AI inside MxP.

  • Manage contacts and opportunities: Look up contact details, add notes, update supported fields, or make supported opportunity changes.
  • Check calendars and appointments: Request an upcoming schedule or ask Ask AI to perform supported appointment actions.
  • Create blog content: Delegate a blog draft and review the resulting content.
  • Generate email templates: Request reusable email content for follow-up, outreach, or replies.
  • Generate images: Create or refine supported images through conversational prompts.
  • Generate video and audio: Request supported video or audio assets through Ask AI.
  • Create recurring tasks: Ask for supported work to run on a schedule instead of repeating the request manually.
  • Run a Skill: Use instructions you have already configured in Ask AI Skills.
  • Ask support questions: Ask product or account questions that can be routed to Support AI.
  • Ask general questions: You do not need to start with a specific platform action.
Actions that change data

Ask AI may request confirmation before performing actions that change data.

Review WhatsApp Conversations in Dispatch

Dispatch keeps your WhatsApp Ask AI sessions available inside MxP so you can return to earlier conversations without relying only on the WhatsApp thread.

  1. Open Ask AI.
  2. Select Customize.
  3. Select Dispatch.
  4. Click View Dispatch Sessions.
  5. Review the conversations under Dispatch conversations.
  1. Use Search conversations to find a conversation.
  2. Use Dispatch type and select WhatsApp to view WhatsApp Dispatch conversations.
  3. Use Sort to change the conversation order when needed.
7

Move Your WhatsApp Number

If your WhatsApp number is already connected through Ask AI Dispatch elsewhere under your user, you can move it during the new connection flow without manually disconnecting it first.

  1. Open Ask AI.
  2. Select Customize.
  3. Select Dispatch.
  4. Start the WhatsApp connection process.
  5. Enter the WhatsApp number that is already connected elsewhere.
  6. Continue until the Move WhatsApp number? confirmation appears.
  1. Review where the number is currently connected.
  2. Click Yes, move it here.
  3. Complete any remaining verification steps shown in the connection flow.

Moving the number disconnects it from the previous Ask AI Dispatch connection and connects it to the current one.

Another user's number cannot be taken over

If the number is already connected by someone else, Ask AI Dispatch blocks the connection instead of presenting the move option.

Frequently Asked Questions

Q: Is Ask AI Dispatch on WhatsApp a separate version of Ask AI?
No. WhatsApp is another Dispatch channel for reaching the same Ask AI copilot.
Q: Can I connect more than one WhatsApp number to the same location?
No. Only one WhatsApp number can be connected to a location at a time.
Q: Can I move my WhatsApp number if it is already connected elsewhere?
Yes. If the existing connection belongs to you, the setup flow can display Move WhatsApp number?. Select Yes, move it here to move the connection.
Q: Can I take over a number connected by another user?
No. Ask AI Dispatch does not allow one user to take over another user's connected WhatsApp number.
Q: Where can I find previous WhatsApp Ask AI conversations?
Open Ask AI → Customize → Dispatch, then click View Dispatch Sessions. WhatsApp conversations appear under Dispatch conversations.
Q: Can I search my WhatsApp Dispatch conversations?
Yes. Use Search conversations on the Dispatch conversations page.
Q: How long is the WhatsApp verification code valid?
The verification code expires in five minutes.
