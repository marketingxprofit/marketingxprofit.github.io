Affiliate Manager Public API: Overview, Endpoints, and Scopes

The Affiliate Manager Public API lets developers and Marketplace app builders manage a location's affiliate program programmatically. Through REST API endpoints, developers can work with affiliates, campaigns, referred customers, commissions, payouts, payout methods, and affiliate media without relying solely on the Affiliate Manager UI.

The API suite includes 28 new endpoints and 4 existing endpoints that were tightened, for 32 endpoints in total. It is available in the v3 API catalog on the MxP Developer Marketplace.

Key Capabilities


  • Manage affiliates without the UI: Onboard, update, activate, and deactivate affiliates from your own app.

  • Report on commissions and payouts: Pull commission and payout data into external dashboards, reconciliation, and finance workflows.

  • Attribute conversions: Validate referral IDs and create leads from external landing pages and checkout flows to credit conversions to the right affiliate.

  • Collect payout details in your own flow: Manage affiliate payout methods, including a lookup of the bank fields each country requires.

Who Can Use This Feature


Developers and agencies building custom dashboards, CRM integrations, automated reporting, or partner apps using Affiliate Manager.


API Endpoint Groups


All endpoints are available under /affiliate-manager and are organized into seven groups:


GroupEndpointsWhat you can do
Affiliates10Create, read, update, and list affiliates. Activate or deactivate an affiliate. Move an affiliate between campaigns. Set and validate referral IDs. Suspend an affiliate from a campaign. Upload a tax form.
Payout Methods6Create, read, update, and delete an affiliate's payout methods. Mark a payout method as primary. Look up the bank fields required for each country.
Commissions5Create, list, and delete commissions. Update commission status. Deny commissions.
Customers5List the customers an affiliate referred. Create and validate leads. Update a customer's state. Delete a customer.
Affiliate Media3List, update, and delete affiliate media files and folders for a location.
Campaigns2List campaigns and retrieve a campaign with its commission structure.
Payouts1List payouts for a location.

Important API Behaviors


Before using the Affiliate Manager API, review these endpoint-specific behaviors:


  • Creating affiliates: If an affiliate with the same email address already exists in a location, the Create Affiliate endpoint updates the existing affiliate instead of creating a duplicate.

  • Updating affiliates: The Update Affiliate endpoint replaces the affiliate record. Fields omitted from the request body are cleared, so include all fields you want to retain.

  • Referral IDs: Referral IDs must be unique within a location, even when affiliates belong to different campaigns.

  • Suspending affiliates: Suspending an affiliate from a campaign cancels their pending and denied payouts, commissions, and transactions. Reinstating the affiliate returns canceled items to pending status.

  • Payout methods: An affiliate can have one PayPal payout method and one bank payout method. The first method added becomes the primary method.

  • Deleting payout methods: You cannot delete the primary payout method while the affiliate has more than one payout method.

  • Payout information: The List Payout Methods endpoint returns only the last four characters of bank account values.


Refer to the Affiliates and Payout Methods API documentation for endpoint-specific requirements.

Authentication and Scopes


The APIs use standard v3 OAuth 2.0 with Location-Access. Two scopes control what your app can do:


  • affiliate-manager.readonly: Required for the 12 endpoints that read data.

  • affiliate-manager.write: Required for the 20 endpoints that create, update, or delete data.

How to Get Started


  1. Open the Affiliate Manager API v3 documentation in the MxP Developer Marketplace.

  2. Create or open your app in the Developer Marketplace and enable the affiliate-manager.readonly and/or affiliate-manager.write scopes, depending on what your app needs to do.

  3. Authorize your app for a location using OAuth 2.0 with Location-Access.
    For instructions on registering an app, configuring OAuth settings, installing the app for a location, and obtaining access tokens, see the MxP OAuth 2.0 documentation.

  4. Call the endpoints for the group you need. Each group has its own reference page with request and response details:

    • Affiliates
    • Payout Methods
    • Commissions
    • Customers
    • Affiliate Media
    • Campaigns
    • Payouts

Common Use Cases


  • Build a custom affiliate dashboard for your clients.

  • Sync affiliates, commissions, and payouts with your CRM or finance tools.

  • Onboard affiliates from your own signup flow, including collecting their payout details.

  • Attribute leads and sales from external landing pages and checkout flows back to the right affiliate.

Frequently Asked Questions


Q: Do I need an app in the Developer Marketplace to use these APIs?

The APIs use v3 OAuth 2.0 with Location-Access, so your integration needs authorization for the location whose affiliate data it accesses.

Q: Where can I find request and response examples?

You can find examples in the Affiliate Manager section of the MxP API documentation linked above. Each endpoint group has its own reference page.
