Force Update Mechanism for the MxP Mobile App

Keeping your MxP mobile app updated helps you access the latest improvements, security enhancements, and performance fixes. The Force Update Mechanism makes certain app updates mandatory, requiring users to install the latest required version before continuing to use the app. When an update is required, a prompt provides a direct link to the updated application. This helps maintain a secure, stable, and consistent mobile experience.

What is the Force Update Mechanism for the MxP Mobile App?


The Force Update Mechanism is a mobile app feature that ensures users move to the required application version when an update is enforced. Instead of allowing users to continue using an outdated version, the app displays an update prompt that directs them to install the current version.


Once the update is complete, users can return to the app and continue their activities.


Important: The exact applications covered by this release are not confirmed.

Key Benefits of the Force Update Mechanism


Mandatory app updates help maintain a reliable mobile experience by ensuring users receive important improvements. Keeping supported app versions current can also reduce compatibility issues, improve security, and provide more consistent access to features.

  • Enhanced Security: Receive the latest available security patches and improvements through required app updates.

  • Improved App Stability: Benefit from fixes and optimizations that help the mobile app operate more reliably.

  • Access to Updated Features: Use the latest enhancements and functionality included in the required app version.

  • Consistent User Experience: Reduce differences in functionality caused by users running outdated application versions.

  • Simplified Update Process: Access the latest required app version through a direct update link.

  • Reduced Version-Related Issues: Minimize potential problems associated with continuing to use older app versions.

How Mandatory App Updates Work


The Force Update Mechanism helps keep users on a supported version of the mobile app. When an update is mandatory, the application displays a prompt directing users to install the required version before resuming their work.


The update experience follows a straightforward process:

  1. An update becomes required: The mobile app determines that the installed version must be updated.

  2. The update prompt appears: Users receive a message indicating that an app update is required.

  3. Users are directed to the latest version: The prompt provides a direct link to the updated application.

  4. The required update is installed: Users download and install the app update.

  5. App usage resumes: After updating, users can reopen the mobile app and continue using its features.


Important: Mandatory updates require users to update before continuing. The prompt is not intended to function as an optional update reminder.

Understanding the Force Update Prompt


The Force Update prompt communicates that the installed application version must be updated before the user can continue. Recognizing the prompt helps users understand why app access is temporarily restricted and what action is needed to restore access.


When a required update is detected, the user receives an update notification with a direct link to the latest app version.


The update prompt serves three primary purposes:

  • Communicates the requirement: Informs users that an update is necessary to continue using the app.

  • Provides an update action: Offers a direct path to obtain the latest required version.

  • Restricts access to outdated versions: Prevents users from continuing with the older version until the mandatory update is completed.

Mandatory Updates vs. Optional Updates


Understanding the difference between mandatory and optional updates helps users know when they must take action. A mandatory update prevents continued use of an outdated application version, while an optional update generally allows users to decide when to install a newer version.

FeatureMandatory UpdateOptional Update
Update requirementRequired to continue using the appUser can generally choose when to update
App accessRestricted until the update is completedTypically remains available
User actionInstall the required versionUpdate when convenient
Primary purposeEnforce a required app versionEncourage adoption of a newer version


Important: This comparison explains the general difference between the two update types. 

How to Update the MxP Mobile App


Completing a mandatory update ensures the mobile application runs on the required version. Following the update prompt provides the intended path to install the newer version and resume using the app.


Step 1: Open the Mobile App


Launch the mobile application on your device. If the installed version requires an update, a Force Update prompt will appear.


Step 2: Select the Update Option


Tap the update button displayed in the notification. The application will provide a direct link to the latest required version.


Step 3: Install the Latest App Version


Follow the provided update link to access the updated application.

  1. Open the destination provided by the app.

  2. Locate the available application update.

  3. Select the option to update the installed app.

  4. Allow the installation to complete.


Step 4: Reopen the Mobile App


After installation is complete, return to the mobile application. The updated version should allow you to resume normal app usage without the previous mandatory update restriction.


Important: The Force Update Mechanism is intended to prevent access until the required update is completed. If the prompt continues to appear after updating, confirm that the installed app version is current.

Troubleshooting Mandatory App Updates


A mandatory update may be interrupted by download, installation, or app store availability issues. Identifying the cause can help users complete the required update and regain access without repeatedly attempting the same unsuccessful action.

IssueRecommended Action
The app store does not show an updateConfirm that you opened the correct app listing and check whether an update is available.
The update fails to downloadCheck your internet connection and available device storage, then retry the update.
The update does not installCheck whether the device meets the app's current operating system requirements.
The update prompt continues to appearClose and reopen the app after installation, then verify that the required version was installed.
The update link does not openOpen the application's listing in the relevant app store and check for an available update.
The issue persistsContact MxP Support and provide the device type, installed app version, and a screenshot of the issue.


Note: These are general mobile troubleshooting recommendations.

Frequently Asked Questions


Q: Can I continue using the app without installing a mandatory update?

No. When a Force Update is required, users must install the required app version before continuing to use the application.


Q: Why am I being asked to update the app even though it was working previously?

The application may require a newer version to provide updated functionality, security improvements, or fixes. An update can become mandatory even if the older app version previously worked.


Q: What should I do if the required update is not available in my app store?

Check that you are viewing the correct application listing and that the update is available for your device. If the required version is still unavailable, contact MxP Support rather than repeatedly attempting the same download.


Q: Does the Force Update Mechanism download updates automatically?

The release note describes an update prompt with a direct link to the latest version. It does not confirm automatic downloading or installation. 


Q: Does the Force Update Mechanism apply to white-label mobile apps?

Support for white-label applications has not been confirmed for this release. MxP provides separate documentation for publishing and updating white-label app builds, but that does not establish that every branded app supports this enforcement mechanism. 


Q: Why does the mandatory update prompt keep appearing after I install the latest version?

The app may still be detecting an older installed version or the update may not have completed successfully. Verify that the installation finished and reopen the application. If the prompt persists, contact MxP Support for assistance.
