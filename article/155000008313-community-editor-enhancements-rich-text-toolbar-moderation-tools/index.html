Community Editor Enhancements: Rich Text Toolbar & Moderation Tools

Create better-looking posts, moderate your community more efficiently, and manage recordings with fewer clicks using the enhanced community editor.
What You'll Learn

The MxP community editor includes several enhancements designed to streamline content creation, moderation, and discussion management. These tools help you format posts more easily, moderate communities without leaving the feed, and interact with recordings directly from posts.

This article covers the floating rich text formatting toolbar, direct user banning from posts, recording downloads, and improved keyboard shortcuts for the comment editor.

Rich Text Formatting Toolbar

The floating formatting toolbar eliminates the need to memorize keyboard shortcuts or navigate away from your content. When you select text in the editor, a toolbar appears with common formatting options, making it faster to create well-structured, visually appealing posts and comments.

The toolbar provides instant access to the following formatting styles:

Bold — Emphasize important words or phrases
Italic — Add subtle emphasis or indicate titles
Underline — Highlight key information
Strikethrough — Show deletions or changes
Insert Links — Embed hyperlinks within your text

Pro Tip

The formatting toolbar appears automatically when you highlight text with your cursor. You can also use traditional keyboard shortcuts if you prefer.

Ban Spammers Directly from Posts

Community moderators can ban users immediately without leaving the discussion feed or navigating to the Members tab. This streamlines moderation workflows and allows you to address spam or inappropriate content quickly.

When you ban a user, MxP provides the option to delete all content created by that user, ensuring spam or policy violations are removed comprehensively.

Step 1
Open the Post Menu

Locate the post from the user you want to ban and click the three-dot menu (⋮) in the top-right corner of the post.

Step 2
Select "Ban User"

Choose "Ban User" from the dropdown menu. A confirmation dialog appears with the user's profile and username.

Step 3
Confirm the Ban

Check the "Delete all content created by this user" box if you want to remove all posts, comments, and recordings from the user. Click "Yes, Ban" to complete the action.



Note

Banned users cannot access the community until unbanned. All their content is permanently removed if you select the delete option during the ban process.

3

Download Recordings from Posts

Video and audio recordings shared in community posts can be downloaded directly from the post menu. This allows you to save recordings for offline viewing, archiving, or repurposing content without additional steps.

Step 1
Locate the Recording Post

Navigate to the post that contains the recording you want to download.

Step 2
Open the Post Menu

Click the three-dot menu (⋮) in the top-right corner of the post.

Step 3
Select "Download Recording"

Choose "Download Recording" from the dropdown menu. The recording file downloads immediately to your device.

Pro Tip

Recording downloads are available for both video and audio posts. The file format depends on the original recording type.

Improved Comment Editor Keyboard Shortcuts

Based on user feedback, MxP has updated the comment editor keyboard shortcuts to align with common text editing behaviors. The updated shortcuts provide a more intuitive writing experience and reduce confusion when drafting comments.

Feature 1
Enter Key → Start a New Paragraph

Pressing Enter creates a new paragraph block with vertical spacing, matching standard word processing behavior.

Feature 2
Shift + Enter → Insert a Line Break

Pressing Shift + Enter inserts a line break within the same paragraph, allowing you to separate lines without creating a new paragraph block.

Feature 3
Ctrl + Enter → Publish the Comment

Pressing Ctrl + Enter (or Cmd + Enter on Mac) submits the comment immediately, providing a keyboard alternative to clicking the "Post" button.

Why This Matters

The updated keyboard shortcuts align with familiar text editor conventions, reducing the learning curve and helping users write comments faster without accidental submissions.

Frequently Asked Questions

Q: Can I use keyboard shortcuts instead of the rich text toolbar?
Yes. The floating toolbar is a visual enhancement that complements existing keyboard shortcuts. You can continue using traditional shortcuts (e.g., Ctrl+B for bold, Ctrl+I for italic) if you prefer.
Q: What happens to a user's content when I ban them?
When you ban a user, you are given the option to delete all content created by that user. If you check the "Delete all content created by this user" box, all posts, comments, and recordings from the user are permanently removed. If you do not check this box, their content remains visible in the community.
Q: Can I unban a user after banning them?
Yes. Navigate to the Members tab, locate the banned user, and select "Unban User" from their profile menu. Note that if you deleted their content during the ban process, that content cannot be restored.
Q: What file format are downloaded recordings?
Downloaded recordings retain the format of the original file uploaded to the community. Most recordings are saved as MP4 for video and MP3 for audio, but formats may vary depending on how the recording was created.
Q: Do the improved keyboard shortcuts work in the post editor as well?
Yes. The updated keyboard shortcuts (Enter for new paragraph, Shift+Enter for line break, Ctrl+Enter to publish) apply to both the comment editor and the post editor, providing a consistent experience across all writing areas in the community.
Q: Can I download recordings from posts I didn't create?
Yes, as long as the post is visible to you in the community. Recording downloads are available to all community members with access to the post, not just the post author.
Q: Does the rich text toolbar appear in mobile browsers?
The floating rich text toolbar is optimized for desktop browsers. On mobile devices, formatting options may be accessed through a different interface depending on your device and browser. The toolbar is designed to provide the best experience on desktop while maintaining full functionality across all platforms.
