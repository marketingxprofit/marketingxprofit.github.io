Manage Comments in Social Planner



Manage comments on your social media posts directly from the social planner! The social planner supports comment management for Facebook, Instagram, TikTok, Communities, Bluesky and LinkedIn. This article covers how to use comment management along with the capabilities and limitations of this feature.

What is Comment Management?


Comment Management in Social Planner helps you view and respond to comments from your posts, all in one dashboard. Instead of jumping between social media platforms, you can now manage conversations directly where you schedule and plan content. 


Note: Currently, only comments from posts published via Social Planner are supported. Comments on posts published natively (directly in Facebook, Instagram, LinkedIn, Tiktok, Communities, etc) will not appear here. Support for other social platforms is in progress.

Key Benefits of Comment Management


  • One-Stop Inbox: View every comment alongside scheduled posts.

  • Real-Time Engagement: Keep engagement consistent by liking and replying to comments.

  • Conversation Context: Manage deeper discussions with threaded (nested) replies.

  • Time-Savings: Save time by replying without leaving Social Planner.

  • Faster inbox cleanup: Mark all unread comments within the selected platform and filtered view as read without reviewing each conversation individually.

What You Can Do in Comment Management


These capabilities streamline day-to-day engagement so you can respond faster, keep conversations organized, and highlight high-value interactions without leaving MxP.



Replying to Comments


Respond to any top-level comment directly from Social Planner, preserving author names, emojis, and GIFs for a native feel. Fast, on-brand replies strengthen relationships and can drive additional engagements or DMs.



Liking Comments


A quick “like” lets followers know you’ve seen and appreciated their input. Every like is recorded on Facebook and contributes to post engagement metrics, further improving reach.



Mark All Comments as Read


Use Mark All as Read to mark all unread comments within the selected platform and active filters as read.

This action clears the unread comment count for the current view. It does not remove comments. You can continue to view and reply to comments after marking them as read.


Responding to Threaded Comments


Threaded replies keep multi-person conversations organized. Click the arrow beside a parent comment to view and answer sub-threads so your replies appear precisely where the discussion is happening.



Smart Filters (Latest vs Top)


Use the dropdown above the inbox to switch views:

  • Latest: Shows the most recent activity so you never miss new questions.

  • Top: Sorts by Facebook’s “most relevant” order, surfacing high-engagement comments first.



Using Mentions in Comment Replies


Tag Facebook Pages or public profiles by typing “@” plus at least three characters. A list of matching public pages appears, allowing you to credit partners or acknowledge customers without leaving MxP.

How to Use Comment Management



Step 1: Open Comments in Social Planner


Go to the Marketing →  Social Planner →  Comments




Step 2: View and Engage with Comments


Here, you can:

  • Read comments from posts published via Social Planner.

  • Reply directly to users.

  • Like comments.

  • Add emoji and images in reply

  • Reply to threaded (nested) comments for deeper discussions.

Click on View More for expanded comment view




Step 3: Filter Between Latest and Top Comments


Use the dropdown filter to choose how you want to view comments:

  • Latest → Shows the most recent comments first.

  • Top → Highlights the most engaging or relevant comments.




Step 4: Mark All Comments as Read


  1. Select the platform you want to manage.

  2. Apply the filters for the comments you want to update.

  3. Click Mark All as Read.


All unread comments within the selected platform and active filters are marked as read. The unread count for that view clears immediately. Existing comments remain available. You can continue to view and reply to them

Platform Capabilities Overview


Comment Management inside Social Planner now supports Facebook, Instagram, TikTok and LinkedIn, with more platforms coming soon.


Facebook

  • View comments on posts published via Social Planner

  • Reply to comments using text, emojis, and images (up to 10MB)

  • Threaded replies supported (multiple levels)

  • Like comments

  • Mentions supported using “@” + minimum 3 characters for search

  • Filter comments by Latest or Top

  • Emoji support available in replies

  • Image uploads supported (up to 10MB per Facebook limitations)

  • Search comments (minimum 3 characters)

  • Hide/Delete not supported

  • API support available

  • Media in comments (GIFs, thumbnails) visible but not clickable

  • Only comments from posts published via Social Planner are supported


 Limitations:

  • Nested comment counts are not displayed (only top-level counts appear).

  • Thumbnails, images, videos, and GIFs in comments are not clickable.

  • Options to add GIFs, stickers, or avatars in replies are not supported.

  • Image uploads above 10MB are not supported (Facebook API limit).

  • Search requires a minimum of 3 characters.

  • Comments on posts published natively on Facebook will not appear.

  • Hide/Delete actions are not supported.



Instagram

  • View comments on posts published via Social Planner

  • Reply to comments using text, emojis, and images (up to 10MB)

  • Threaded replies supported

  • Like comments

  • Mentions supported only when typing the exact @username (search not available)

  • Filter comments by Latest or Top

  • Emoji support available in replies

  • Image uploads supported (up to 10MB per Instagram limits)

  • Search comments (minimum 3 characters)

  • Hide/Delete not supported

  • API support not available for Instagram comments

  • Media in comments visible but not clickable

  • Only comments from posts published via Social Planner are supported


Limitations:

  • Mentions do not support search, users must type the exact @username (Instagram API limitation).

  • Thumbnails, images, videos, and GIFs in comments are not clickable.

  • Image uploads above 10MB are not supported.

  • Search requires a minimum of 3 characters.

  • Hide/Delete actions are not supported.

  • API support for Instagram comment management is limited, which restricts advanced actions.

  • Comments on posts published natively on Instagram will not appear.



Linkedin

  • View comments on LinkedIn Page posts published via Social Planner

  • Reply to comments using text and emojis

  • Support for one level of threaded replies

  • Like comments

  • Mention other LinkedIn users by searching for their usernames

  • Filter comments similar to Facebook and Instagram (Latest, Top)

  • Search comments (minimum 3 characters)

  • View all comments inside the unified inbox

  • Supports LinkedIn Page posts published through Social Planner


Limitations:

  • Only LinkedIn Pages are supported; personal profiles cannot be connected (API restriction)

  • Threaded replies are limited to one level

  • Image uploads in replies are not supported

  • Thumbnails, images, GIFs, and videos in comments are not clickable

  • Comments on posts published natively on LinkedIn do not appear in Social Planner

  • Hide/Delete comment actions are not supported

  • Search requires a minimum of 3 characters

  • Replies must be within LinkedIn’s 3000-character limit



TikTok

  • View comments on posts published via Social Planner

  • Reply to comments using text and emojis

  • Support for one level of threaded replies

  • View all comments inside the unified inbox


Limitations:

  • Comment Management is supported only for TikTok Business Profiles
  • Maximum comment length is 150 characters
  • Media attachments are not supported in replies
  • Users can reply to one level of threaded comments only



Communities

  • View comments on community posts directly within Social Planner
  • Reply to comments using text
  • Support for one level of threaded replies
  • View all comments inside the unified inbox
  • Mention community members using “@” in replies
  • Real-time sync with the native platform for latest updates


Limitations:

  • Attachments are not supported in replies
  • Course mentions and event mentions are not supported
  • Comment editing is not available within Social Planner
  • Maximum comment length is 8000 characters
  • Users can reply to one level of threaded comments only



Bluesky

  • View comments on Bluesky posts published via Social Planner
  • Reply to comments using text and emojis
  • Threaded replies supported (up to 3 levels visible)


Limitations:

  • Replies are limited to 300 characters  
  • Only text and emojis are supported (no media attachments)  
  • Profile tagging is not supported  
  • Replies are visible up to 3 levels deep (full threads are stored internally)  
  • Comments are synced for the last 15 posts only
  • Sync runs every 6 hours (4 times a day)


Threads

  • View comments on Threads posts published via Social Planner
  • Reply to comments using:
    • Text
    • Images
    • Emojis
    • Location attachments
  • Support for one level of threaded replies
  • View all comments inside the unified inbox
  • Real-time comment synchronization using webhooks
  • Manage Threads conversations alongside Facebook, Instagram, LinkedIn, TikTok, Communities, and Bluesky


Limitations

  • Only Threads posts published via Social Planner are supported
  • Threaded replies are limited to one level
  • Comment management is available only for connected Threads Business/Professional accounts supported by the Threads API
  • Hide or delete comment actions are not supported
  • Search requires a minimum of 3 characters
  • Replies are subject to Threads platform character and API limitations
  • Features available in Social Planner depend on the capabilities supported by the Threads API


Note: Existing Threads accounts must be reconnected once to grant the permissions required for Comment Management

Frequently Asked Questions


Q: Can I see comments from other platforms?
Not yet. Currently, only Facebook, Instagram, TikTok, Communities, Bluesky, and LinkedIn comments are supported. Other platforms are coming soon.


Q: Will I see comments on posts published directly from Native Platform?
No. Only comments on posts published via Social Planner will appear here.


Q: Can I delete or hide comments?

No. Delete and hide actions are not supported in Comment Management.


Q: Can I reply with images and emojis?

Yes, we support replying with emojis. Images are platform dependant.
